# LAN 模型投遞

## 直接傳送更新（1.0.1）

邀請連結只包含地址，唔包含金鑰或查詢參數。已移除更新投遞碼嘅控制。舊版 DROP_CODE 設定同資料卷內嘅 drop-code 檔案會保留但唔再使用。升級保留同一個資料卷、接收站金鑰同等候中模型。檔案格式、大小、佇列同到期限制維持不變。

任何連得到服務嘅人都可以傳送；收件箱、下載同管理仍然需要接收站金鑰。每個來源地址一分鐘最多嘗試傳送 60 次，之後要等五分鐘。只限可信任嘅區域網絡使用，切勿公開到互聯網。新版容器發佈同實際 LAN 驗證仍待完成。

呢個係你本地網絡上面嘅一個細網頁，其他人（手機、平板、手提電腦）可以用佢傳
3D 模型去呢部電腦嘅 Bambu Studio MD3。佢喺 Docker 容器入面運行；Bambu Studio
會攞走收到嘅模型，再問你每個要開啟定棄置。唔會自動開啟、切片或者打印任何嘢。

完整指南：Bambu Studio MD3 原始碼入面嘅
`docs/features/application-integration/lan-model-drop-site.yue_HK.md`，應用程式嘅「說明」都有。

## 啟動

開咗 Docker Desktop 之後，喺呢個資料夾開終端機，執行：

```powershell
..\host.bat --detached
```

啟動器會下載已發佈、以摘要鎖定嘅映像，保留資料卷，等候健康檢查通過，
再顯示完整 LAN 地址。預設埠係 8833。請喺傳送裝置再試開一次地址；
啟動器唔會更改現有網絡保護。要睇即時服務狀態同記錄，執行：

```powershell
..\host.bat --logs
```

## 連接 Bambu Studio

喺 Bambu Studio 開啟「偏好設定」>「LAN 模型投遞」，揀「啟動本機投遞伺服器」。
原生操作會經受保護嘅本機管道傳送接收站金鑰，再儲存連線，唔會顯示金鑰。
設定失敗時會顯示結果，並保留原有設定。

## 設定

將 .env.example 複製成 .env，按需要調整埠號、檔案大小、佇列、到期時間同 LAN 地址，再執行 docker compose up -d。

## 停止、更新、移除

| 工作 | 指令 |
| --- | --- |
| 停止（模型同金鑰會保留） | `docker compose down` |
| 安裝咗新版 Bambu Studio MD3 之後更新 | `..\host.bat --detached` |
| 全部移除，包括等緊嘅模型同金鑰 | `docker compose down -v` |

## 會做同唔會做嘅嘢

- 只接受 3MF、STL、STEP、OBJ 同 AMF，會按檔名同內容檢查。
- 模型只會保留到 Bambu Studio 攞走，或者 24 個鐘。

完成配對後，開啟接收模型，再分享邀請連結或者 QR 碼。.env 可能包含接收站金鑰，切勿分享。
