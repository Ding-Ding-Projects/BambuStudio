# Slice motion storyboard

The print setup waits on a stale plate. Four high-contrast brackets slowly press toward the current plate geometry and release. No percentage or toolpath is shown. The existing Slice again action remains keyboard accessible.

A slice requested from print setup carries that origin after the dialog closes. A pair of opposing bands draws inward, recoils and reassembles around the plate. The movement is ornamental. Render current model geometry until actual paths are available. Show the reported processing percentage separately.

An ordinary slice carries an outward impact ring and a rising scan line across the exact current plate. Batch slicing uses the same visual language on the currently executing plate. Real ordered extrusion data, when available, builds in machine execution order. A time-based animation never stands in for reported processing progress or for real print paths.

Reduced motion holds each composition still and keeps the model, state label, actual progress and cancel action. A stale identity or empty plate clears the preview. Abort and finish stop animation. Review normal and minimum windows, all three language modes, light and dark, and 100%, 125%, 150% and 200% scale.
