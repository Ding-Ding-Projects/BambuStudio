Lubricate mode in the process settings
A switch on the Others page, beside Express print mode. When it is on, the start G-code runs the full-travel routine right after the printer's first full homing, then homes again so the rest of the preparation is unchanged.

Tooltip
Before every print, right after the printer homes, run the motion system through its whole travel so fresh grease spreads along the rails, lead screws and bearings: the bed moves all the way down and back up twice, and the toolhead runs the full length of X, of Y and both diagonals. On Bambu Lab printers the buzzer beeps like a truck backing up while the bed moves. The printer homes again before the rest of the preparation, so the print itself is unchanged; the start takes a few minutes longer. Default: off.
Where it runs on the H2C
G28 X T300 G1 X175 Y160 F30000 G28 Z P0 T250 ; end of the first homing ; lubricate melody: truck_backup G1 Z5.00 F1500 M1006 A83 B20 L99 ... ; a beep, then 25 mm of bed G1 Z29.23 F1500 ... ; down and up twice, X, Y, diagonals G28 Z P0 T250 ; home again after lubricate mode ... M622 J0 G28 R ; skipped: inside a firmware conditional M623
With lubricate mode off, the chosen melody still plays once at the very start of every print, in every mode, including Express print mode. Silent turns it off.
