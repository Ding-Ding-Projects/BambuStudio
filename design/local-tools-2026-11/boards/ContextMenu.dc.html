Keyboard and screen readers
KeyDoes
Shift+F10Opens the menu for the focused element
Up, DownMove between rows, controls included
SpaceToggles a switch and keeps the menu open
Left, RightChange a choice, slider or stepper
EnterRuns a plain command
EscCloses and returns focus to the element
Screen readers hear "Snap to grid, switch, on". Shortcuts come from the same table that binds the keys, so a shown shortcut always works in that place.
