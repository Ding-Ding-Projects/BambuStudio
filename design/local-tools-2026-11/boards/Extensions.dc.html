manifest.json
Valid
{ "id": "com.example.spool-weigh-in", "name": "Spool weigh-in", "version": "1.2.0", "apiVersion": 1, "description": "Tracks spool weights.", "run": { "windows": "powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -File weigh-in.ps1" }, "hooks": ["plate.sliced", "print.before_send", "print.finished"], "actions": [{ "id": "show", "title": "Show spool weights" }], "permissions": ["slice.read", "printer.read", "notes.show", "send.warn"] }
One JSON request goes in on standard input, one JSON answer comes back on standard output. A broken extension cannot take Bambu Studio down.

How the answers are used
AnswerWhat happens
Every row passesNothing to look at: the window closes by itself and sending carries on.
warn or fail rows, notesShown grouped by extension. Send carries on; Back returns.
block: trueThe print is not sent. Only extensions you allowed send.block can do this.
No valid answerShown with the reason. It never holds a print back.
Send without the checksThe runs stop at once and are recorded as stopped by you.
