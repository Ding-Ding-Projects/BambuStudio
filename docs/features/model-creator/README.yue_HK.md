# 原生模型創作者

模型創作者把自然語言描述轉換成一個有限版本 1 場景規格、用 OpenSCAD 或 Blender 渲染網格同在用戶嘅本地應用數據資料夾下面保持每個完成修訂。用戶明確地選擇一個供應商同模型。對話盒提供 Claude CLI、Codex CLI、Anthropic API 同 OpenAI API。佢從未匯入生成網格直到**加到板**被按下。

## 場景合約

模型回應必須係一個單個 JSON 對象帶著 `version: 1`、最多 80 字節嘅標題同 1 到 32 部分。每個部分係 `box`、`cylinder` 或 `sphere`，帶著毫米尺寸同三號位置。方形取三號大小，圓筒取高度同半徑，球體取半徑。圓形原始可以指定有限面。尺寸同位置有固定界限。每個完整立體，包括佢嘅半徑或半寬度在翻譯後，必須適合喺兩個軸上面 -500 到 500 毫米內嘅水平工作區。立體必須適合喺建造板上面。未預期鑰匙、可執行內容、URL 同其他模式版本被拒絕。回應被限制到 64 KiB。一個無效場景可能接收最多兩個自動供應商更正請求；連接同進程失敗唔被重試。供應商文字永唔會變成腳本：應用從接受數值發出固定 OpenSCAD 或 Blender 代碼。

生成 STL 被限制到 100 MiB。一個完成修訂保持佢嘅已驗證源、網格同有限本地元數據用於重新打開在重啟後。Blender 修訂都保持可編輯 `.blend` 檔案。工作區保持最新 100 完成修訂。在成功生成後同重新打開對話盒時，只當佢哋包含被識別版本 1 清單、源檔案同網格時更舊修訂資料夾被移除。符號連接同未完成資料夾唔被清除。保持一個獨立複本在依賴修訂做永久項目檔案前。對話盒喺背景工作員載入保持修訂同重新驗證每個網格在使其可用於預覽或板匯入前。生成保持禁用直到該掃描完成，所以佢唔可以競賽保持清除。關閉對話盒等待活躍掃描完成。取消請求永遠唔達到板。未簽署 Windows 套件階段釘住便攜式 OpenSCAD 2021.01 同 Blender 5.2.2 分佈在驗證佢哋 SHA-256 摘要後。對話盒根據預設選擇束縛可執行檔、顯示是否佢可用同允許自訂可執行檔。渲染用固定參數同五分鐘超時。一個渲染失敗為檢查保持佢嘅檔案而唔洩露網格用於匯入。

## 供應商認證同隱私

API 鑰匙只通過 Windows 認證管理員儲存，帶著增加/替換、連接測試同移除控制。鑰匙唔被寫到項目、進程參數、生成場景、回應檔案或診斷輸出。連接測試發出短認證模型請求同失敗時僅報告 HTTP 狀態。API 請求用 HTTPS、有限回應、連接超時、全部超時同取消。兩個 API 通過佢哋結構化輸出選項請求共享 JSON 模式同有限解析器檢查結果再次。選擇供應商、模型、渲染器同自訂可執行檔路徑被儲存做非秘密偏好。

Claude Code CLI 同 Codex CLI 進程用隔離工作家庭同設定資料夾。佢哋通過標準輸入接收請求同用佢哋結構化輸出模式選項。Claude Code CLI 執行喺安全模式帶著工具同 MCP 設定禁用。Codex CLI 忽視用戶設定同規則、禁用可用外部功能同用唯讀沙箱。每個 CLI 通過佢嘅支援設定資料夾介面保持佢嘅現有登入位置，唔複製認證字節。Codex CLI 唔洩露禁用每個建立功能嘅單個有文件旗幟，所以佢嘅唯讀沙箱同禁用外部功能保持防禦深處而唔係一個零可用工具聲稱。對話盒識別選擇供應商同模型先至提交。

每個 CLI 同渲染進程開始暫停、加入 Windows 工作對象同被恢復只在進程樹包含成功後。取消同超時終止工作同等待佢嘅後代。CLI 標準輸出被限制到 256 KiB 同渲染輸出到 1 MiB 當子執行時；超過任意限制終止工作。Codex CLI 嘅直接結構回應檔案都在執行期間被檢查針對 64 KiB 回應限制。臨時請求、回應、模式同診斷檔案喺正常完成、錯誤同取消被移除。突然應用出口可以留佢哋後面；重新打開對話盒移除修訂資料夾從 24 小時舊版本擷取檔案，同保持最新檔案獨自避免打擾活躍生成喺另一對話盒。

## 整合

原生對話盒從主匯入選單同命令調板可用。佢嘅 `AddToPlate` 回調接收驗證本地 STL 路徑只在用戶按下**加到板**後，然後主機載入佢到現有清單機。對話盒嘅**預覽網格**動作用系統嘅登記查看器打開保持網格。佢尚未嵌入 3D 預覽。

## 確認同限制

被聚焦 C++ 測試覆蓋有效場景、尺寸同版本拒絕、未預期可執行欄位、建造板界限、固定渲染輸出、隔離進程環境同超時同取消時後代終止。完整應用建立同實際供應商同渲染驅動需要先至聲稱整個流工作。嵌入式 3D 預覽同完整網格流形分析唔被實施。由不連通原始組成嘅模型可能需要支援、方向或布林運算先至打印。預覽係幾何檢視幫助，唔係可打印性保證。冇都被執行任意供應商生成原始碼。
