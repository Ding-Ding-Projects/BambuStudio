# 動畫同轉場

外觀編輯器嘅第五個分頁 **動畫同轉場**，用嚟編輯編輯器錨定嗰個指定元素喺狀態變化時點樣郁，
以及包含佢嘅視窗點樣淡入。喺元素嘅右鍵選單揀 **編輯外觀…**、Shift+撳右掣，或者喺有焦點嘅
控制項撳 Ctrl+Shift+E 打開編輯器，然後揀呢個分頁，或者一直撳 Ctrl+Page Down 去到佢。

## 全域動畫設定優先

**偏好設定 > 介面動畫** 同 Windows 嘅用戶區動畫設定仍然話事。任何一個要求減少動畫，所有
轉場同進場都會即刻顯示最終狀態，分頁嘅預覽都一樣。喺呢度設定嘅數值會保留，等可以再播動畫時
再用。分頁頂部會講明而家係邊種情況，設定改咗之後一秒內會更新。

呢個應用程式冇動態彩虹色，亦冇全域速度級別，所以呢度冇嘢同佢哋衝突。

## 狀態轉場

按鈕、欄位、列表同卡片喺狀態變化時，會一齊動畫化佢哋嘅狀態顏色（背景、邊框同文字）。
喺 **觸發** 揀要編輯嘅變化：

| 觸發 | 幾時播 |
| --- | --- |
| 懸停 | 指標進入或者離開元素 |
| 焦點 | 元素得到或者失去鍵盤焦點 |
| 撳 | 喺元素上面撳落或者放開指標按鈕 |
| 選擇 | 切換按鈕或者剔選開啟或者關閉 |
| 啟用同停用 | 元素變成可用或者不可用 |

一個事件改咗幾個狀態時，撳最優先，跟住係選擇、焦點、懸停同啟用。每種觸發有三個數值：

| 數值 | 範圍 | 未設定時 |
| --- | --- | --- |
| 時長 | 0 至 10000 毫秒；16 毫秒或以下會即刻顯示最終狀態 | 100 毫秒，即 Material Design short 2 時長 |
| 延遲 | -10000 至 10000 毫秒；負數延遲會由中途開始 | 0 毫秒 |
| 緩動 | 具名曲線、`cubic-bezier()`、`steps()` 或者 `linear()` | Material Design 標準曲線 |

正數延遲期間，元素會保持起始顏色。每個轉場只播一次，而且一定準確停喺新狀態，唔理曲線中途
點樣行。新嘅狀態變化會打斷運行緊嘅轉場，並由畫面上嘅顏色開始。冇嘢會等轉場：狀態、焦點同
輸入會即刻改變。

每個數值都會講明佢嘅來源：為呢個元素設定、由父元素（ID 斜線之前嗰部分）或者活躍預設繼承，
定係 Material Design 預設。每個數值都有自己嘅重設按鈕。

## 緩動

**緩動** 列表有 Material Design 曲線（標準同強調，各有加速同減速版本）、線性、緩和、緩入、
緩出同緩入緩出。揀 **自訂** 會去到 **緩動函數** 欄，可以輸入以下任何一種，再撳 Enter：

| 形式 | 例子 | 規則 |
| --- | --- | --- |
| 三次 Bezier | `cubic-bezier(0.2, 0, 0, 1)` | x1 同 x2 由 0 至 1；y1 同 y2 由 -5 至 5 |
| 分步 | `steps(4, jump-end)` | 1 至 100 步；jump-start、jump-end、jump-none（2 步或以上）或者 jump-both |
| 線性停點 | `linear(0, 0.25 40%, 1)` | 2 至 64 個停點；每個係一個數字，最多加兩個百分比 |

唔能夠解讀嘅文字會被拒絕並講明原因，元素會保持原本嘅緩動。呢個欄位永遠顯示已儲存數值嘅標準
寫法。暫時未可以拖拉 Bezier 控制點；數字一改，曲線預覽就會即刻重畫。

## 預覽

預覽會對住時間尺，用實線畫出所揀嘅轉場，旁邊用虛線畫 Material Design 預設，延遲部分加陰影，
下面嘅色帶顯示播放位置嗰刻嘅顏色。**播放**、**倒轉播放** 同 **停止** 用同元素一樣嘅計算方法；
再播一次會由頭開始。**預覽速度** 可以將預覽減到半速或者四分一速，唔會改元素。**預覽位置**
可以跳去任何一毫秒。每組時間下面嘅文字摘要會講明總運行時間，所以預覽永遠唔係唯一嘅描述。

## 視窗進場

用 Material Design 標題列嘅對話框、指令面板、正則表達式建立器、選單同呢個編輯器，打開時會由
四分一不透明度淡入。如果包含元素嘅視窗有呢種進場，而且係已登記嘅元素，**視窗進場** 就可以
編輯佢嘅時長、延遲同緩動；否則呢部分會講明點解冇嘢可以編輯。編輯器自己打開時嘅淡入，就係
元素 `appearance-editor` 嘅進場。

## 變更、記錄、預設同檔案

- **復原** 同 **重做** 會逐步行過喺呢個編輯器做嘅動畫編輯，跨元素都得；提示會講明會改咩。
- **重設元素動畫** 會用一個可以復原嘅動作，移除呢個元素所有動畫數值，認得同唔認得嘅都包括。
  編輯器底部嘅 **重設元素** 同 **全部重設** 仍然會重設所有嘢。
- 每個變更都會同其他元素樣式一齊即刻儲存，並記錄喺 **版本記錄**；復原、重做同重設喺嗰度都有
  名稱。
- **另存為預設** 會保留動畫數值，而預設嘅說明會列出佢設定嘅每個動畫數值。
- 匯出嘅主題會帶埋動畫數值。匯入時會檢查：無效數值會列喺匯入結果同分頁嘅 **保留但未套用**，
  並改為播 Material Design 預設。呢個版本唔認得嘅動畫設定會留喺檔案，亦會列喺嗰度。

動畫數值以元素嘅 `motion.<trigger>.<field>` 屬性儲存；trigger 係 hover、focus、press、
selection、enable 或者 entrance，field 係 duration、delay 或者 easing。

## 繪製程式功能

分頁底部會列出外觀規範入面每一項動畫功能，以及呢個繪製程式點樣處理；可以用純文字或者正則
表達式建立器搜尋。不可用嘅功能會以停用項目連埋準確原因保留喺列表，包括圖層、軌道、關鍵影格
同標記、動畫路徑、逐個屬性嘅轉場列表、變形同控制項不透明度、重複、方向同填充模式、播放速率、
彈簧、文件同捲動時間軸、排序同錯開、退場動畫、驗證、載入、成功、警告同錯誤狀態、複製同貼上
樣式、排程，以及指令面板直達。

列表背後嘅手寫對照表係
[`design/native-appearance/motion-capability-inventory.json`](../../../design/native-appearance/motion-capability-inventory.json)。
每一行已接駁嘅項目都會講明播放佢嘅原始碼；原始碼合約會確保對照表同分頁列表完全一致。

## 驗證

純測試涵蓋緩動語法同計算、正數、負數同零延遲嘅時間、驗證、經樣式層解析、儲存同載入來回、
復原同重做，以及功能表。樣式登記測試涵蓋父元素同預設繼承、匯入報告，以及控制項實際呼叫嘅
即時解析。原始碼合約會檢查分頁存在、對照表每一行同分頁一致、每個已接駁項目嘅使用者都喺度，
而且移除任何一個都會被發現。

未驗證：已建置嘅 Windows 應用程式。仍然需要定時錄影或者取樣畫格，喺真實控制項上顯示每種觸發、
時長、延遲、曲線、進場、中斷同減少動畫情況，並喺英文、廣東話同雙語模式、兩個主題同每個顯示
比例下，逐次撳擊擷取分頁畫面。
