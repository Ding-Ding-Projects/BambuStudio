# 原生外觀繪製

元素登記表提供 `ElementStyle::metrics_for(id, baseline)`，統一處理圓角半徑、邊框闊度、內外距、字距同行高。先解析繼承值，再限制數值喺有效範圍。幾何數值用邏輯像素，自繪元件以 `FromDIP` 換算。`StyleMetrics::radius_for`、`inset_for` 同 `line_advance` 負責有界限嘅版面計算。

通用 wxWindow 轉接器會將外距套用到承載佢嘅 sizer 項目，記住原有邊框同版面旗標，重設時還原。唔喺 sizer 入面嘅元素套用唔到呢項屬性。字型同前景、背景色沿用現有原生實作。

外觀編輯器嘅形狀頁會實際預覽圓角、邊框闊度同顏色、內外距、字型、前景同背景色及行高。標籤沿用原生文字塑形，內容限制喺示範框內。呢個預覽只證明繪製轉接器可以運作，其他元件要各自接駁。

## 整合位置

- 自繪元件要喺量度同繪製兩個階段都呼叫 `metrics_for(ElementStyle::element_id_of(this), existing_baseline)`，等內距同點擊範圍同步改變。
- 外框用 `colour_for(id, StyleProp::border_color, existing_border)`。圓角同筆畫必須留喺元件範圍內。
- 指令面板可列出 `StyleProp::all()` 並開啟 `AppearanceEditorPopover::open_for(anchor, id)`。登記時要保留確實存活嘅目標，唔好快取原始指標。
- 新增文字要抽取入翻譯目錄，再審閱廣東話同雙語效果。

## 能力限制

原生 wxFont 支援字族、大小、數值字重、斜體、單底線同單刪除線。逐字形間距可以儲存，但未套用到原生標籤；按 Unicode 碼位切開字串會破壞文字塑形，所以唔用呢個方法代替正式排版引擎。

可變字型軸、傾斜角度、有樣式或顏色嘅底線、雙刪除線、頂線、小型大寫、上標下標、文字外框、陰影、光暈、詞距、基線偏移、方向同段落對齊都需要富文字轉接器。編輯器會列明未支援嘅功能。完整分層圖片編輯器同按狀態繪製外觀仍未完成。

## 驗證

`style_metrics_tests` 係喺外觀 CMake 目錄登記嘅獨立 C++17 執行檔，檢查數值收窄、細小同負數邊界、行高同非有限值。2026-10-05 用 GCC 編譯執行，回傳 0。喺獨立臨時標頭移除邊界限制之後，測試中止並回傳非零；正式來源冇更改。

Catch 外觀測試另有繼承度量同重設檢查。當時未有完整 MSVC/wxWidgets 建置，所以未執行。封裝版互動、截圖、無障礙同版面矩陣仍待確認。整合時要建置真正嘅應用程式，驗證外距重設同每個已接駁元件，再用正常同最細視窗、兩款主題、三種語言以及 100%、125%、150%、200% 縮放截圖。
