# Appearance

- [Native appearance rendering](native-rendering.md): native presentation settings,
  integration and current verification boundaries.
- [App logo](app-logo.md): the mark shown in the title bar, window and taskbar
  icon, About dialog and startup screen; presets, presentation controls, local
  persistence and the unavailable custom import.
- [Animation and transition](motion-editor.md): the appearance editor tab that
  edits each element's state transitions and its window's entrance, with the
  curve preview, undo and the renderer capability list.

Packaged runtime interaction and visual verification remain pending. Core checks
do not prove native rendering, accessibility or layout behavior.

Postman is not applicable: these local presentation features expose no HTTP API.
