# 應用程式標誌

喺 **偏好設定 > 外觀 > 應用程式標誌** 揀應用程式用嚟代表自己嘅標誌。
呢個選擇淨係改外觀。已安裝嘅程式、執行檔圖示、捷徑、安裝程式、更新來源、
應用程式識別碼同資料資料夾，全部都保留出廠身份。

## 標誌會喺邊度出現

| 位置 | 尺寸 | 幾時更新 |
| --- | --- | --- |
| 標題欄圖塊（選單左邊） | 26 px，按顯示器比例縮放 | 即時 |
| 視窗同工作列圖示 | 16、20、24、32、40、48、64、128 同 256 px | 即時 |
| 「關於」對話方塊橫額 | 64 px 圖塊，蓋喺出廠標誌上面 | 下次打開對話方塊 |
| 啟動畫面 | 122 px | 下次啟動 |

每個尺寸都由來源直接繪製，唔會由另一個尺寸縮放出嚟。每次繪製最多 256 像素；
顯示位置再大啲，就將呢個有上限嘅結果放大。「關於」嘅綠色橫額上面，透明標誌會
襯一塊白色圓角圖塊，等佢睇得清楚。

## 揀來源

來源清單係一組單選按鈕：用 Tab 可以去到，方向鍵、Home 同 End 會移動選擇，每一行
都會向螢幕閱讀器報告單選按鈕角色、名稱同揀咗未。上面嘅搜尋欄會篩選呢啲行；佢嘅
`.*` 切換掣同調校掣就係共用嘅正則建構器。冇嘢符合嘅時候，面板會直接講出嚟，
唔會淨係顯示一個空清單。

| 來源 | 顯示乜 |
| --- | --- |
| 出廠標誌（預設） | 每個位置都用返原裝圖案 |
| 綠色打印機、藍色打印層、琥珀色噴嘴 | 用本機幾何圖形畫出嚟、以打印機為主題嘅原創標誌 |
| 自訂圖片（未能使用） | 會列出但停用；詳情睇下面 |

揀一行就即刻套用同儲存。**重設為出廠標誌** 會喺所有位置還原出廠圖案，
並清除儲存咗嘅設定。

## 外觀控制

呢啲控制只用喺預設標誌；揀咗出廠標誌嘅時候佢哋會停用，面板會講原因。

- **圖片適配**：「完整顯示」會顯示成個標誌；「填滿」會裁剪到填滿為止。
- **水平同垂直焦點**：標誌擺喺邊，或者「填滿」裁剪時保留邊部分（0–100%）。
- **安全區內縮**：每邊留 0–25% 空位。
- **透明背景**，或者用共用顏色選擇器揀一個唔透明嘅 **背景顏色**。

16、24、32 同 64 像素嘅即時預覽，顯示嘅就係各個位置喺呢啲尺寸用嘅同一個繪製結果。
細尺寸用最近鄰取樣，幼細位可能會唔見咗；透明標誌喺某啲背景上可能對比唔夠，
面板會提你。

## 儲存咗乜

應用程式自己嘅設定檔入面，`app_logo` 呢個鍵只儲存十個細數字：來源、預設標誌、
適配方式、兩個焦點、內縮、透明與否同背景顏色。唔會儲存任何圖片、檔案名或者路徑。
鍵係空嘅就代表出廠標誌。讀唔到嘅值會顯示出廠標誌，面板會話佢無效，但唔會覆寫，
直至你揀過標誌或者重設。舊版只得一種來源嘅設定，仍然會載入成對應嘅預設標誌。

## 狀態

| 狀態 | 面板點講 |
| --- | --- |
| 冇自訂標誌 | 用緊出廠標誌，冇載入自訂圖片 |
| 用緊預設標誌 | 用緊邊個預設標誌，同埋已經儲存 |
| 儲存值無效 | 顯示出廠標誌；儲存值會保留 |
| 已套用 | 套用咗同儲存咗邊個來源 |
| 已重設 | 已還原出廠標誌，儲存咗嘅設定已清除 |
| 儲存失敗 | 保留之前嘅標誌 |
| 搜尋冇結果 | 冇標誌來源符合搜尋 |

## 自訂圖片

暫時未可以匯入自訂圖片。嗰一行同 **匯入自訂圖片** 掣會一直顯示但停用，
亦都唔會打開任何圖片檔案。核心有一個有上限嘅解碼基本功能，只處理完全未壓縮嘅
24 位元 BMP（4 MiB、每邊 2048 像素、1,048,576 像素），但佢唔係隔離邊界，
亦都冇接駁檔案選擇器。匯入功能，連同載入中、已轉換、取代同轉換失敗呢幾個狀態，
要等一個有作業系統 CPU 同記憶體限制嘅隔離解碼程序，加埋經驗證嘅轉換先至得。

## 未包括嘅部分

- 排程設定、外觀匯出同匯入、本機歷史快照、指令面板直達同逐個元素外觀編輯，
  暫時都未包括標誌。偏好設定嘅設定搜尋就搵得到「應用程式標誌」嗰行。
- 其他對話方塊嘅視窗圖示保留出廠圖示；冇通知會畫應用程式標誌。
- 每個顯示尺寸喺打包程式入面嘅實際效果，仲要由建置好嘅應用程式截圖證明。

## 驗證

```powershell
g++ -std=c++17 -Wall -Wextra -pedantic -Isrc -Itests -Itests/catch2 tests/app_logo/app_logo_tests_main.cpp -o "$env:TEMP/app-logo-model.exe"
& "$env:TEMP/app-logo-model.exe"
g++ -std=c++17 -Wall -Wextra -pedantic -Isrc tests/app_logo/test_logo.cpp -o "$env:TEMP/app-logo-core.exe"
& "$env:TEMP/app-logo-core.exe"
node --test ui-md3/tests/app-logo-chrome.test.mjs
```

兩個 C++ 目標都已經喺 CTest 登記（`app_logo_tests`、`app_logo_core`）。
模型測試涵蓋出廠預設、重設清除鍵值、預設標誌來回儲存、無效同舊版儲存值、
選擇清單、每個介面位置嘅尺寸，同高 DPI 顯示器嘅繪製計劃。核心測試涵蓋預設標誌、
適配、焦點、內縮、透明度合成、設定還原同有上限嘅 BMP 基本功能。Node 測試會檢查
面板有編譯、有放入偏好設定、有接駁每個位置，冇任何身份路徑讀取呢個鍵，同埋面板
每句文字都有粵語翻譯。

Postman 唔適用：呢個本機外觀功能冇提供 HTTP API。
