# 受限空間內嘅 Preview 佈局

Preview 通知先使用實際可用寬度，再計算文字行。圖例旁邊放得落可讀卡片時，會保留該邊距；否則通知留喺畫布上、圖例前面，但唔會蓋過已開啟選單。較高卡片可以捲動。堆疊為兩個可用鍵盤操作嘅溢出動作預留實測區域：下一批通知同通知歷史。延後顯示通知連同回呼保留喺即時集合；延後期間暫停顯示同淡出計時器。原有通知中心保留既有事件歷史。

切片進度卡片量度完整本地化狀態，先計算目前高度再定位。提示保留原有內部佈局，包括控制器同連結，放喺受限可捲動視窗內。Preview 圖例喺窄寬度下可以展開；原有水平同垂直捲動令詳細內容仍可到達。列印板列旁邊放唔落嘅狀態標籤，會以換行文字顯示喺圖例標頭。分組說明有需要時移到另一列並換行，保留鍵盤啟動。統計縮圖文字喺圖塊內換行同縮放；懸停或鍵盤焦點亦可取得完整原始標籤。

## 驗證

`tests/preview_layout/geometry_tests.cpp` 呼叫 `PreviewLayout.hpp` 正式函式，涵蓋 100%、125%、150%、200% 縮放視窗寬度、保留可用圖例邊距、高卡片高度上限、溢出分頁資格、提示高度同翻譯後分組標頭適配。喺託管 Windows 執行器用 `cl /std:c++17 /EHsc /I src tests/preview_layout/geometry_tests.cpp /Fe:preview_layout_tests.exe` 編譯，再執行檔案。預期總數係 68 項檢查。現有 `ui-md3/tests/preview-overlays.test.mjs` 原始碼合約檢查，現時驗證共用幾何整合、即時溢出保留同狀態替代呈現。

呢項改動冇進行本機應用程式建置、測試執行或執行期間畫面擷取。託管編譯同實際繪畫驗證仍需完成。要測試長英文、廣東話同雙語通知、多個固定通知、通知分頁同回呼、展開提示同取消、窄而展開嘅圖例、多塊列印板、兩種主題、文件列明嘅最小用戶區域，以及四種顯示縮放。確認鍵盤焦點、捲動存取、彈出視窗優先次序、縮圖標籤同冇重疊。幾何檢查唔能夠證明實際外觀或原生無障礙。

延後計時會將每個經過時間區間只計算一次，唔受重畫次數影響。回歸案例涵蓋重複閒置更新、相同時間戳、重複延後繪畫、計時器更新之間恢復，以及完全冇閒置更新嘅完整延後區間。呢啲案例仍待託管執行。
