# 多重切片：每款墨水一個切片檔

多重切片會按你揀咗幾多款墨水，就將而家個盤切幾多次，每款墨水各自存一個切片檔
（`.gcode.3mf`）。同一個模型要用幾種物料準備好，例如打印機 USB 手指入面放一個 PLA
版同一個 ABS 版，就唔使逐款換墨水再自己切多次。

喺 **檔案 > 匯出 > 多重切片**、**全部功能**，或者指令面板（搜尋「多重切片」）都打開得到。

## 點用

1. 將模型放上個盤，照平時咁設定好。
2. 打開 **多重切片**，剔兩款或者以上嘅墨水。搜尋欄可以用墨水名或者類型篩選，
   同其他搜尋一樣有正規表示式產生器。
3. 睇清楚檔案存去邊。插住 USB 手指嘅話會自動揀佢；冇嘅話就用你上次存檔嘅資料夾，
   未存過嘢就用「文件」資料夾。**換資料夾** 可以揀第二個。
4. 揀 **切片同儲存**。每款墨水會有個標籤：**等緊**、**正在切片**、**已經存咗**，或者
   **冇存到**。冇存到嘅會喺墨水名下面一行寫明原因。
5. 完成之後，**睇吓啲檔案** 會打開個資料夾。如果係 USB 手指，平時嗰個退出掣會出現。

檔名用項目名加墨水名，例如 `bracket_Bambu_PLA_Basic_BBL_X1C.gcode.3mf` 同
`bracket_Bambu_ABS_BBL_X1C.gcode.3mf`。空格同某啲檔案系統唔收嘅字元會變成 `_`；同一次
入面重複嘅名會加 `(2)`、`(3)` 咁落去。

## 視窗係點樣

- 頂部有標題同關閉掣，視窗可以拉大拉細。
- 每款墨水係一個圓角列表入面嘅一行。指住一行會輕輕填色；揀咗嘅墨水會保持一個色調
  填色，一眼睇到揀咗邊啲。㩒行入面任何位置都得，用鍵盤就用行內嗰個剔選格。墨水類型
  （PLA、ABS……）係名後面一個細標籤。列表上面嘅表頭寫住兩欄：**墨水**同**狀態**。
- 狀態標籤：等緊或者已停止係灰色，切片緊係色調填色，存咗係綠色，冇存到係紅色。
- 列表下面一行講而家嘅情況：揀咗幾多款墨水，或者運行緊嗰陣「切片緊 2 / 3」連一條進度條。
- **存去** 只會寫一次個資料夾，太長就喺中間縮短。資料夾喺打印機 USB 手指上面嘅話，
  會出現一個綠色嘅 **USB 手指** 標籤。**換資料夾** 喺旁邊。
- 底部：存咗檔之後，**睇吓啲檔案** 喺左邊；右邊係 **關閉** 同唯一嘅確認動作 **切片同儲存**。
  運行緊嗰陣 **關閉** 會變做紅色嘅 **停止**。

## 每個檔案改咗啲乜

- 每個檔案入面，項目嘅 **所有墨水槽** 都會用揀咗嗰款墨水，槽嘅顏色唔變。多重切片係
  畀單一物料打印用；多色項目都會每款墨水出一個檔，不過每個槽都係嗰款墨水。
- 只會切 **而家個盤**。
- 唔會改工藝同打印機設定。
- 完咗之後，無論點樣完，都會換返項目原本嘅墨水。

## 點樣確保每個檔都係啱嘅墨水

換咗墨水之後，要等個盤嘅切片結果先被標做過時、再變返有效，先會存檔。所以上一款墨水
嘅結果永遠唔會用下一款墨水嘅名存起。如果揀嘅墨水同而家用緊嘅一樣，都會照樣標做過時，
令嗰個檔重新切過。

留低個檔之前，多重切片會打開佢，讀返佢設定入面切片用嘅墨水。用咗第二款墨水切嘅檔會
即刻刪除，嗰款墨水會報 **冇存到**，所以個檔永遠唔會頂住一款墨水嘅名，裝住另一款嘅切片。

如果 10 秒內冇開始切、切完冇結果，或者個盤用嗰款墨水打印唔到（例如墨水唔啱部打印機，
或者路徑出咗熱床），嗰款墨水會報 **冇存到**，然後繼續下一款。

## 停止

**停止**、頂部嘅關閉掣，或者 Escape 鍵，會切完而家嗰款墨水就停。未開始嘅墨水會顯示
**已停止**，原本嘅墨水會換返。

## 限制

- 最少要兩款墨水；得一款就用 **匯出單盤切片檔**。
- 只會列出啱而家部打印機嘅墨水。
- 檔案存喺本機或者抽取式磁碟。經網絡傳去打印機唔屬於呢個功能。
- 進行緊嘅時候唔好郁個盤：途中改模型會令嗰款墨水嘅切片再過時，佢會報冇存到。

## 驗證

- `tests/multi_slice_names_test.cpp` 檢查檔名：唔安全嘅字元、結尾嘅點、非 ASCII 墨水名
  同重複嘅名。
- 實際運行喺建置好嘅程式入面檢查過：X1 Carbon 設定、20 mm 方塊、PLA 同 ABS，出咗兩個檔，
  每個讀返都係自己嗰款墨水（PLA 220 °C，ABS 270 °C）。
