# 原生選單同印表機選取生命週期

Prepare 印表機卡片透過明確可見焦點擁有者開啟預設下拉選單。選取會先保存列快照，再關閉子層同根層彈出表面。關閉通知先於選取回呼執行。弱參照防止擁有者銷毀後仍然派發；關閉期間若重建清單，項目修訂編號會拒絕選取，即使列睇落一模一樣亦一樣。佈局、點陣圖同旗標更新唔會改變呢個結構項目修訂編號。

阻塞式 Material 選單先完成巢狀事件迴圈，並排程銷毀彈出視窗，之後先派發所選指令。子選單指令保留擁有其綁定嘅選單。派發使用仍存在嘅頂層呼叫視窗。自動插入嘅外觀指令，喺移除暫存選單項目之前，分別保留元素同弱錨點。

冇相符模型變體時，印表機選取保留目前印表機。取消未儲存預設對話框，會停止套用設定、重新分配列印板、修改已儲存映射同自動沖刷計算。

實體耗材列對應設定槽索引。選單回呼讀取目前映射，唔用列最初索引。刪除只解析一次目標、確認該目標；確認期間槽清單改變就中止。混合槽身分來自專案旗標，唔係可見實體列數。最後一列實體耗材繼續受保護。銷毀列期間，由父層負責兄弟控件清理，唔會由組合方塊再次排程銷毀同一批兄弟控件。

## 驗證同限制

`dropdown_lifecycle_tests` 將實際正式派發同組合方塊轉接器函式內容，配合確定性事件同生命週期替身編譯。涵蓋根／子選單順序、過期項目世代、只失效量度後仍有效嘅選取、停用列、無效列、關閉期間銷毀擁有者、子層關閉銷毀根層，以及選取銷毀自身彈出視窗。測試驗證回呼順序同擁有權決策，唔能夠代替原生 wxWidgets 後端互動。

`node --test ui-md3/tests/native-lifecycle.test.mjs` 提供補充原始碼合約同刻意負面變更。完整原生建置同真實互動證據，必須另外涵蓋 P1S／H2C 切換、重複選取、未修改同已修改預設、儲存／捨棄／取消結果，以及實體／混合耗材刪除。原始碼改動或確定性測試，唔會隱含證明執行期間根因或成功畫面擷取。
