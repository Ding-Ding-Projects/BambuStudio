# 準備邊欄標籤

準備邊欄有三個標籤用來製造打印機墨水、打印設定同埋打印板物件列表容易去尋找喺一個狹窄邊欄。

- **墨水**：打印機、床、長絲同埋 AMS 控制。長絲搜尋過濾材料行同埋保留佢嘅正則表達式構建器。
- **流程**：設定搜尋同埋完整打印設定樹。搜尋結果可以跳到一個設定而冇重新構建樹。
- **物件**：物件搜尋、打印板同埋物件列表同埋一個操控卡當一個有效選擇存在。

用指針或鍵盤選擇一個標籤。帶開始喺左邊，帶一個緊湊 128 DIP 軌、可以停靠到任何邊緣透過佢嘅上下文選單同埋儲存佢嘅排列。若果邊欄太狹窄針對每個標籤、用帶嘅溢出控制。選擇部分開始喺現有滾動區域嘅頂部。切換部分保留當前預設、長絲行、物件模型同埋選擇喺記憶中。

## 限制同埋失敗處理

流程設定樹可以係寬比預設邊欄。水平滾動條保留可用用於控制，唔能重流。操控卡只在一個有效物件選擇同埋 3D 視圖提供值時出現。一個標籤切換唔改動打印機設定或打印板數據。

呢個原始碼改動尚未通過託管構建或軟件包二進制佈置檢查。較早嘅用戶映像有冇驗證二進制身份。見[設計同埋驗證交接](../../../design/prepare-sidebar-tabs.md)用於要求嘅捕捉矩陣。
