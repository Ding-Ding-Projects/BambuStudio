# 趣味程度嘅預設值同已有偏好

英文同廣東話可以分開設定，兩者預設都係第 5 級。已儲存嘅值欠缺或者無效，就用編譯時定好嘅預設值。重設滑桿亦會用返同一個預設值。

已有嘅明確選擇會保留，包括特登揀嘅第 2 級。即使有效設定啱啱等於舊預設，遷移都唔會改寫，因為應用程式無法判斷呢個係咪使用者嘅選擇。超出 1 至 5 範圍嘅數值會照舊收窄至上下限。呼叫端明確提供嘅後備值亦會繼續生效。

`tests/personal_modes/funny_default_contract.mjs` 用 MSVC 編譯正式版本嘅常數同解析函式，檢查缺失或者無效嘅值、每一級明確設定、前後空白、超出範圍嘅輸入同明確提供嘅後備值。之後喺獨立副本將預設改返第 2 級，確認測試會失敗，再還原到通過測試嘅原始碼。wxWidgets 語言同點心測試亦會直接檢查正確預設值，避免兩邊同時錯都照樣過關。
