# 旁白：逐段播放、事件同語音揀選

旁白預設關閉，要喺偏好設定 ▸ 其他 自己開。開咗之後，打印機同軟件嘅事件會用你揀嘅語言讀出嚟：英文、廣東話，或者兩樣都讀（先英文、後廣東話，逐段依次播放，唔會重疊）。

## 會講啲咩

**打印機事件**（只喺狀態轉變嗰刻講，唔會每次更新都講）：開始打印、暫停、繼續、完成、失敗、取消、墨水用完、墨水機（AMS）出錯，同其他打印機錯誤。打開軟件嗰陣，舊嘅完成狀態或者一直存在嘅錯誤唔會即刻讀出。

**軟件事件**：切片完成（成批切片只喺最後一塊板完成時講一次）、切片失敗、匯出完成、有更新準備好、同埋任何錯誤通知。旁白只讀簡短摘要，**唔會讀出檔案路徑、檔案名稱、帳戶資料或者任何密碼**。

打印機門開關事件暫時未有：呢個版本嘅打印機資料冇門狀態欄位，程式入面已經預留咗位置。

## 語氣跟搞笑程度

每個事件都有三種語氣。搞笑程度 1 至 2 用平實講法，3 用友善講法，4 至 5 用輕鬆搞笑講法。英文同廣東話各自跟自己嘅搞笑程度。無論邊種語氣，事實都一樣；錯誤提示一定會講明出咗咩事同點樣處理。

## 三條獨立軌道

事件分三條軌道：**打印機**、**軟件**、**輔助**（語音試聽同墨水掃描器）。每條軌道有自己嘅開關，主開關開咗之後預設全部開啟。軌道各自排隊、各自計冷卻時間，所以一條軌道嘅事件唔會取代或者拖慢第條。錯誤永遠優先，亦唔會被取代。舊式 `say()` 同 `say_now()` 已經淘汰，墨水掃描器而家跟「旁白語言」設定，而唔係介面語言。

## 靜音時段同專注輔助

| 情況 | 結果 |
| --- | --- |
| 開咗「靜音旁白」、有螢幕閱讀器喺度運作，或者喺你設定嘅靜音時段（可以跨午夜，例如 22:00 至 07:00） | 完全靜音，排緊隊嘅語音都會取消 |
| Windows 專注輔助、全螢幕軟件或者簡報模式，而且開咗「遵守專注輔助」 | 只讀錯誤，其他事件會被丟棄 |
| 其他情況 | 正常 |

Windows 冇分「只限優先」同「只限鬧鐘」，所以兩種專注輔助模式一律當同一樣處理。你自己撳「試聽」，主開關關咗都會讀，但喺完全靜音嗰陣唔會讀。

## 揀語音、試聽同 OneCore 語音

偏好設定會列出已安裝嘅傳統（SAPI）語音，英文同廣東話各自揀。每種語言都有「試聽」掣，用目前生效嘅語音讀一小段示範。語音下面會寫明：實際用緊邊個語音、你揀嘅語音係咪已經唔存在（揀選會保留）、同埋呢個語音係咪使用網上服務（離線時可能冇聲）。

Windows 嘅自然語音同 OneCore 語音（香港粵語語音通常喺度）係放喺另一個清單。程式會列出佢哋，**但呢個版本暫時未能用佢哋講嘢**，因為播放仍然經傳統 SAPI。如果部電腦嘅香港粵語語音只係喺嗰個清單，偏好設定會直接話你知，唔會假裝冇。

## 驗證

`node tests/narration/narration.test.mjs` 會編譯並執行純邏輯檢查（語氣、狀態轉變、去重、靜音時段、專注輔助、軌道獨立、語音分類），加 `--negative` 會喺暫存副本逐項破壞九條規則，每項都一定要失敗。`node tests/narration/narration_wiring.test.mjs` 檢查事件來源、設定、翻譯完整度同建置接線。喺 Windows 實機編譯後嘅行為仍未驗證。
