# 啟動本機模型投遞伺服器

本機啟動入口會拉取指定版本嘅容器映像、啟動現有 Compose 專案，再檢查服務健康狀態。
佢會保留 `drop-data` 儲存卷、排隊中嘅模型，唔會自動切片或者列印。

## 命令列啟動

Docker Desktop 運行期間，喺原始碼根目錄執行 `host.bat --detached`。
直接開啟 `host.bat` 會提供鍵盤模式選單。`host.bat --logs` 顯示即時狀態：
F 跟隨、P 暫停、R 更新，Q 或 Escape 離開畫面而保留容器運行。
目前只有一個服務：`lan-model-drop`。

入口會列出已經由主機成功測試嘅私人網絡網址。仍然要喺傳送模型嘅裝置測試所選網址，
主機自己連到唔代表另一部裝置可以穿過防火牆。入口唔會更改防火牆、作業系統設定或者其他容器。

## 由 Bambu Studio 連接

本機整合會喺 File 同 Preferences 可到達嘅邀請介面加入啟動伺服器及開啟網頁控制。
自動配對經過只限目前帳戶嘅本機具名管道，管道只傳送服務地址，
亦唔會取代已設定嘅遠端工作站。啟動途中更改嘅設定會優先保留。

## 復原及驗證狀態

Docker、Compose、映像拉取、連接埠、健康檢查或者網絡網址有問題時，入口會傳回非零結果。
修正列明嘅原因後再試，唔好刪除儲存卷嚟修理連線。

目前原始碼仍在整合。PowerShell 語法、Compose 服務解析及實際啟動失敗路徑已驗證；
原生管道、大小限制及取消操作測試已通過。完整程式編譯、實際配對、跨裝置連線、
互動日誌鍵盤操作、映像發佈同已安裝版本仍待驗證。便攜設定精靈尚未交付。
