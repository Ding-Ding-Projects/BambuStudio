# 打印完自動降溫

打印完嘅時候，Bambu Studio 可以將打印機所有風扇開到最盡，一路吹到部機涼到可以開門為止，最多吹五分鐘。預設係關閉，要你自己開。

## 降溫卡

張卡喺 Device 頁，**門鈴** 卡下面。

- **打印完之後幫打印機降溫** 係成個功能嘅開關。
- 開關下面嗰行字講而家咩情況：未開、未連接打印機、準備好、降溫緊（有熱床同機艙溫度，同埋距離時限仲有幾耐）、已經涼咗，或者去到五分鐘時限停咗。

個開關記喺應用程式設定（`print_cooldown_enabled`），對 Device 頁揀咗嗰部打印機生效。

## 打印完之後會發生咩事

1. 揀咗嗰部打印機嘅狀態由打印緊變成完成、失敗或者停止。
2. 如果熱床高過 40 °C，或者（部機有報機艙溫度嘅話）機艙高過 40 °C，Bambu Studio 會送出 `M106 P1 S255`、`M106 P2 S255` 同 `M106 P3 S255`：模型冷卻風扇、輔助風扇同機艙風扇全部開盡。部機冇其中一把風扇就會當嗰行冇到。
3. 熱床同機艙都跌到 40 °C 或以下，就用 `M106 P1 S0`、`M106 P2 S0` 同 `M106 P3 S0` 熄返啲風扇。
4. 風扇開咗五分鐘都未涼到，照樣熄風扇，張卡會講部機可能仲暖。

如果打印完嗰陣部機已經夠涼，就唔會開風扇。

## 限制同出事情況

- 指令係 Bambu Studio 自己送嘅，所以由打印完到熄風扇為止，佢要一直開住，仲要揀住同連住部打印機。呢個功能唔會改切片檔；由第二部裝置送嘅打印，要呢部 Bambu Studio 喺打印完嗰陣睇住部機先會降溫。
- 只有今次開機期間見過佢打印緊嘅打印先會觸發。開 Bambu Studio 嗰陣部機一早印完，就乜都唔做。
- 風扇吹緊嗰陣，如果 Bambu Studio 閂咗、斷咗線，或者你揀咗第二部打印機，佢就熄唔到啲風扇。喺打印機度自己熄，或者開始下一個打印，新打印會自己設定風扇。
- 降溫期間開始新打印，風扇就交返俾新打印，Bambu Studio 唔會再為舊嗰個送任何指令。
- 降溫期間熄個開關，風扇即刻熄。
- 唔會檢查噴嘴溫度。40 °C 同五分鐘都係固定嘅。
- 部打印機鎖咗風扇控制嘅話，風扇唔會郁，張卡會講明。

## 保安

指令行打印機同 Bambu Studio 本身條連線送出，唔會送去第二度，亦都唔會喺打印機度儲任何新設定。

## 驗證

`tests/print_cooldown.test.mjs` 會編譯同執行 `tests/print_cooldown_test.cpp`，檢查狀態同溫度規則、風扇 G-code、正常降溫、五分鐘時限、本身已經夠涼、開關未開或者中途熄、新打印接手，同埋轉打印機。張卡係喺 build 好嘅應用程式度影低嘅。未喺真打印機度行過降溫。
