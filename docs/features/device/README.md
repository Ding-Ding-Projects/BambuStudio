# Device features

- [LAN printer farm](farm-lan.md): device inventory, selection, local sending, and task results.
- [Door chimes](door-chime.md): the printer plays a chime when its door opens and another when it closes, picked and previewed on the Device page.
- [Printer melodies](printer-melody.md): compose a tune the printer plays through M1006, preview it, play it on the printer or add it to the start or end G-code.
- [Live charts](live-charts.md): nozzle, bed and chamber temperatures over time, as the printer sends them, with targets, candles, a keyboard crosshair and CSV.
- [Live printer readings and printer options](live-readings.md): the Wi-Fi, air duct, door detection setting and nozzle chips on the print monitor, and when the Print Options and Safety Options entries appear.
- [Local printer status API](status-api.md): an off-by-default, loopback-only, read-only web interface with a bearer token for the printer list and the beta door state ([Postman collection](status-api.postman_collection.json)).

The local printer status API is the only HTTP API in this category; the other articles describe features with no HTTP API.
