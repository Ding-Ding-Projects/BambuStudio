# 區域網絡打印機群組

多裝置選擇器、群組網格、寄送對話框同埋任務檢視用一個由打印機裝置 ID 作為鍵嘅清單。佢將帳戶裝置同埋發現嘅同已儲存嘅本機裝置結合。配對嘅本機裝置當相同 ID 出現喺兩個源時優先、因為佢嘅地址同埋存取碼係直接打印所需。已記憶嘅裝置喺離線時保持可見。選擇限制最多六個不同嘅 ID。

選擇器會保留雙噴嘴打印機可見、並附帶解釋多裝置寄送唔支援佢。區域網絡打印機使用現存本機配對同埋存取碼路徑。寄送前、對話框檢查配對、本機地址同埋一個已加載嘅網絡模組具有直接區域網絡打印支援。佢解釋缺少嘅需求並唔排隊無法使用嘅工作。

直接區域網絡工作帶着打印機地址、存取碼、用戶名同埋設定嘅 FTP 同埋 MQTT 傳輸設定。任務管理員序列化區域網絡傳輸並喺每次傳輸前檢查取消。每個任務保留佢自己嘅完成、取消或失敗狀態。帳戶連接嘅打印機通過現存服務路徑繼續。純區域網絡打印機絕唔會靜默落後到嗰個路徑。

獨立嘅 `farm_device_policy_tests` 目標執行 ID 去重複、離線清單、六裝置選擇上限、區域網絡就緒原因、取消、序列化分發同埋獨立嘅成功同埋失敗結果同埋一個模擬傳輸。佢唔建立同實際打印機韌體或網絡條件嘅相容性。實際配對打印機係該驗證必需嘅。
