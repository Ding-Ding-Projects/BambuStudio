# 逐個冷拉 H2C 噴嘴架嘅熱端

連接已經閒置嘅 H2C，喺「設備」嘅「熱端及噴嘴架」揀「逐個冷拉架上噴嘴」。網頁版設備面板就喺「熱端」分頁揀同一個操作。嚮導按當前讀到嘅序號排列熱端。如果其中一個架上熱端已經裝喺右工具頭，就先處理嗰個。左邊嘅固定熱端唔會加入呢個次序。

1. 將雙手同工具移離機艙，確認「取出噴嘴」。等嚮導核實指定嘅熱端已經裝喺右工具頭。
2. 喺 H2C 觸控屏打開「工具箱」嘅「噴嘴冷拉保養」，揀右熱端同相應物料。按屏幕指示拆開 PTFE 管，再用手插入耗材。原廠指引用之前用過嘅耗材；只有原廠確認嗰款清潔耗材適用於所選程序先好用。
3. 加熱、擠出同降溫期間跟觸控屏提示。等到有指示先抽出耗材，裝返 PTFE 管，再檢查結果。嚮導要先讀到冷拉狀態，再讀到閒置，先會容許確認。如果取消咗或者保養失敗，就關閉嚮導。
4. 確認成功之後，再將雙手同工具移離機艙，揀「放回噴嘴」。嚮導會核對原位嘅熱端序號，再顯示下一個。

隨時可以關閉嚮導。打印機已經接受嘅動作可能繼續，請喺觸控屏檢查或者停止。斷線、資料過時、熱端身份改變、有其他工作或者等候逾時，嚮導就會停止。韌體要提供新近嘅佔位同序號資料先可以開展。重新連線之後唔會自動繼續。

提取同放回熱端用原有噴嘴架交換指令。韌體有冷拉狀態回報，但未有文件列出遙距啟動冷拉嘅指令。狀態回報分唔到成功同取消，所以最後由操作員喺觸控屏核實結果。
