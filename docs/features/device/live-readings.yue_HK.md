# 打印機即時讀數同打印機選項

設備分頁嘅打印監控，喺 **控制** 標題下面有一行唯讀晶片，顯示打印機有回報、而應用程式已經解析嘅讀數。同時，打印機回報支援嘅每一個「打印選項」同「安全選項」設定，都會提供入口。呢篇文章列出顯示咩、每個數值來自邊度，以及幾時會隱藏。

喺真實打印機上嘅執行行為仍未驗證。以下規則只係對照原始碼同標頭層級測試檢查過；呢啲晶片同改動咗嘅入口未喺實機上操作過。

## 即時讀數列

每粒晶片有一個標籤同一個數值。只有數值有回報而且合理，晶片先會出現；如果打印機一項都冇回報，成條列都唔會顯示。完全冇猜測、預設值或者佔位數值。

| 晶片 | 數值 | 來源 | 隱藏條件 |
| --- | --- | --- | --- |
| Wi-Fi 訊號 | 例如 `-61 dBm，中等` | 列印狀態訊息入面嘅 `wifi_signal`，存喺 `MachineObject::wifi_signal`（`DeviceManager.cpp` 訊號區塊） | 文字係空、格式錯誤，或者超出 -120 至 0 dBm |
| 風道 | 冷卻、加熱、排氣或者全力冷卻 | `device.airduct.modeCur`，由 `DevFan::ParseV3_0` 解析入 `AirDuctData::curren_mode` | 打印機冇回報風道，或者模式唔係上面四個之一 |
| 開門偵測 | 關閉、警告或者暫停打印 | 開門時嘅設定反應，即係 `xcam_door_open_check`（`MachineObject::parse_new_info` 入面設定位元 20 至 21） | 打印機冇回報支援開門檢查（功能位元 12） |
| 噴嘴（雙噴嘴型號會標示右或者左） | 例如 `0.4 mm，硬化鋼`；只有非標準流量類型先會加上 `高流量` 等 | `DevNozzleSystem` 入面每個擠出機嘅噴嘴（`DevNozzle::GetNozzleDiameter`、`GetNozzleType`、`GetNozzleFlowType`） | 直徑係零、物料未知，或者噴嘴被標示為不可靠、未知或者異常 |

訊號強弱字眼只係顯示用嘅經驗法則，唔係通訊協定數值：-60 dBm 或者更強係「強」，到 -75 dBm 係「中等」，再弱就係「弱」。

**唔會顯示門嘅狀態。** 應用程式冇解析打印機即時嘅開門或者關門數值，所以呢條列冇門感應器讀數。「開門偵測」晶片顯示嘅係開門時打印機點樣反應嘅設定，標籤都有咁講。想顯示即時門狀態，要先喺通訊協定入面搵出對應欄位並解析。

**腔室溫度、噴嘴同熱床溫度、風扇速度、速度級別、腔室燈、儲存狀態、AMS 濕度同乾燥** 喺設備分頁其他位置已經有顯示，所以唔會喺度重複。腔室風扇速度喺冇回報時會解析成預設嘅零，分唔到係未回報定係風扇停咗，所以唔提供做晶片。

每粒晶片都唔可以取得焦點，名稱同提示都係「標籤：數值」，跟隨淺色同深色主題，窄監控會自動換行，DPI 或者主題改變時會重新量度。字串已經本地化，粵語條目喺 `bbl/i18n/yue_HK`。

## 打印選項同安全選項入口

**打印選項** 按鈕以前只會喺首層檢查、AI 監控、打印板標記偵測同自動失步恢復出現。如果打印機只支援其他選項，例如耗材纏結偵測、噴嘴結塊偵測、異物或者位移檢查、打印完結空氣淨化、打印狀態快照或者儲存到儲存裝置，就冇辦法打開對話框。而家只要打印機回報支援對話框能夠顯示嘅任何一個選項，按鈕就會出現；對話框入面每一行仍然按自己嘅能力判斷，所以打印機唔支援嘅選項唔會出現失效控制項。呢個適用於所有型號，包括 H2C。

**安全選項** 對話框載有開門檢查同閒置加熱保護。以前只有打印機設定啟用佢、而且回報支援開門檢查嘅型號先去到。H2D、H2S 同 H2C 嘅設定冇啟用，所以呢啲打印機可以回報（功能位元 62）嘅閒置加熱保護就去唔到。而家只要設定嘅開門檢查路徑適用，或者打印機回報閒置加熱保護，入口就會出現。未啟用安全對話框嘅型號，開門檢查繼續留喺打印選項，安全對話框唔會再重複。

共用規則喺 `src/slic3r/GUI/DeviceLiveReadings.hpp`，狀態面板同安全對話框都有用。

## 失敗情況

- `wifi_signal` 格式錯誤或者風道編號未知，會隱藏晶片，而唔係顯示錯誤數值。
- 打印機唔再回報嘅選項，會喺下一次狀態更新時從打印選項消失。
- 如果狀態訊息先於噴嘴資料到達，噴嘴晶片會喺帶有資料嘅更新出現。

## 安全同私隱

讀數只留喺應用程式入面。除咗現有嘅狀態處理，唔會傳送、記錄或者儲存任何嘢。呢條列係唯讀，唔會向打印機發出任何指令。

## 驗證

- `node --test tests/device_live_readings.test.mjs` 會將真實標頭編譯成測試程式，並且將實際接線綁定到已解析嘅欄位。加 `--negative` 可以確認移除 Wi-Fi 接線之後測試會失敗。
- `python bbl/i18n/yue_HK/compile_translation.py --check` 會喺新增字串之後驗證目錄。
- 未驗證：呢個改動嘅原生建置、喺真實 H2C 或者其他打印機上嘅晶片列同入口按鈕，以及新晶片列嘅截圖。
