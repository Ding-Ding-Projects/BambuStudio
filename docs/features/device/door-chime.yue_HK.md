# 門鈴

打印機門打開嘅時候，蜂鳴器會播一段短鈴聲；門關上嘅時候再播另一段。兩段鈴聲都喺 Device 頁揀，撳 **預覽** 就喺打印機度聽，一個掣就開關成個功能。預設係關閉，要你自己開。

## 門鈴卡

張卡喺 Device 頁 **移動** 卡下面。

- **打印機門開或者關嘅時候響一下**：開關呢個功能。提示入面標明係測試版，因為門嘅讀數嚟自打印機廠冇公開說明嘅狀態位元。
- **門打開嘅時候** 同 **門關上嘅時候**：各自揀一款鈴聲。每個列表最尾都有 **靜音**，可以淨係其中一邊響。
- 每個列表旁邊嘅 **預覽**：即刻喺打印機播嗰邊揀咗嘅鈴聲。任何已連接、冇打印緊嘅打印機都用得，有冇門感應器都得；揀咗 **靜音** 就會停用。
- 列表下面嗰行話你知而家會點：未連接打印機、冇門感應器（淨係預覽會響）、打印緊所以等緊，或者已經準備好。

開關同兩邊嘅選擇都記喺程式設定（`door_chime_enabled`、`door_chime_open`、`door_chime_close`），適用於 Device 頁選咗嘅打印機。

## 鈴聲

| 開門 | 音符 | 關門 | 音符 |
| --- | --- | --- | --- |
| 叮噹（預設） | E5 再 C5，兩下嘅門鈴 | 噹叮（預設） | C5 再 E5 |
| 歡迎上揚 | C5、E5、G5、C6 | 下行琶音 | C6、G5、E5、C5 |
| 店舖門鈴 | 兩下快嘅 E6 | 西敏寺鐘聲收尾句 | G4、D5、E5、C5 |
| 西敏寺鐘聲第一句 | E5、C5、D5、G4 | 早唞 | E5、D5、C5 |
| 哈囉啾啾 | G5、C6 | 輕輕扣門 | C4，再 G3 |
| 木琴上行 | C5、D5、E5、G5、A5 | 敲兩下 | 兩下短嘅 C5 |
| 一聲叮 | C6 | 拜拜啾啾 | C6、G5 |
| 靜音 | 冇聲 | 靜音 | 冇聲 |

每個音符都用晒蜂鳴器三個聲部一齊播，同潤滑旋律一樣。西敏寺鐘聲兩句嚟自公有領域嘅 Westminster Quarters。

## 幾時會響

程式每秒睇兩次所選打印機嘅門讀數。由關變開就送開門鈴聲，由開變關就送關門鈴聲。程式連上一部打印機之後、或者你揀另一部打印機之後，第一個讀數淨係記低狀態，所以本身已經開咗嘅門唔會響。未報告門狀態嘅打印機會跳過，等佢報咗先算。

鈴聲係當即時指令送出，同 [旋律製作器](printer-melody.md) 入面 **喺打印機播放** 送旋律一樣：

```
M17
M400 S1
M1006 S1
M1006 A76 B25 L100 C76 D25 M100 E76 F25 N100
M1006 A72 B35 L100 C72 D35 M100 E72 F35 N100
M1006 W
M18
```

播之前會開馬達，播完會放鬆（`M18`），`M400` 會等動作佇列做完。呢啲嘢絕對唔可以喺打印途中發生，所以打印緊、暫停、準備緊或者切片緊嘅時候，鈴聲會等，嗰陣開門唔會響。響完之後馬達會放鬆，所以之後喺 Device 頁點動，可能要先歸零。

## 要求同限制

- 門讀數只係喺會報告門開偵測嘅打印機先有，例如 Bambu Lab H2C。其他打印機淨係 **預覽** 會響。
- 門讀數跟住打印機嘅狀態報告一齊嚟，所以鈴聲可能會遲門一陣。
- 只會睇住 Device 頁選咗嗰部打印機。
