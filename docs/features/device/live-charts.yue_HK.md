# 即時圖表

**表面**：設備頁溫度下面嘅**即時圖表**按鈕、檔案 > 即時圖表、指令面板（`Ctrl+Shift+F`，打「Live charts」、「AMS humidity chart」或者「Part cooling fan chart」），或者全部功能頁 → `LiveChartsPanel`（`src/slic3r/GUI/LiveCharts/LiveChartsPanel.{hpp,cpp}`），係本機工具分頁入面嘅一頁。規則喺冇 wxWidgets 嘅 `LiveSeries` 模組度（`src/slic3r/GUI/LiveCharts/LiveSeries.{hpp,cpp}`）。

設計：[design/local-tools-2026-11](../../../design/local-tools-2026-11/README.md)，Liveline 板。

設備頁揀咗嗰部打印機嘅噴嘴、熱床同機箱溫度、每部有報濕度嘅墨水機入面嘅濕度，同部件冷卻風扇隨時間嘅變化，完全照打印機送嚟嘅樣。

## 讀數由邊度嚟

由程式一開始，就有個記錄器每秒睇兩次揀咗嗰部打印機，唔理你開緊邊一頁，只有打印機推送咗新報告先會保留一個讀數。你喺本機工具睇圖表、設備頁收埋咗嘅時候，圖表都會繼續填。讀數永遠唔會作出嚟：打印機超過 10 秒冇報告，條線就會斷開，個空隙會保持係空隙。打印機報告咗機箱溫度之後先會畫機箱；之前會寫**冇感應器報告**。

- **墨水機濕度**：每部有報濕度嘅墨水機一個系列。送百分比嘅墨水機（AMS 2 Pro、AMS HT）用百分比畫；淨係送等級嘅（第一代墨水機）就畫佢由 1（濕）到 5（乾）嘅等級，兩種刻度永遠唔會撈埋一齊。兩樣都唔報嘅，例如 AMS Lite，就唔會畫。識烘乾嘅墨水機仲會講佢係咪烘緊同埋仲有幾耐。
- **部件冷卻風扇**：設備頁顯示嘅百分比，由打印機報告嘅風扇速度計出嚟。

讀數只係保留喺今次使用期間，每部打印機分開：每個系列最多 14,400 個，即係每秒一個報告大約 4 個鐘。除非你儲存，否則永遠唔會寫落磁碟。

## 呢一頁

- **而家**：最新嘅噴嘴、熱床同機箱讀數同佢哋嘅目標，同埋今次使用期間收到幾多個讀數。
- **系列**：噴嘴、熱床、機箱、墨水機濕度或者部件冷卻風扇。有兩部或以上墨水機報濕度嘅時候，**墨水機**可以揀睇邊部。
- **時間範圍**：1 分鐘、5 分鐘、15 分鐘或者 1 個鐘，結束喺而家。
- **檢視**：**線**（每個讀數，除咗空隙之外都連埋一齊）或者**蠟燭**（每分鐘一枝：第一個、最高、最低同最後一個讀數；向上嘅蠟燭用主題色，向下嘅用錯誤色，仲喺度形成緊嘅嗰枝係空心）。
- **暫停**（`Space`）會凍結圖表；讀數照樣入嚟，狀態會講有幾多個。**繼續**會追返。
- 大數值、用文字講嘅趨勢、用文字講嘅走勢，同讀數來源嘅狀態：**即時**、**等緊**（第一個讀數之前）、**停咗**（超過 10 秒冇讀數，連埋最後一個嘅時間，同喺讀數停咗嗰度畫一條虛線）、**離線**，或者冇墨水機報濕度、又或者未有機箱溫度嘅時候顯示**冇嘢可以畫**。
- **細圖表**：一眼睇晒墨水機濕度同部件冷卻風扇，時間範圍同大圖表一樣，有數值、一個字講趨勢，識烘乾嘅墨水機仲會講係咪烘緊。撳一個，或者令佢有焦點再撳 `Enter` 或者 `Space`，就會喺大圖表顯示。

趨勢會將最新讀數同大約一分鐘之前嗰個比較：如果目標大過零，而讀數喺目標 1.5 °C 或者 1 % 之內，就係**維持喺**目標附近；唔係就係升或者跌超過半個單位嘅**上升**或者**下降**，或者**平穩**，連埋變化同用咗幾多秒。濕度同風扇冇目標，所以永遠唔會係維持。

數值範圍會順滑咁靠向新讀數，最新嗰點會輕輕跳動。百分比喺 0 到 100 之間畫，等級喺 1 到 5 之間畫。開咗減少動畫（偏好設定嘅介面動畫，或者 Windows 設定）就會直接跳過去；每個數值、趨勢同狀態都一樣。

## 圖表選項

會記低落程式設定，下次照用：

| 選項 | 預設 | 做乜 |
| --- | --- | --- |
| **目標線** | 開 | 目標溫度以虛線做參考線 |
| **走勢箭咀** | 開 | 最新嗰點旁邊一個箭咀，講過去十秒點行：上用主題色，落用錯誤色，穩定用淡色。斜度跟住螢幕上條線，最斜都唔會超過 60 度。同一個走勢亦會喺趨勢旁邊用文字講（「上緊，每秒 +0.52 °C」） |
| **創新高時噴粒子** | 關 | 讀數比今次使用期間之前所有讀數高最少半個單位嘅時候，噴一陣粒子，最多每 5 秒一次。減少動畫時唔會噴粒子；會改為顯示一個靜止嘅**新高**標示 3 秒 |
| **時鐘** | 跟 Windows 時間格式 | 時間軸、十字線下面同停咗嘅提示用 **24 小時制**（13:05）或者 **12 小時制**（下午 1:05）。你未揀之前，會跟 Windows 嘅短時間格式 |

**預覽減少動畫**會喺開住嗰陣，俾你睇減少動畫時呢頁係點；唔會記低。**介面動畫**會打開偏好設定嘅動畫設定。

走勢係最新讀數之前十秒內嘅讀數嘅最小平方斜率：要有兩個讀數、橫跨最少兩秒；嗰個斜率喺覆蓋嘅秒數入面令數值變多過 0.3，就係**上**或者**落**，唔係就係**穩定**。

## 讀數值

指住圖表，或者令佢有焦點（撳一下，或者 `Tab`）再用以下按鍵：

| 按鍵 | 動作 |
| --- | --- |
| `Left`、`Right` | 十字線移一個讀數 |
| `Home`、`End` | 顯示緊嘅第一個同最後一個讀數 |
| `Esc` | 收起十字線 |
| `Space` | 暫停或者繼續 |
| `Ctrl+C` | 複製十字線下面嘅數值 |
| `Ctrl+S` | 將顯示緊嘅讀數儲存做 CSV |
| `F1` | 呢篇文章 |

圖表下面嗰行會顯示十字線下面嘅時間同數值。螢幕閱讀器每 10 秒會經圖表嘅名稱聽到最新數值、趨勢同走勢，每個細圖表嘅名稱亦會講佢嘅標題、數值同趨勢。喺圖表撳右鍵，或者撳 `Shift+F10`，會有暫停更新、複製十字線下面嘅數值、將顯示緊嘅讀數儲存做 CSV、編輯外觀（包括動畫同過渡），同解釋呢個圖表。

## CSV

`time,series,value`，顯示緊嘅每個讀數一行，按時間排，時間係 UTC（ISO 8601，有毫秒），數值去到一個小數位。濕度（墨水機同 `%` 或者等級）同風扇（`%`）嘅系列名稱會講埋單位。

## 檢查

`tests/live_series.test.mjs` 會編譯 `tests/live_series_test.cpp`：唔係有限數或者次序唔啱嘅讀數會被拒絕、時間範圍、空隙、趨勢文字、蠟燭、讀數來源狀態、十字線、數值範圍同 CSV，跟住係有界限嘅範圍、走勢同箭咀角度、有門檻同冷卻時間嘅新高、粒子（同一個種子會噴出同一陣）、12 小時制時鐘嘅午夜同中午、Windows 時間格式同記低咗嘅選項。三個反向建置必須失敗：一個跨過空隙連線，一個每個新高都噴而冇冷卻時間，一個喺 12 小時制將午夜顯示做 0。

`tests/live_charts_wiring.test.mjs` 會檢查原始碼：取樣同程式一齊開始、程式關嘅時候停；濕度按每部墨水機記錄而唔會撈亂刻度；風扇同設備頁顯示嘅一樣；選項用佢哋嘅鍵讀同儲存；揀咗嘅時鐘用喺時間軸、十字線下面同停咗嘅提示；減少動畫時永遠唔會噴粒子；選單同全部功能嘅入口開返佢哋講嘅嘢。每個檢查喺壞咗嘅原始碼副本上都會失敗。
