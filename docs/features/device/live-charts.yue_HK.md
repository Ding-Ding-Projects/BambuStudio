# 即時圖表

**表面**：設備頁溫度下面嘅**即時圖表**按鈕、檔案 > 即時圖表、指令面板（`Ctrl+Shift+F`，打「Live charts」），或者全部功能頁 → `LiveChartsPanel`（`src/slic3r/GUI/LiveCharts/LiveChartsPanel.{hpp,cpp}`），係本機工具分頁入面嘅一頁。規則喺冇 wxWidgets 嘅 `LiveSeries` 模組度（`src/slic3r/GUI/LiveCharts/LiveSeries.{hpp,cpp}`）。

設計：[design/local-tools-2026-11](../../../design/local-tools-2026-11/README.md)，Liveline 板。

設備頁揀咗嗰部打印機嘅噴嘴、熱床同機箱溫度隨時間嘅變化，完全照打印機送嚟嘅樣。

## 讀數由邊度嚟

設備頁每次更新都會交俾一個記錄器，只有打印機推送咗新報告先會保留一個讀數。讀數永遠唔會作出嚟：打印機超過 10 秒冇報告，條線就會斷開，個空隙會保持係空隙。打印機報告咗機箱溫度之後先會畫機箱；之前會寫**冇感應器報告**。

讀數只係保留喺今次使用期間，每部打印機分開：每個系列最多 14,400 個，即係每秒一個報告大約 4 個鐘。除非你儲存，否則永遠唔會寫落磁碟。

## 呢一頁

- **而家**：最新嘅噴嘴、熱床同機箱讀數同佢哋嘅目標，同埋今次使用期間收到幾多個讀數。
- **系列**：噴嘴、熱床或者機箱。
- **時間範圍**：1 分鐘、5 分鐘、15 分鐘或者 1 個鐘，結束喺而家。
- **檢視**：**線**（每個讀數，除咗空隙之外都連埋一齊）或者**蠟燭**（每分鐘一枝：第一個、最高、最低同最後一個讀數；向上嘅蠟燭用主題色，向下嘅用錯誤色，仲喺度形成緊嘅嗰枝係空心）。
- **目標線**：目標溫度以虛線做參考線。
- **暫停**（`Space`）會凍結圖表；讀數照樣入嚟，狀態會講有幾多個。**繼續**會追返。
- 大數值、用文字講嘅趨勢，同讀數來源嘅狀態：**即時**、**等緊**（第一個讀數之前）、**停咗**（超過 10 秒冇讀數，連埋最後一個嘅時間）或者**離線**。

趨勢會將最新讀數同大約一分鐘之前嗰個比較：如果目標大過零，而讀數喺目標 1.5 °C 或者 1 % 之內，就係**維持喺**目標附近；唔係就係升或者跌超過半度嘅**上升**或者**下降**，或者**平穩**，連埋變化同用咗幾多秒。

數值範圍會順滑咁靠向新讀數，最新嗰點會輕輕跳動。開咗減少動畫（偏好設定嘅介面動態，或者 Windows 設定）就會直接跳過去；每個數值、趨勢同狀態都一樣。

## 讀數值

指住圖表，或者令佢有焦點（撳一下，或者 `Tab`）再用以下按鍵：

| 按鍵 | 動作 |
| --- | --- |
| `Left`、`Right` | 十字線移一個讀數 |
| `Home`、`End` | 顯示緊嘅第一個同最後一個讀數 |
| `Esc` | 收起十字線 |
| `Space` | 暫停或者繼續 |
| `Ctrl+C` | 複製十字線下面嘅數值 |
| `Ctrl+S` | 將顯示緊嘅讀數儲存做 CSV |
| `F1` | 呢篇文章 |

圖表下面嗰行會顯示十字線下面嘅時間同數值。螢幕閱讀器每 10 秒會經圖表嘅名稱聽到最新數值同趨勢。喺圖表撳右鍵，或者撳 `Shift+F10`，會有暫停更新、複製十字線下面嘅數值、將顯示緊嘅讀數儲存做 CSV，同解釋呢個圖表。

## CSV

`time,series,value`，顯示緊嘅每個讀數一行，按時間排，時間係 UTC（ISO 8601，有毫秒），數值去到一個小數位。

## 檢查

`tests/live_series.test.mjs` 會編譯 `tests/live_series_test.cpp`：唔係有限數或者次序唔啱嘅讀數會被拒絕、時間範圍、空隙、趨勢文字、蠟燭、讀數來源狀態、十字線、數值範圍同 CSV。佢嘅反向建置會跨過空隙連線，必須失敗。
