# 打印機旋律

**檔案 ▸ 旋律製作器…** 可以編寫一段打印機播放嘅旋律、喺呢部電腦預覽、喺已連接嘅打印機播放、複製佢嘅 G-code、放入打印機預設嘅開始或者結束 G-code，以及儲存做檔案。Bambu Lab 打印機嘅開機同完成音樂都係同一個方法播放，所以原廠旋律已經內置做範本。

## 打印機點樣播放旋律

原廠開始同結束 G-code 範本用以下呢類行播放音樂：

```
M17
M400 S1
M1006 S1
M1006 A0 B10 L100 C37 D10 M60 E37 F10 N60
M1006 A46 B10 L100 C43 D10 M70 E39 F10 N100
M1006 W
M18
```

對照原廠旋律嚟睇，每行 `M1006` 係一個時間步驟，有三個聲部：`A`、`B` 同 `L` 係第一聲部嘅音符、以 tick 計嘅時值同音量（0 到 100），`C`、`D` 同 `M` 係第二聲部，`E`、`F` 同 `N` 係第三聲部。音符 0 代表該聲部靜音。`M1006 S1` 開始一段序列，`M1006 W` 等佢播完；之前會啟用馬達（`M17`），之後釋放（`M18`），顯示聲音來自馬達。呢個指令冇任何文件：音符編號（MIDI 式，69 係 440 Hz 嘅 A4）同 tick 長度都係推斷，所以 tick 長度係旋律嘅一個設定，只影響預覽。請調校到預覽同打印機嘅節奏一樣。

## 對話框

- **名稱**同**Tick 長度（毫秒，只影響預覽）**。Tick 長度會喺工作階段之間記住。
- **由呢個開始**：空白旋律、原廠 Bambu Lab X1、A1、A1 mini 同 H2D 嘅開始同完成旋律，或者 C 大調音階。
- **步驟**：每個時間步驟一行，三個聲部各有音符、時值同音量。音符寫法係一個字母、可選嘅 `#` 或者 `b`，再加八度，例如 `C4` 或者 `F#3`；留空即係靜音。讀唔到嘅值會連同原因被拒絕，儲存格回復之前嘅值。
- **加入步驟**、**複製**、**上移**、**下移**同**刪除步驟**作用於選取嘅行。
- **快速記譜**用單聲部旋律取代全部步驟：音符後面可以加 `/tick 數`，`r` 代表休止，例如 `c4 e4/5 g4/20 r c5`。
- 狀態行顯示步驟數目同以目前 tick 長度計嘅長度，或者旋律嘅第一個問題。

頁腳動作：

- **預覽**用方波喺呢部電腦播放旋律。音色唔係打印機嘅；只係顯示旋律嘅形狀。
- **喺打印機播放**將 M1006 區塊經設備頁面自己指令用嘅同一條路徑傳送去設備頁面選取嘅打印機。冇選取打印機、打印機未連接或者打印緊嘅時候會拒絕，傳送後會有通知確認。
- **複製 G-code** 將區塊放入剪貼簿。
- **加入開始 G-code** 同**加入結束 G-code** 將區塊連同 `;===== melody start =====` 同 `;===== melody end =====` 標記寫入打印機預設嘅開始或者結束 G-code。之前嘅旋律區塊會被取代，否則會加到結尾。會先執行慣常嘅自訂 G-code 驗證，而且要儲存預設先會保留改動。
- **儲存**同**開啟**將旋律儲存做 JSON 檔案，預設喺應用程式資料目錄嘅 `melodies` 資料夾；最後用過嘅資料夾會記住。

一段旋律最多 256 個步驟，音符最高 127，時值最長 255 tick，音量最高 100。

## 快速開印模式

[快速開印模式](../windows/express-print-mode.md)會跳過原廠開機音樂。經製作器加入嘅旋律喺自己嘅標記區塊入面，永遠唔會被跳過，因為係用戶放入去嘅。
