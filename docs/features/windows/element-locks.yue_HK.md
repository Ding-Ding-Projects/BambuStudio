# 元素鎖同解鎖階梯

**表面**：喺任何有「編輯外觀」嘅元素撳右鍵，揀**鎖住呢個元素...**（鎖咗嘅就係**解鎖呢個元素...**）；物件嘅選單（喺物件清單或者 3D 檢視）同墨水行嘅選單入面同一個項目，會鎖住嗰一件物件或者嗰一行；檔案 > 元素鎖會列出每個鎖；仲有指令面板（`Ctrl+Shift+F`，打「Element locks」）同全部功能頁 → `src/slic3r/GUI/ElementLocks/LockService.{hpp,cpp}`。規則喺冇 wxWidgets 嘅 `LockModel` 度（`src/slic3r/GUI/ElementLocks/LockModel.{hpp,cpp}`）。

鎖係用嚟防止視窗某部分因為手快或者一時衝動而被改，例如考試期間嘅搞笑程度，或者小朋友唔應該郁嘅設定。佢唔係保安界線：任何可以改資料夾入面檔案嘅人都可以移除佢。

## 上鎖

**鎖住呢個元素...** 會問：

- **原因**，可選，會顯示畀遇到呢個鎖嘅人睇。
- 一個 4 至 32 個字元嘅**密碼**，要打兩次。

個鎖會記低你（你嘅 Windows 用戶名）同時間。密碼永遠唔會儲存：只會保留一個加咗鹽、重複 20,000 次嘅 SHA-256 雜湊值。

## 鎖會做乜

鎖住咗嘅元素唔理撳滑鼠、滑鼠滾輪同按鍵，入面嘅所有嘢都一樣。`Tab` 仍然可以跳過佢，佢嘅右鍵選單（滑鼠、選單鍵或者 `Shift+F10`）仍然會打開，入面有**解鎖呢個元素...**。試吓用佢會出一段短提示：鎖住咗乜、邊個鎖、點解，同埋撳右鍵就可以解鎖。

每個鎖住咗嘅元素右上角都有個細細嘅鎖標記，視窗移動、捲動或者改大細嘅時候會跟住佢走。撳個標記會顯示邊個鎖同點解，仲有**解鎖...**。之後先出現嘅元素（打開嘅對話框、新加嘅行）會喺一秒之內有標記。

## 清單入面嘅行

有兩種行係逐行鎖嘅，雖然佢哋清單入面每行都一樣：

- 側邊欄嘅**墨水行**（嗰行嘅 **...** 選單，**鎖住呢個元素...**）。佢嘅墨水選擇、顏色同噴嘴按鈕會唔再理你。佢嘅選單仍然會打開，入面有解鎖，鎖住嘅時候**刪除**同**合併到**會停用；喺其他地方刪佢（大量墨水操作、會刪走佢嘅 AMS 同步）都會被拒絕，並且出提示。鎖係跟行嘅號碼：刪咗前面一行，鎖就會留喺而家係嗰個號碼嘅行。
- **一件物件**（佢喺物件清單或者 3D 檢視嘅右鍵選單）。佢喺物件清單嘅行，圖示上會有個鎖。喺清單或者 3D 檢視撳佢會停低並出提示，撳右鍵就會出提示同**解鎖...**。佢唔會留喺選取入面：全選、選取框或者喺清單用鍵盤揀中佢，都會即刻放返佢出去，所以任何作用喺選取上面嘅嘢（移動、旋轉、縮放、刪除、佢嘅設定、佢嘅墨水）都掂唔到佢。**全部排列**會將佢留喺原位，其他物件圍住佢排；淨係排列佢嗰塊板同清空佢嗰塊板會被拒絕，**全部刪除**會停用直到佢解鎖。鎖係跟物件嘅名。佢前面嘅工具手柄照樣用得。

喺鎖住咗嘅行上面，滾輪同按鍵照常運作，所以清單可以捲動、3D 檢視可以縮放。喺其他地方開始嘅拖曳，喺鎖住咗嘅行上面放手都照樣會完結。

## 解鎖

**解鎖呢個元素...** 會顯示邊個鎖、幾時鎖同點解，然後問密碼。打錯兩次冇代價；連續第三次打錯開始，下一次要等：

| 連續打錯次數 | 下次可以試之前要等 |
| --- | --- |
| 1 或 2 | 唔使等 |
| 3 | 30 秒 |
| 4 | 2 分鐘 |
| 5 | 10 分鐘 |
| 6 或以上 | 1 個鐘 |

## 解鎖階梯

畀唔記得密碼嘅時候用。連續打錯三次之後會提供，或者喺**唔記得密碼？**度打開：

1. 等 1 分鐘。
2. 打鎖住咗嘅嘢嘅名（大細楷同空格唔緊要）。
3. 再等 5 分鐘。

之後個鎖就會解開。你關咗個視窗或者 Bambu Studio，階梯都會記住去到邊；個視窗開住嘅時候，等完就會自動行落一步。

## 每個鎖

檔案 > 元素鎖會列出每個鎖，連埋邊個、幾時同點解，每個旁邊都有**解鎖...**。

## 儲存嘅值

資料夾（`%APPDATA%\BambuStudio`）入面嘅 `element-locks.json`：每個鎖嘅元素 id、名稱、原因、邊個、幾時、鹽同雜湊值、連續打錯次數、等待時間，同埋階梯去到邊一步。

## 檢查

`tests/element_locks.test.mjs` 會編譯 `tests/element_locks_test.cpp`：被拒絕嘅密碼、同獨立計算比較嘅雜湊值、打錯密碼同之後嘅等待、階梯、儲存同載入。佢嘅反向建置只會雜湊一次而唔係 20,000 次，必須失敗。

`tests/element_locks_rows_wiring.test.mjs` 會檢查原始碼：撳鎖住咗嘅行會停低、撳右鍵會提供解鎖、放手只會喺按落被攔住之後先攔、墨水行按號碼鎖並拒絕刪除同合併、鎖住咗嘅物件會喺清單同 3D 檢視嘅選取度被放走、有佢嘅標記、排列會圍住佢、會停用全部刪除，同埋標記會跟住鎖住咗嘅元素。每個檢查喺壞咗嘅原始碼副本上都會失敗。

## 未做

復原同重做仍然會行返物件鎖住之前嘅改動；用大量墨水操作或者 AMS 同步去改墨水行嘅墨水，仍然會改到鎖住咗嘅行（淨係刪除會被拒絕）。3D 檢視入面鎖住咗嘅物件冇標記；佢喺物件清單嘅行就有。
