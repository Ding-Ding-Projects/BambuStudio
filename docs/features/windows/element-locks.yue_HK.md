# 元素鎖同解鎖階梯

**表面**：喺任何有「編輯外觀」嘅元素撳右鍵，揀**鎖住呢個元素...**（鎖咗嘅就係**解鎖呢個元素...**）；檔案 > 元素鎖會列出每個鎖；仲有指令面板（`Ctrl+Shift+F`，打「Element locks」）同全部功能頁 → `src/slic3r/GUI/ElementLocks/LockService.{hpp,cpp}`。規則喺冇 wxWidgets 嘅 `LockModel` 度（`src/slic3r/GUI/ElementLocks/LockModel.{hpp,cpp}`）。

鎖係用嚟防止視窗某部分因為手快或者一時衝動而被改，例如考試期間嘅搞笑程度，或者小朋友唔應該郁嘅設定。佢唔係保安界線：任何可以改資料夾入面檔案嘅人都可以移除佢。

## 上鎖

**鎖住呢個元素...** 會問：

- **原因**，可選，會顯示畀遇到呢個鎖嘅人睇。
- 一個 4 至 32 個字元嘅**密碼**，要打兩次。

個鎖會記低你（你嘅 Windows 用戶名）同時間。密碼永遠唔會儲存：只會保留一個加咗鹽、重複 20,000 次嘅 SHA-256 雜湊值。

## 鎖會做乜

鎖住咗嘅元素唔理撳滑鼠、滑鼠滾輪同按鍵，入面嘅所有嘢都一樣。`Tab` 仍然可以跳過佢，佢嘅右鍵選單（滑鼠、選單鍵或者 `Shift+F10`）仍然會打開，入面有**解鎖呢個元素...**。試吓用佢會出一段短提示：鎖住咗乜、邊個鎖、點解，同埋撳右鍵就可以解鎖。

## 解鎖

**解鎖呢個元素...** 會顯示邊個鎖、幾時鎖同點解，然後問密碼。打錯兩次冇代價；連續第三次打錯開始，下一次要等：

| 連續打錯次數 | 下次可以試之前要等 |
| --- | --- |
| 1 或 2 | 唔使等 |
| 3 | 30 秒 |
| 4 | 2 分鐘 |
| 5 | 10 分鐘 |
| 6 或以上 | 1 個鐘 |

## 解鎖階梯

畀唔記得密碼嘅時候用。連續打錯三次之後會提供，或者喺**唔記得密碼？**度打開：

1. 等 1 分鐘。
2. 打鎖住咗嘅嘢嘅名（大細楷同空格唔緊要）。
3. 再等 5 分鐘。

之後個鎖就會解開。你關咗個視窗或者 Bambu Studio，階梯都會記住去到邊；個視窗開住嘅時候，等完就會自動行落一步。

## 每個鎖

檔案 > 元素鎖會列出每個鎖，連埋邊個、幾時同點解，每個旁邊都有**解鎖...**。

## 儲存嘅值

資料夾（`%APPDATA%\BambuStudio`）入面嘅 `element-locks.json`：每個鎖嘅元素 id、名稱、原因、邊個、幾時、鹽同雜湊值、連續打錯次數、等待時間，同埋階梯去到邊一步。

## 檢查

`tests/element_locks.test.mjs` 會編譯 `tests/element_locks_test.cpp`：被拒絕嘅密碼、同獨立計算比較嘅雜湊值、打錯密碼同之後嘅等待、階梯、儲存同載入。佢嘅反向建置只會雜湊一次而唔係 20,000 次，必須失敗。

## 未做

清單入面嘅行（物件清單行、墨水行）嘅鎖，同喺鎖住咗嘅元素上面畫鎖嘅標記仲未起；嗰啲選單只會喺元素後面有視窗嘅時候先提供鎖。
