# 畫布工具提示裝飾動態

`ImGuiWrapper::tooltip` 同 `IMSlider::show_tooltip` 保留原有即時文字、背景、尺寸、懸停時序同關閉。一條窄強調線喺原有左內距內增長 100 ms，唔改文字 alpha、對比顏色、工具提示透明度、輸入區或者任何命令。wrapper 使用反向表面強調色；預覽滑桿使用原有主題 primary 強調色。呢啲工具提示冇套用通用彈出淡化。

wrapper 持有有界 context 本地時間線，最多 128 項。身分結合呼叫視窗／項目同顯示內容。冇 ImGui item ID 嘅已登記項目亦綁定觀察到嘅項目矩形。手動滑桿懸停區則透過工具提示渲染器傳入明確滑桿、路徑同實際 tick 身分。涵蓋現有 tick、懸停層時間、模擬播放／暫停同模擬速度，全部都唔會喺工具提示之前登記項目。呢個防止重用內部工具提示視窗共用上一項時間線。新出現視窗、內容改變、畫格間斷或者 context 時間倒退會重啟裝飾。Context 變化清除狀態；目前畫格未用項目喺 render 刪除。只有仍喺轉場中嘅可見工具提示，透過現有排程器要求額外畫布畫格。

冇計時器、非同步回呼、捕捉原生擁有者或者儲存 draw-list 指標。銷毀丟棄 wrapper 狀態。隱藏畫布唔會取得計時器。減少動態即時畫出最終直線並收定時間線，切返普通模式唔會重播已完成進場。現有增強畫布排程功能停用時，略去裝飾，唔加入另一排程器。容量或者不可用內距情況保留完整原有工具提示，唔加裝飾。

預覽路徑透過 `IMSlider::show_tooltip` 涵蓋真實模擬播放／暫停同速度說明、層資料、暫停／自訂程式碼描述，同現有層路徑切換說明。此單元唔加入畫布選單懸停或者篩選動畫，亦唔聲稱涵蓋無關工具提示 API。

## 仍需驗證

源碼檢查唔係繪製證據。只喺託管 Windows 針對精確來源／套件編譯同執行。觀察首次懸停、相同標籤項目之間快速移動、層內容變化、消失／重現、畫布隱藏／顯示、context 替換、顯示前同期間減少動態，以及主題／DPI 變化。喺英文、粵語同雙語正常／最低組合，檢查直線留喺內距內而唔與文字重疊。語意文字同輸入必須即時可用，冇延遲操作或者移動點擊區。記錄原始逐操作圖片同實際時序請求間隔。

有界時序輔助喺實際四畫格間隔同區域像素合格時，可能觀察到呢條由繪製擁有嘅直線。只要求取樣偏移唔係證據；錯過節奏仍係未觀察到。人工審查須將目標直線同其他像素變化分開。呢次源碼變更冇本機建置、測試、程式執行或者畫面擷取。
