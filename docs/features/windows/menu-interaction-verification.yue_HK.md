# 原生選單建構器互動驗證

已安裝原生驅動器提供獨立 `menu-builder-root` 同 `menu-builder-nested` 範圍。現有 `menus` 範圍不變。分開呼叫保留加密封套 30 圖限制：根範圍需要 15 個固定觀察，巢狀範圍需要 20 個，均包括首次就緒觀察，另加最多八次焦點巡覽輸入。每次原生輸入之後都有獨立擷取，因此兩個範圍都唔超過 28 圖。

兩個範圍都打開空白 Prepare 畫布快顯選單。字面匹配、冇結果同 Escape 復原留喺不變嘅 `menus` 範圍。建構器範圍啟用正則模式，打開真實 Regex builder 彈出視窗，要求空白模式輸入有鍵盤焦點，再輸入 `^fixture$`。所屬選單必須顯示完全相同查詢。

驅動器用原生 Ctrl+A 選取模式，輸入無效 `[`，要求畫面顯示未平衡字元集合狀態，再換返有效模式，確認可見有效狀態先離開上方控制項。唔假設修飾鍵輸入成功，每次替換後都檢查實際輸入值。呢個序列唔聲稱無效輸入會清除之前已有內容嘅樣本結果。

最多六次真實 Shift+Tab 尋找精確 Test pattern 控制項；實際點擊展開後最多兩次 Tab 尋找 Sample text。每步要求原建構器框架內有一個可見且有焦點嘅控制項；目的地亦須容納於目前實測捲動視口。普通 wxScrolledWindow 子項焦點行為必須真實顯示目的地，否則範圍不可用。唔假設固定 Tab 次數一定成功。Test pattern 打開樣本區；輸入 `fixture` 必須令可見樣本同結果欄位完整落喺視口內。單一匹配狀態由同一建構器作語意讀取，因為上方標籤可能已捲走；對應圖片只證明樣本／結果可見。建構器 Escape 必須只關閉建構器並將焦點還原至選單。Clear 恢復原有列清單；選單 Escape 將焦點還原至呼叫表面。

巢狀範圍先將父選單篩選至 Add Primitive，打開子選單，並喺每個子項操作後檢查父選單非空查詢。子項關閉後，兩次獨立 Escape 清除再關閉父選單，重新檢查焦點。唔執行選單命令，亦唔使用模型、打印機傳輸、剪貼簿操作或者外部協助路徑。

## 證據邊界

輸入使用現有自有隱藏桌面原生路徑。UI Automation 讀取識別精確可見控制項同檢查值；唔用 UI Automation 修改、程式命令注入或者生成圖片替代互動。缺少、含糊、畫面外或者停用控制項會停止範圍。驅動器唔會盲目捲動尋找樣本欄位。焦點巡覽用普通原生鍵，冇 UI Automation 捲動或者焦點修改。原生 DPI 檢查、實測溢出檢查、隔離設定檔、程序清理同加密傳輸仍必須執行。原始標籤、查詢、幾何同圖片留喺現有受限制證據包，直至私隱同真實像素審查完成。

實作只係源碼準備。冇本機程式、編譯器或者測試執行。每個範圍仍需精確來源嘅已安裝託管執行、經驗證解開證據包，同逐操作像素審查。源碼審查唔證明原生提供者名稱、實際修飾鍵交付、彈出焦點還原、樣本可見性、中間動畫或者可讀性。

兩個範圍都要涵蓋英文、粵語、雙語、淺深色、正常同實測最低尺寸，以及實際支援顯示比例。不可用組合須明確保留。現有 `menus` 嘅正則完整清單同鍵盤巡覽觀察仍必須執行。呢啲建構器範圍唔聲稱涵蓋畫布／ImGui 選單或者所有程式快顯選單。
