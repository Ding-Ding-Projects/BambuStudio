# Base64 工具箱

**表面**：檔案 > Base64 工具箱、命令調色盤（`Ctrl+Shift+F`，打「Base64」），或者全部功能頁 → `Base64ToolkitPanel`（`src/slic3r/GUI/Base64Toolkit/Base64ToolkitPanel.{hpp,cpp}`），係本機工具分頁入面嘅一頁。決定全部喺三個冇 wxWidgets 嘅模組度做：`Base64Codec`（編解碼器）、`Base64Files`（成個檔案）同 `Base64Workbench`（文字轉換、預覽、復原、歷史同紀錄）。

設計：[design/local-tools-2026-11](../../../design/local-tools-2026-11/README.md)，Base64 呢塊板。

所有嘢都喺呢部電腦度做。乜都唔會上載，解碼出嚟嘅嘢亦都永遠唔會自己執行或者打開。

## 文字

喺左邊打字或者貼上；一路打，結果一路喺右邊出現。

| 選項 | 選擇 |
| --- | --- |
| 方向 | 編碼、解碼 |
| 字母表 | 標準（RFC 4648 第 4 節）、URL-safe（第 5 節） |
| 換行 | 一行、MIME 76 加 CRLF、自訂闊度（4 至 1000 個字元） |
| 補位 | 開、關 |
| 解碼器 | 嚴格、寬鬆 |
| 文字當做 | UTF-8、UTF-16 LE、UTF-16 BE、Latin-1 |

- 兩邊都會顯示數量，例如「28 個字元 · 31 位元組」。
- 位元組嗰行會用所揀嘅文字編碼，以十六進制顯示頭 48 個位元組。
- **驗證**：編碼結果會再解碼一次，同原本嘅位元組比較（「解返出嚟係同樣嘅 31 位元組」），仲有一段短 SHA-256（滑鼠停喺上面就睇到全部）。解碼結果會講輸入係咪正正係所揀選項嘅標準寫法。
- **解碼停咗嘅時候**，會有張卡顯示問題、以字元計嘅位置、問題附近嘅文字（壞咗嗰個字元會標亮），同埋個問題係乜意思：無效字元、補位錯、補位後面仲有資料，或者斷咗尾。**試吓寬鬆** 會轉解碼器；**刪咗個壞字元** 就淨係刪嗰一個字元。半截嘅結果永遠唔會當做完成咁顯示。
- 所揀編碼裝唔落嘅文字（例如用 Latin-1 寫表情符號）會連位置一齊停低，並提供 **用 UTF-8**。
- 唔係所揀編碼文字嘅位元組會保留：十六進制嗰行會顯示佢哋，**將位元組存做檔案** 會一模一樣咁寫出嚟。
- **左右對調** 會將結果搬去輸入，再反轉方向。**清除** 會清空輸入。
- **複製做 data: URL**、**匯出紀錄（JSON）** 同 **用喺 data: URL** 都係由而家嘅結果做。
- 可以貼上，或者打開一個文字檔。文字上限係 16 MB；結果格只顯示頭 1 MB，複製同儲存就用全部。

## 檔案，喺原檔旁邊

**編碼檔案** 會喺同一個資料夾將 `report.pdf` 變做 `report.pdf.base64.txt`。**解碼檔案** 會將 `report.pdf.base64.txt` 或者 `report.pdf.b64` 變返做 `report.pdf`。可以揀檔案，或者拖去任何一張卡度。

- 檔案以 1 MB 一段串流處理，所以冇大小限制。**全部暫停**、**全部繼續** 同 **全部取消** 會喺下一段生效。
- 單一個檔案：揀咗嗰行，㩒 **暫停呢個檔案**、**繼續呢個檔案** 或者 **取消呢個檔案**，或者喺嗰行撳右掣（或者 `Shift+F10`）都係一樣。暫停嘅檔案會停喺原位，排緊隊定做到一半都係，其他檔案照做，佢嘅剩餘時間唔會計暫停嘅時間；取消嘅檔案唔會留低任何嘢。嗰行會寫 **已暫停，呢個檔案**，等你分得出同全部暫停嘅分別。
- 每個檔案都要檢查過先算完成。編碼咗嘅檔案會再解碼一次，用 SHA-256 同來源比較。解碼咗嘅檔案會先寫去一個臨時名，讀返同計雜湊之後先用佢真正嘅名。
- 撞名就會用編號名（`report (1).pdf`），最後改名嗰下亦永遠唔會取代中途出現嘅檔案，所以永遠唔會覆寫任何嘢。失敗或者取消咗嘅檔案乜都唔會留低。
- 解碼出嚟嘅名如果冇副檔名，會由 data: URL 類型、或者由位元組、或者用 `.bin` 補返。
- 接受 UTF-8 位元組順序記號同 `data:...;base64,` 標頭。錯誤訊息入面嘅位置由檔案開頭以字元計。
- 檔案會用文字分頁嘅字母表、換行同補位。檔案一律用寬鬆方式解碼：換行同欠補位都接受，其他任何字元就會停低嗰個檔案，並講出位置。
- 個表會顯示來源、寫出嘅名、大小、進度同剩餘時間，同埋狀態（已驗證、已驗證並改名，或者問題）。**喺資料夾顯示**（或者雙擊）會喺檔案總管揀中個檔案。

## data: URL

- **建立**：由一個檔案（最多 16 MB，可以揀或者拖落呢頁）或者由文字分頁。MIME 類型由位元組偵測，可以改；文字可以加 charset。可以複製或者儲存成條 URL。
- **讀取**：貼上一條 data: URL。會顯示類型、聲明嘅 MIME 類型、大小、參數、係 Base64 定百分比編碼，同埋位元組特徵同聲明類型夾唔夾。
- **預覽**：圖片由像素畫出嚟（連大小同色彩），文字用佢嘅 charset 以純文字顯示，十六進制就顯示頭 4 KB。超過 2 MB 嘅文字同超過 64 MB 嘅圖片會改為顯示大小提示。呢度唔會播放聲音同影片；**將位元組存做檔案** 會寫出嚟俾你用自己嘅播放器。

## 歷史

歷史會保留編碼同解碼檔案、複製、儲存同匯出文字、建立同讀取 data: URL 嘅名、大小同雜湊，最新嘅排最頭。佢儲存喺資料夾入面嘅 `base64-toolkit-history.jsonl`，保留最新 500 行，永遠唔會離開呢部電腦。

- **保留內容**（預設關）會連文字行嘅輸入文字都保留。熄咗佢就會一次過喺歷史刪走所有保留咗嘅文字。
- 雙擊一行文字紀錄，就會喺文字分頁打開佢：選項一定會返嚟，文字就要當時有保留先有。
- **復原** 同 **重做** 會喺記憶體入面行過文字分頁最近 50 個狀態（文字同選項）。
- **匯出歷史** 會寫出 JSON；**清除歷史** 會先問你。

## 儲存嘅值

| AppConfig 鍵 | 值 |
| --- | --- |
| `base64_toolkit_options` | 文字分頁嘅選項，以 JSON 儲存 |
| `base64_keep_payloads` | `1` 或者 `0` |

## 檢查

- `tests/base64_codec.test.mjs`：編解碼器；負面建置會丟咗補位，一定要失敗。
- `tests/base64_files.test.mjs`：跨過兩個分段邊界嘅來回轉換、編號名、取消、第二段入面一個壞字元同佢準確嘅位置、data: URL、位元組順序記號、空檔案同唔存在嘅檔案，仲有非 ASCII 嘅名。負面建置會丟咗編碼器最後一組，一定要失敗。
- `tests/base64_per_file.test.mjs`：單一檔案暫停同取消嘅原始碼：工作執行緒會跳過排緊隊但暫停咗嘅檔案、喺暫停咗嘅執行中檔案入面等、取消會叫醒暫停咗嘅檔案，啲掣同行嘅選單都係對揀咗嗰行生效。每項檢查對壞副本都一定要失敗。
- `tests/base64_workbench.test.mjs`：設計板嘅範例文字同錯誤、文字編碼、標準寫法、預覽、大小、復原、有同冇保留內容嘅歷史，同埋匯出嘅紀錄。負面建置會喺冇同意之下保留內容，一定要失敗。
