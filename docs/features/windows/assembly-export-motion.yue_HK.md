# 組裝匯出進度進場效果

可到達嘅組裝匯出進度框架持有一個 `MD3TransientEntrance`。`AssemblyStepsUtils::update_assembly_export_progress` 建立框架並呼叫其 `update_progress`；`hide_assembly_export_progress` 隱藏同一擁有者。呢個係頂層異形框架，唔係子面板或者 OpenGL 表面。

進度文字、範圍、值、百分比、排列同位置即時更新。原有 `ShowWithoutActivating` 呼叫仍係唯一顯示操作。成功由隱藏變為顯示後，框架啟動共用短進場效果。可見期間反覆進度更新唔會重啟效果。原有 `Raise`、取消回呼同取消啟用條件保持不變。

框架喺自己嘅隱藏事件同銷毀前停止控制器。共用控制器令排隊啟動失效，綁定弱擁有者同精確原生控制代碼，只恢復自己取得嘅分層狀態。子控制代碼或者已分層控制代碼會跳過，唔會搶走另一動畫器嘅擁有權。減少動態效果令框架保留最終外觀；進場期間更改偏好，透過現有動畫器政策收定。關閉、進度更新同操作都唔會等動畫。

## 驗證待完成

呢次修改只做過源碼檢查。編譯同全部執行時驗證，必須喺託管 Windows 工作流程針對精確套件進行。使用最少有一個真實組裝步驟嘅專案同真正支援嘅匯出。檢視首次顯示、頻密進度更新、隱藏後立即重開、進場中取消，以及擁有者銷毀嘅真實時序擷取。確認顯示唔會移動焦點，進度同取消保持即時，舊透明度回呼唔會影響替代框架。測試顯示前同動態期間減少動態效果、主題變化同實測 DPI。

擷取路徑必須證明有記錄合成後框架透明度；未合成嘅客戶區擷取唔能夠證明呢個進場效果。源碼擁有權同最終狀態圖片，單獨都唔證明中間動態或者回應速度。未有本機產品執行、建置、測試或者畫面擷取。
