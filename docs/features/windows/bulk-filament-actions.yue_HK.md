# 批量墨水操作

一次過批量操作許多物理墨水插槽，喺一個 MD3 對話框中佈置同埋作為單個批次應用。

## 行為

**BulkFilamentDialog**（`src/slic3r/GUI/BulkFilamentDialog.{hpp,cpp}`）列出每個*物理* 墨水插槽；混合（虛擬）墨水被排除，正正如`Sidebar::collect_physical_filament_info()` 過濾佢哋；作為行複選框 + 編號色樣本 + 預設名稱，喺 **全選** 切換下（部分檢查時不確定）。四個操作可以被佈置；

1. **設定預設…** 打開對墨水預設嘅單選選擇器，這些預設當前係可見 *同埋* 相容（側邊欄組合顯示嘅相同集合）。佈置嘅選擇作為預設別名顯示，但通過完整預設名稱應用。
2. **設定色…** 打開 MD3 色選擇器（`MD3ColorPickerDialog`）；佈置嘅十六進位應用到`filament_colour`、`filament_multi_colour` 同埋 `filament_colour_type`（「1」、實心）喺一個克隆項目配置補丁中。
3. **刪除選定墨水** 刪除每個檢查嘅插槽。
4. **添加 N 墨水** 一個獨立數值轉軸附加 N 個新墨水使用下一個自動分配色（`Plater::get_next_color_for_filament()`）。

冇嘢改變而對話框係打開嘅。**應用**（wxID_OK）提交批次；**取消** 係一個嚴格嘅無操作。應用被禁用，直到一個操作實際被佈置（同埋，對每插槽操作，至少一行被檢查）。結果通過存在側邊欄刷新表面；冇模態成功彈出視窗。

## 入口點

**批量** 概述按鈕喺準備側邊欄嘅墨水部分標頭中，靠近 **同步 AMS**（相同 MD3 標頭按鈕配方；h30 藥丸、`Body_11`、Material`Stack` 字形）。佢呼叫 `Sidebar::bulk_filament_actions()`（`Plater.cpp`），喺`Plater.hpp` 中靠近其他墨水方法聲明。標頭佈局數學（`Sidebar::priv::adjust_filament_title_layout`）計算額外按鈕，所以冇嘢喺狹窄側邊欄寬度被擠壓。

## 衛隊

- **最少 1 規則** 刪除停止，一旦只有一個墨水保持；最後墨水永遠無法被批量刪除。對話框喺刪除操作旁陳述呢個。
- **最多 32 規則** 總墨水被限制喺 `EnforcerBlockerType::ExtruderMax`（32）。添加轉軸嘅範圍係 `1..remaining capacity`；喺容量嘅添加行被禁用。`add_custom_filament()` 每次迭代重新檢查上限，同埋迴圈仲停止一旦墨水組合計數停止增長。
- **下降刪除順序** 檢查嘅插槽從最高配置索引刪除下來，所以早期刪除永遠唔會移動後來嘅索引。
- **單刷新批處理** 預設同埋色改變跨所有檢查插槽分享一個刷新尾（項目骯髒更新、選擇導出、組合更新、`on_config_change`、動態墨水列表更新、備份管理器更改日誌、每平台切片狀態無效），而唔係每插槽刷新。刪除重用 `delete_filament()`，這執行佢自己每插槽刷新。
- 應用順序係預設 → 色 → 刪除 → 添加，所以每插槽操作總係操作索引喺對話框打開時捕捉；刪除無法使佢哋無效。
- gcode-3mf 衛隊（`is_new_project_in_gcode3mf()`）喺對話框打開前執行，相同作為其他墨水變異流。

## 失敗模式

- **冇相容預設** 「設定預設…」按鈕被禁用；色/刪除/添加仲然工作。
- **過時插槽集** 對話框喺打開時快照插槽。配置索引被重新驗證反對快照喺應用；超出範圍條目被跳過而唔係誤應用。
- **容量競速** 如果墨水被另外添加喺對話框打開時，添加迴圈停止一旦 `add_custom_filament()` 拒絕增長列表。
- **刪除下到一個** 剩餘佈置刪除被默默丟棄一旦一個墨水保持（匹配側邊欄嘅單個刪除行為）。

## 安全考量

純粹本地 UI 跨記憶中預設組合同埋項目配置；冇網絡、檔案或過程訪問除咗標準項目骯髒/備份簿記每個墨水編輯執行。本地化字串通過標準 `_L()` 目錄。

## 驗證

1. 構建同埋打開準備帶多墨水項目；**批量** 按鈕出現喺墨水標頭中靠近 **同步 AMS**，同埋標頭仲然佈置喺狹窄(312/344 DIP) 側邊欄寬度。
2. 檢查幾個插槽、佈置預設、應用；每個檢查組合顯示新預設；切片狀態無效一次；項目標記骯髒。
3. 佈置色；檢查樣本所有顯示實心色（`filament_colour_type` = 1）；沖洗體積喺自動計算設定為「全部」時重新計算一次。
4. 檢查所有插槽同埋佈置刪除；刪除停止帶一個墨水保持。
5. 喺 30/32 墨水，添加轉軸上限 2；喺 32 添加行被禁用。
6. 應用後佈置；冇嘢改變。
7. 語言模式；字串喺英文、粵語（批量墨水操作 …）同埋雙語後備中渲染；`compile_translation.py` 同埋 `--check` 兩者通過。
