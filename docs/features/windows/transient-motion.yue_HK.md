# 工具提示同對話框進場動態

原生參數工具提示卡、帶 `MD3DialogCaption` 嘅對話框，同命令面板，每個表面持有一個進場控制器。真實顯示事件將視覺進場排隊，等原生可見先開始。建構期間框架設定只要求圓角，唔再喺隱藏時啟動淡化。

參數卡使用共用短時長；對話框同命令面板使用共用中時長。控制器使用共用緩動、弱擁有者同減少動態偏好。永不延遲顯示、焦點、模態狀態、關閉、接受或者其他語意操作。隱藏停止計時器、恢復透明度，並令排隊進場失效。重開替換舊 run。可見參數卡內容更新唔會重啟進場。

只有明確提供嘅頂層 Windows 控制代碼接受 alpha 淡化。子控制代碼同已分層表面跳過。控制器只喺自己未變嘅控制代碼恢復自己裝上嘅樣式；參數卡獨立陰影唔會動畫化。減少動態即時保留最終不透明狀態；run 中偏好改變喺下一計時交付收定。銷毀令擁有者失效並取消回呼。不支援平台保留普通即時顯示。

## 待完成網頁工具提示覆蓋

`MarkdownTip` 仍冇動畫。其 `wxWebView` 內容可附加至另一父項，而非同步載入同待處理指令佇列目前冇擁有者範圍動畫世代或者已儲存動態偏好。`resources/tooltip/styled.html` 持有內容容器，內附 `showMarkdown` 函式替換 HTML；冇專用進場生命週期握手。源碼檢查唔能證明喺該合成器套用原生 alpha。後續必須將只影響內容嘅 CSS 轉場綁定目前擁有者、已載入文件同顯示世代，傳遞減少動態，並喺隱藏、替換、附加同銷毀取消。呢個係待完成覆蓋，唔係已完成轉場，亦唔係動畫化子控制代碼嘅理由。

## 必須託管證據

冇本機編譯、測試或者 UI 執行。精確合併候選喺託管 Windows runner 建置同操作之前，實作只限源碼。驗證首次顯示、快速隱藏／重開、可見工具提示替換、模態接受同取消、擁有者銷毀、計時器啟動失敗，同動態中偏好變更。檢查排隊進場永不復活隱藏表面，完成後冇此控制器持有嘅分層樣式或者運行計時器。現有透明表面必須不變。

使用真實時序畫格同最終狀態擷取，記錄精確套件同來源身分。涵蓋原生參數卡、一個可重用帶標題對話框，同命令面板；測試英文、粵語、雙語、淺深色、正常同實測最低尺寸，以及實際量度 100%、125%、150%、200% 比例。驗證鍵盤焦點、指標操作、工具提示、陰影對齊、可讀內容同冇裁切。靜態圖片唔證明轉場時序、取消或者閒置計時器行為。網頁工具提示動態同不支援合成器情況仍明確未驗證。
