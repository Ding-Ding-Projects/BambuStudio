# 虛擬磁碟

**表面**：檔案 > 虛擬磁碟、指令面板（`Ctrl+Shift+F`，打「Virtual」）同全部功能頁 → `src/slic3r/GUI/VirtualDisks/VirtualDisksPanel.{hpp,cpp}`。讀磁碟檔案喺 `DiskImage.{hpp,cpp}`，每個操作嘅限制同步驟喺 `DiskPlan.{hpp,cpp}`，問 Windows 嘅嘢同操作點樣執行喺 `DiskSystem.{hpp,cpp}`，全部喺同一個資料夾。

你加入嘅每一個 VHD、VHDX、VHD Set 同 ISO，直接由檔案本身讀出嚟，連埋 Windows 提供嘅每一個操作。呢度唔會掂你冇揀嘅磁碟，亦都唔使 Hyper-V。

## 清單

用**加入磁碟檔案...**、**加入資料夾...**（入面每一個磁碟檔案，最深三層資料夾），或者將 `.vhd`、`.vhdx`、`.avhdx`、`.vhds` 或 `.iso` 檔案拖放到頁面任何地方嚟加入磁碟。**由清單移除**只會忘記個磁碟；檔案留喺原位。

| 欄 | 顯示 |
| --- | --- |
| 名稱 | 檔案名；子碟會用箭咀排喺父碟下面 |
| 資料夾 | 檔案喺邊 |
| 格式同類型 | VHD、VHDX、VHD Set 或者 ISO；固定、動態、差異或者唯讀 |
| 大小 | 個磁碟俾 Windows 睇到嘅大小 |
| 佔用空間 | 檔案喺佢個磁碟機度佔幾多 |
| 已掛載 | 否、是，或者佢個卷掛載喺邊 |
| 鏈測試 | 通過、受保護（有子碟嘅父碟）、搵唔到父碟、父碟改過、讀唔到、磁碟 ID 相同，或者唔係鏈 |

**全部**、**已掛載**、**喺鏈入面**同**問題**會篩選清單，每個都有數量，搜尋可以搵名、路徑、標籤或者 ID。**再讀一次**會重新讀晒每個檔案，再問一次 Windows。

## 讀一個磁碟

清單旁邊嘅詳細資料全部由檔案本身嚟：

- **VHD**：檔案尾嘅頁尾（會檢查佢嘅校驗和），動態同差異磁碟仲有動態標頭：區塊大小、父碟嘅唯一 ID、名同儲咗嘅路徑。
- **VHDX**：兩個標頭（過到 CRC-32C 檢查而序號較大嗰個係而家用緊嘅）、區域表，同埋中繼資料：區塊大小、邏輯同實體磁區大小、虛擬大小、虛擬磁碟 ID，子碟仲有父碟定位器。
- **ISO**：由主要卷描述符讀卷標同大小。
- **磁碟入面**：如果磁碟第一個區塊喺呢個檔案入面，就讀分割表：GPT 同佢嘅磁碟 GUID、MBR 同佢嘅簽名，或者係原始。
- **VHD Set**：認得個檔案；佢嘅檢查點要 Windows 用 Hyper-V 模組讀，所以呢度唔會顯示。

一個以讀寫方式掛載咗嘅磁碟，Windows 揸住嗰陣讀唔到；頁面會繼續顯示上次讀到嘅嘢。

## 鏈同撞 ID

差異磁碟（子碟）會用路徑同身份去講邊個係佢嘅父碟。搵父碟會先用儲咗嘅絕對路徑，再用由子碟資料夾計起嘅相對路徑，最後用子碟資料夾入面嘅檔案名。然後鏈測試會對身份：VHDX 子碟記住父碟嘅資料寫入 GUID，VHD 子碟記住父碟嘅唯一 ID。如果父碟喺子碟整咗之後再被寫入過，子碟會顯示**父碟改過**；如果清單入面冇檔案對得上，就係**搵唔到父碟**。

兩個磁碟嘅分割表帶住同一個磁碟 ID 就係**撞 ID**：第一個掛載咗嘅時候，Windows 會將第二個保持離線。兩個都會顯示**磁碟 ID 相同**，**新磁碟 ID...** 就可以解決。子碟同佢嘅父碟本來就共用分割表，永遠唔會當係撞 ID。

## 操作

每個操作都會先計劃好，再用管理員權限執行：Windows 只會問一次，底部會顯示緊行緊邊一步，連埋**取消**，會喺下一步停。如果你取消管理員提示，乜都唔會改，個操作會記錄做未完成，永遠唔會當做完成。

| 操作 | 會做乜 | 途徑 |
| --- | --- | --- |
| 掛載、唯讀掛載 | 掛載個磁碟；Windows 會掛佢啲卷 | Storage 模組 |
| 卸載 | 問過之後卸載 | Storage 模組 |
| 建立... | 見下面 | VirtDisk API、Storage 模組 |
| 放大... | 放大個檔案；掛載緊嘅話，會喺同一次執行入面將最後一個卷延伸到新空間 | VirtDisk API、Storage 模組 |
| 壓縮... | 完整會掃描零區塊同交還冇用嘅區塊；快速會交還冇用嘅區塊而唔掃描。掛載緊嘅磁碟會喺執行期間改為唯讀掛載，之後再還原 | VirtDisk API |
| 整子碟... | 喺呢個磁碟上面整一個新嘅差異磁碟 | VirtDisk API |
| 合併入父碟... | 要經過兩匙確認，會講明父碟同每一個會停止運作嘅其他子碟。會先整一份父碟嘅驗證過嘅副本（`Name (copy).vhdx`，用 SHA-256 檢查） | VirtDisk API |
| 重新連接父碟... | 檢查過揀嘅檔案真係嗰個父碟之後，將子碟指去父碟嘅新位置 | VirtDisk API |
| 新磁碟 ID... | 一個新嘅 GPT 磁碟 GUID 或者 MBR 簽名；改嘅時候會掛載而唔俾盤符，改完就卸載 | Storage 模組 |
| 快速打包... | 見下面 | VirtDisk API、Storage 模組、Robocopy |

放大只適用於唔係子碟、亦都唔係父碟嘅磁碟：放大父碟會整壞佢啲子碟。壓縮適用於動態同差異磁碟。兩樣都需要磁碟個檔案讀得到。縮細仲未做。

**複製步驟...**（清單撳右掣都有）可以將揀咗嘅磁碟嘅任何操作複製成 PowerShell 腳本，或者喺 DiskPart 做得到嘅時候複製成 DiskPart 腳本。複製出嚟嘅 PowerShell 腳本會先定義埋步驟要用嘅小工具，所以喺以管理員身份開嘅 Windows PowerShell 貼上就行得。

## 建立

由**便攜資料碟**（VHDX、動態、GPT、NTFS）、**Dev Drive**（ReFS、最少 50 GB、格式化做 Dev Drive）或者**我自己嘅磁碟**開始，然後揀：

- **格式**：VHDX 或者 VHD。**類型**：動態（用幾多佔幾多）或者固定（一開始就佔晒）。
- **大小**，用 MB、GB 或者 TB。VHDX 可以係 3 MB 至 64 TB，VHD 最多 2,040 GB。
- **區塊**：Windows 預設，或者 VHDX 用 1、8、32 或 256 MB（VHD 用 512 KB 或者 2 MB）。**磁區**：邏輯 512 或 4096，實體 512 或 4096。
- **初始化**：GPT、MBR（最多 2 TB）或者保持原始。**檔案系統**：NTFS、ReFS、exFAT 或者 FAT32（Windows 格式化 FAT32 最多 32 GB），連埋一個啱佢嘅標籤（32、15 或者 11 個字元）。**盤符**：下一個空嘅或者你揀嘅。**快速格式化**。
- **放喺邊**（永遠唔會蓋過現有檔案）同**建立之後掛載**。

打字嘅時候會檢查晒每個限制，仲有提示，例如個磁碟機有幾多空位。**同樣步驟寫成腳本**會顯示 PowerShell 或者 DiskPart 步驟，連埋**複製**。DiskPart 用自己嘅區塊大小；VirtDisk API 會用你揀嘅。

## 快速打包

揀一個資料夾：佢會被打包入旁邊一個新嘅動態 VHDX，大小啱啱好（檔案本身、每個檔案大約 6 KB 俾檔案系統自己嘅記錄、2% 同 64 MB）。如果 `Photos.vhdx` 已經存在，新磁碟就係 `Photos (1).vhdx`；乜都唔會被蓋過。資料夾結構、時間、屬性同替代資料流（包括網絡下載標記）都由 Robocopy 複製，唔會跟住連接點走，之後每個檔案都會用 SHA-256 同來源對過。如果有檔案喺複製期間變大而磁碟唔夠位，磁碟會大四分之一再繼續複製。**取消**只會卸載同刪除個新磁碟；你嘅檔案永遠唔會被搬或者改。最後新磁碟會卸載。

## 記錄

**記錄**會列出每個操作、做嗰個操作嘅途徑同點樣完結（完成、未完成或者失敗），壓縮會有之前同之後嘅大小，快速打包會有檔案數量，新磁碟 ID 會有新 ID。會保留最近 200 個。

## 冇 Windows 嘅時候

頁面會講明虛擬磁碟需要 Windows。磁碟檔案仍然可以加入、讀同檢查；但係乜都唔可以掛載或者改。

## 檢查

- `tests/virtual_disks.test.mjs` 會編譯 `tests/virtual_disks_test.cpp`：逐個位元組砌出嚟再讀返嘅 VHD、VHDX 同 ISO 映像（揀較新嘅 VHDX 標頭、報告損壞嘅校驗和）、入面嘅分割表、搵到、完整、改過同唔見咗嘅鏈、撞 ID、每個限制、每個操作嘅 PowerShell 同 DiskPart 步驟、快速打包嘅大小同命名，同埋清單檔案。佢嘅反向建置會拎走大小限制，又將父碟同子碟當係撞 ID，必須失敗。
- `tests/virtual_disks_windows.test.mjs` 喺 GitHub 提供嘅 Windows 機器上面行（`.github/workflows/virtual-disks-windows.yml`），用 app 自己嘅程式碼處理真嘅磁碟：建立一個 8 MB 區塊、4096 位元組實體磁區嘅 VHDX 再讀返、整子碟、經子碟寫入再喺整好驗證過嘅副本之後合併入父碟、卸載同掛載狀態下放大、壓縮、用新磁碟 ID 解決撞 ID、重新連接搬咗位嘅父碟，同埋快速打包一個資料夾，佢嘅網絡下載標記一定要保留。
