# 通知同進度動態

呢個單元將現有通知淡化同原生 `ProgressBar` 脈衝連接至共用 `MD3::Motion::reduced()` 偏好。冇新增設定或者翻譯文案。已儲存程式偏好同作業系統請求，都由現有共用政策解析。

## 通知生命週期

通知保留原有可讀停留時間、懸停暫停同溢出延後。一旦未暫停通知進入裝飾淡化，減少動態效果會直接移至完成狀態。普通動態保留原有有界淡化。持續通知仍持續，明確關閉同取消回呼唔等轉場。

管理器只喺真實畫布存在、未被刪除而且畫面可見時排定未來通知畫格。唔會取消語意更新或者改變進度值。其他地方已請求嘅畫格仍可能到達；呢個檢查防止通知排程器喺隱藏表面維持動畫迴圈。現有非活動視窗處理不變。通知位置同按鈕幾何唔會動畫化。

## 原生進度條

確定進度嘅 `SetValue`／`SetProgress` 保持即時。冇內插改變已報告值、延遲完成或者捏造進度。`Pulse` 表示活動但百分比未知。減少動態下顯示靜止置中片段，唔改儲存數值或者聲稱完成。原生計時器未能啟動時，片段仍可見。

脈衝計時器只喺控制項啟用、可見、不確定而且容許動態時運行。`Disable`、確定進度更新、明確隱藏同銷毀會停止。祖先隱藏控制項時，已排隊 tick 喺下一交付計時事件觀察 `IsShownOnScreen()` 並停止。即時改為減少動態亦同樣處理，通常喺現有 40 ms 節奏內，視乎事件迴圈可用情況。穩定狀態只重畫一次。真實顯示／繪製事件或者另一 `Pulse` 恢復符合條件動畫；冇閒置計時器輪詢未來偏好或者可見性變化。不確定片段使用軌道高度，即使標記標籤令控制項更高。標記位置同互動幾何不變。

## 驗證狀態同必要託管檢查

呢個候選只有源碼檢查，冇本機編譯、測試、產品執行或者擷取。託管編譯，以及真實計時器、可見性、取消同繪製行為仍未驗證。

針對性託管原生夾具應使用事件迴圈測試產品 `ProgressBar`：可見時 Pulse、Pulse 前同掃動期間減少動態、明確同祖先隱藏／顯示、Disable、SetValue／Reset、帶排隊 tick 銷毀，以及重新啟用動態後真實繪製。分開觀察計時器狀態同數值。確認隱藏、停用或者減少模式唔持續重畫，而且靜止指示可見。

真實通知須驗證普通訊息跨越可讀間隔、懸停同溢出延後關閉、減少動態只略過淡化、普通模式仍淡化、持續警告保持可見，以及取消立即呼叫真實回呼。淡化中隱藏或者最小化畫布，驗證排程器唔再持續要求動畫畫格。必須使用實際產品物件，唔係重複政策斷言。

保留綁定來源、執行檔雜湊、語言、主題、實際 DPI 同視口嘅時序序列同逐輸入擷取。涵蓋英文、粵語、雙語、淺深色、正常／最低尺寸同 100/125/150/200%。現有已安裝取消證據仍須獨立取得；此動態單元唔需要實體打印或者傳輸。通知進場、位置轉場同其他 widget 系列不在此有界變更內，仍留喺共用介面動態清單。
