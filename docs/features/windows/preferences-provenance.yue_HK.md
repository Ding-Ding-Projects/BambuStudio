# 偏好設定：每個值由邊度嚟

**表面**：偏好設定（`Ctrl+P`，或者導航欄嘅設定）→ `PreferencesDialog`（`src/slic3r/GUI/Preferences.{hpp,cpp}`），變更紀錄同來源規則喺 `src/slic3r/GUI/PreferencesRemake/PreferenceHistory.{hpp,cpp}`，重設部分、匯入、復原同相關設定嘅計劃喺 `src/slic3r/GUI/PreferencesRemake/PreferencePlans.{hpp,cpp}`。

設計：[design/local-tools-2026-11](../../../design/local-tools-2026-11/README.md)，InfoIcons 呢塊板。

## 每一行設定

每一行有標題欄嘅設定而家多咗兩樣嘢（外觀嗰幾行：主題、密度、強調色、字型同文字大小都有）：

- **標題下面一行，講個值由邊度嚟。** 會係其中一句：
  - 「內建預設：開。你未改過。」
  - 「你喺 2026-11-02 18:40:11 設做深色。」（嚟自變更紀錄）
  - 「儲存咗做 110。內建預設係 100。」（紀錄出現之前改嘅，或者唔係喺呢個視窗改嘅）
  - 「排程設定而家暫時將佢設做關。」（有排程蓋過咗佢）
  - 「呢個值係私人嘅，所以唔會喺度顯示。」（權杖、存取碼、站台鎖匙之類）
- **一個資訊掣**，會喺右邊打開解釋面板。

內建預設係 `AppConfig::set_defaults()` 宣告嘅值，由一個淨係用預設值砌出嚟嘅設定讀出，所以唔係估嘅。冇宣告預設值嘅設定會直接講明，唔會作一個出嚟。

## 解釋面板

- 呢個設定做乜（行本身嘅描述）；
- 個值由邊度嚟，用上面嗰啲講法；
- 內建預設；
- 幾時生效：即刻、重新開程式之後，或者下次用到佢嘅功能行嗰陣；
- 儲存喺邊（`BambuStudio.conf` 同佢個鍵）；
- 最近五次變更，連時間；
- **試玩區**，畀外觀設定用：一個樣本掣、開關、進度列同一行字，每次改完都會重新砌過，所以佢哋著住而家生效嘅樣。佢哋乜都唔會改你嘅項目；
- **相關**：同一個標題下面最多五個其他設定（標題下面少過兩個嘅話，就用同一部分其他設定補足）；撳每粒晶片會去嗰個設定，打開佢嘅解釋；
- **重設做**內建預設，畀開關、選擇同外觀控制用：佢係用嗰行自己嘅控制改，所以控制平時會觸發嘅副作用一樣會行。控制而家停用咗嘅行（學校模式、元素鎖、閘門）永遠唔會喺度改，冇呢類控制嘅行會叫你用佢自己嘅控制改返。

啲值會用嗰行顯示嘅叫法：「深色」、「緊湊」、「大」、「綠色」，唔會寫 `1`、`compact`、`1.15` 或者 `#146c2e`。

## 部分數目

工具列每個部分都會顯示佢有幾多個設定，例如「外觀（5）」。各部分保留原本嘅 id 同名，因為儲存咗嘅工具列排位同指令面板連結都靠佢哋。

## 重設呢一部分

搜尋欄隔籬嘅**重設呢一部分**會為顯示緊嗰個部分作計劃：

- 每個同內建預設唔同、而且有控制可以改嘅設定，都會連佢會變返嘅值列出嚟；
- 會重新開程式、登出你或者答同意問題嘅設定（語言、單一實例、細節程度、地區、體驗計劃、開發者模式），會留返畀佢哋自己嘅控制改；
- 文字欄同滑桿而家都會重設：個值會打入欄度再喺入面撳 Enter（滑桿就行一次同拖動一樣嘅步），所以嗰行會好似你親手打咁檢查、儲存同套用。欄唔收嘅值（數字欄入面有字母、超出滑桿範圍嘅數）唔會打入去，之後會講出名；
- 私人值（權杖、代碼、鎖匙）永遠唔會喺度重設。

兩條鎖匙都扭咗、滑桿都推到尾（雙匙確認）之前，乜都唔會改。之後每個設定都經佢自己嘅控制改，歷史會記低佢原本係乜。變唔返預設嘅、同埋留返畀自己控制改嘅，之後都會列出。

## 匯入

**匯入偏好設定…** 會讀由**匯出設定…**寫出嚟嘅 JSON、YAML、TOML 或者 XML（有冇結構標頭都得，最多 1 MB），列出會改乜，最多列 12 個，再講仲有幾多個。格式睇副檔名；副檔名係其他嘢嘅話，就睇檔案開頭幾個字。YAML、TOML 同 XML 會照匯出器寫嘅樣讀，再加埋大家常做嘅簡單修改：註解、冇引號嘅字、單引號、CRLF 行尾，同埋分幾行寫嘅 TOML 清單。入面其他嘢（YAML 錨點、標籤同流式集合、TOML 多行字串、XML CDATA、同一個鍵出現兩次）會講明格式拒絕，唔會靠估。CSV、Markdown、HTML 同壓縮檔係報告，唔會讀返入嚟。只會考慮偏好設定顯示嘅設定；私人值、偏好設定冇顯示嘅設定，同埋唔係文字、true 或 false、或者整數嘅值，會計數同跳過；留返畀自己控制改嘅設定（同上面一樣）會講出名。較新版本嘅檔案，或者唔係偏好設定匯出嘅檔案，會連原因拒絕。你同意之後，每個設定都經佢自己嘅控制改；控制冇呢個值或者鎖咗，就保持原狀，之後會講出名。

## 要重新啟動

單一實例、Filament Manager 同多部機管理，只會喺程式啟動嗰陣讀。佢哋其中一個同程式啟動時用緊嘅值唔同嗰陣：

- **你改過嘅**隔籬會出現一粒**要重新啟動**晶片，講有幾多個設定等緊；開咗佢就淨係顯示嗰啲行，同搜尋文字一齊用；
- 底下一行會講乜嘢等緊（「等緊重新啟動：單一實例。」），仲有**即刻重新啟動**。

即刻重新啟動會先關偏好設定，再經正常路徑關主視窗，所以未儲存嘅專案仍然會問，亦可以取消。安裝咗嘅版本會好似更新之後咁經 `Update.exe` 再開；冇 `Update.exe` 嘅版本會講佢唔可以自己重新開，個掣會保持停用。將設定改返做用緊嘅值，就會清走。語言同細節程度唔會列出：佢哋改咗之後會自己重新開視窗。

## 你改過嘅

搜尋欄隔籬嘅晶片會顯示有幾多個設定同內建預設唔同，開咗佢就會收埋其他行。佢同搜尋文字（普通文字或者正規表達式）可以一齊用。由指令面板或者全部功能頁打開一個設定，會熄咗呢粒晶片，等嗰行顯示得到。

## 偏好設定歷史

偏好設定歷史掣會列出偏好設定開住嗰陣每一次變更，最新嘅喺最上，有時間、舊值同新值。紀錄係資料夾入面一個 JSON 行檔 `preferences-history.jsonl`，永遠唔會離開呢部電腦。私人嘅鍵只會記低「改咗」，兩個值都唔記。檔案保留最新 1,000 次變更。

**復原上一次變更**只會將最新嗰次變更放返，經嗰行自己嘅控制改，前提係嗰行有咁嘅控制而且冇鎖；之前嘅值係空，即係嗰陣乜都冇儲存，所以會放返內建預設。復原會好似其他變更咁記低，所以再撳一次就係重做。私人值，或者留返畀自己控制改嘅設定，會直接講明。

## 檢查

`tests/preference_plans.test.mjs` 會建置 `tests/preference_plans_test.cpp`：重設部分嘅計劃（重設、留返畀自己控制、冇改過、私人、出現兩次嘅鍵）、匯入（結構標頭同淨資料、每種拒絕、唔係文字嘅值、私人同唔認識嘅鍵）、復原（只限最新、空舊值用預設、每種原因）、相關設定、部分數目，同等緊重新啟動嘅設定。佢嘅負面建置連要手動改嘅設定都會重設，仲會將改返咗嘅設定當仍然等緊，一定要失敗。

`tests/preference_formats.test.mjs` 會用匯出器為一組細偏好設定真正寫出嚟嘅 YAML、TOML 同 XML（有同冇結構標頭）建置 `tests/preference_formats_test.cpp`，每個都好似 JSON 咁經同一個計劃匯入；佢亦會檢查簡單修改、跳脫字元、每種拒絕嘅形狀同格式偵測。一個連讀唔到嘅檔案都放行嘅負面建置一定要失敗，而執行器會檢查匯出器仲係照固定樣本咁寫呢啲格式。

`tests/preferences_tools_wiring.test.mjs` 會檢查視窗源碼：重設呢一部分喺雙匙確認之前乜都唔改，而且只改計劃列出嘅；匯入喺你同意預覽之前乜都唔改；每次改都經嗰行自己嘅控制，永遠唔會改停用咗嘅；同意嗰行冇設定器；面板嘅重設同相關晶片要等撳完先做嘢；文字欄同滑桿經佢哋自己嘅 Enter 或者步改，而且只會用佢哋收嘅值；YAML、TOML 同 XML 喺計劃之前變成 JSON；即刻重新啟動會先結束偏好設定，主視窗先經正常路徑關；每個檢查喺壞咗嘅副本上都必須失敗。

`tests/preference_history.test.mjs` 會建置 `tests/preference_history_test.cpp`（遮蔽私人值、紀錄格式、壞行同 CRLF 行、壓縮、每種來源情況），仲有一個當咩都唔係私人嘅負面建置，一定要失敗。佢亦會檢查視窗源碼：行登記嗰陣會加裝飾、來源行唔會俾搜尋搵到、追蹤喺搜尋索引之後開始、計時器會跟住視窗停。
