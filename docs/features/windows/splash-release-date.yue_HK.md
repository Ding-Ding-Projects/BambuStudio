# 啟動畫面上嘅發佈日期

應用啟動時顯示嘅啟動畫面會話在應用名稱同版本下面嘅獨立一行顯示運行緊嘅版本係幾時發佈：

- **英文：** `Released 29 September 2026`
- **香港廣東話：** `2026年9月29日發佈`
- **雙語：** 兩行，英文嗰行先，廣東話嗰行下面
- **其他語言：** 翻譯嗰隻字加上系統嘅短日期格式

冇經過發佈工作流製作嘅構建會話顯示 `Built` 而唔係 `Released`（廣東話 `構建`），因為冇發佈發行佢。

## 日期點嚟

- CMake 記錄構建配置嘅時刻，用 UTC 表示
  （`libslic3r_version.h` 入面嘅 `SLIC3R_BUILD_TIME_UTC`，由
  `src/libslic3r/CMakeLists.txt` 寫入）。舊啲嘅 `SLIC3R_BUILD_TIME` 標記係構建主機嘅本地時間，冇時區偏移，所以唔能夠安全地轉換。
- 啟動畫面將個時刻轉換到用戶嘅時區並顯示日期。
  一個喺香港安裝發佈版本、而個發佈係喺 UTC 23:55 構建嘅用戶會睇到下一日，就係佢自己個鐘會顯示嘅日子。
- 發佈工作流（`.github/workflows/build_bambu.yml`，由
  `build_all.yml` 調用）用 `-DBBL_RELEASE_TO_PUBLIC=1` 配置，選擇咗「發佈」個字。冇用呢個設定構建嘅構建（`version.inc` 入面嘅預設係 `0`）會話「構建」。
- 同一個工作流運行會構建個應用同發佈佢個 `md3-v<N>` 發佈版，通常係一個鐘之內，所以構建日期就係發佈日期。跨越午夜嘅運行（用戶嘅時區）會話顯示個發佈頁面日期前面嘅日子；發佈頁面嘅時間標記係確切嘅發佈時刻。

## 語言

`src/slic3r/GUI/GUI_App.cpp` 入面嘅 `splash_release_date_text()` 通過語言模式服務翻譯
`Released %s` 同 `Built %s`：

- 英文字會得到英文日期：日、英文月份名字、年份；
- 廣東話字會得到香港格式：年年年年年月月日日；
- 當廣東話翻譯目錄冇呢行嘅條目，廣東話模式會話顯示英文行加英文日期，永遠唔係英文句子包住中文日期；
- 雙語模式會堆疊個兩行，啟動畫面會將佢哋設定為置中。

## 版面

呢行用屬件個 `Body_13` 字體用啞色文字顏色，置中響 480 x 480 DIP 啟動畫面，喺標題同點心 logo 之間嘅空隙（100% 縮放下 72 DIP）。假如標題變得高過呢個空隙，例如大系統字體大細嘅雙語行，logo 會向下移所以日期永遠唔會同佢重疊。

## 失敗模式

- 個版本標題有空或格式錯誤 UTC 標記嘅構建會話唔畫日期行；啟動畫面其他部分保持唔變。
- 日期屬於構建，唔係發佈時刻。個發佈冇發行嘅運行只會將佢嘅套件留做工作流成品，個別樣會顯示佢哋個構建日期連同「發佈」個字。

## 安全考量

日期編譯咗入二進制檔。冇嘢喺啟動時取得，冇發出網絡請求，同冇讀用戶資料。

## 驗證

- `node --test ui-md3/tests/splash-release-date.test.mjs` 釘咗 UTC 標記、
  啟動畫面繪製同語言路由，同檢查廣東話翻譯目錄翻譯個兩行。
- 發佈工作流嘅呢個改變嘅構建係編譯檢查。
- 包含呢行嘅第一個發佈嘅啟動畫面會喺全部三個語言模式拍咗相做視覺檢查。
