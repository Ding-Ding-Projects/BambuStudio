# 核取方塊同滑桿動態效果

共用自訂核取方塊同滑桿，而家透過現有弱擁有者 `MD3::Motion::Anim` 持有短暫裝飾強調。呢個係源碼實作；託管編譯同繪製時序驗證仍待完成。

## 可到達控制項

Filament Setting Overrides 透過 `Tab.cpp` 嘅 `TabFilament::add_filament_overrides_page` 建立自訂 `CheckBox`。原生勾選值、不確定狀態同切換事件保持即時。選擇變化立即畫出最終勾號／橫線同輪廓，唔會淡入淡出。獨立外緣留喺原有點陣圖範圍內，喺 `short2`（100 ms）期間衰減。現有鍵盤焦點環保持即時並以原有強度繪製。停用點陣圖冇裝飾強調。建立圖形內容失敗時，繪製保留原有圖形。

共用滑桿嘅真實呼叫者包括 `StatusPanel.cpp` 風扇控制同 `MD3ColorPicker.cpp` alpha 控制。單憑通用欄位建構，唔作為特定設定欄位到達呢個實作嘅證據。取得焦點同開始拖曳會喺原有光環加入短強調脈衝；光環仍即時以原本靜止強度顯示。額外 alpha 喺 100 ms 由 24 衰減至零。失去焦點、釋放同失去捕捉立即收定。滑塊位置、軌道幾何、指標對應、值回呼同無障礙宣告唔會等動畫。冇加入指標延遲或者動畫數值濾波。

## 擁有權同中斷

每個控制項持有一個動畫器，喺基底視窗銷毀前停止。再啟動強調會取消上一世代。冇分離計時器、全域顯示掛鈎、完成操作、子視窗透明度或者延遲語意狀態變更。隱藏擁有者透過共用政策收定；自身隱藏事件亦停止裝飾工作。減少動態效果直接繪製最終狀態並收定進行中工作。停用控制項唔保留強調。

核取方塊主題改變同重新縮放，喺重建快取點陣圖之前停止脈衝。滑桿重新縮放、尺寸同配色變化會收定脈衝；繪製亦偵測即時強調色／背景色改變，先收定再畫。使用目前主題顏色，唔會內插過時顏色快照。全部裝飾留喺現有控制項幾何內。呢個係控制項回饋，唔係面板或者頁面內容動畫。

## 必須託管驗證

冇本機編譯、測試或者 UI 執行。喺精確建置候選驗證真實 Filament Setting Overrides、不發硬件命令嘅風扇滑桿，以及顏色揀選器 alpha 滑桿。保留原生狀態同回呼，配合真實時序畫格：

- 已勾選、未勾選同不確定變化，包括快速反轉同程式替換，確認即時圖形同焦點環不變。
- 鍵盤焦點、滑鼠拖曳、釋放同失去捕捉，證明數值同滑塊幾何即時跟隨輸入，靜止光環從不延遲。
- 隱藏／重開、動態中銷毀、停用狀態，以及脈衝前同期間更改減少動態效果，銷毀後冇回呼。
- 主題、強調色同 DPI 變化，保留最終顏色同點陣圖尺寸。
- 英文、粵語、雙語、淺深色、正常／最低尺寸，同實測 100/125/150/200% 顯示比例。

證據綁定來源提交、執行檔雜湊、實際控制項同輸入、量度幾何、比例同私隱判定。只有回呼嘅測試夾具唔證明圖形對比、裝飾外緣位置或者繪製時序。現有共用動畫器執行時夾具只涵蓋自己嘅生命週期合約，唔取代各配接器觀察。呢段驗證說明唔授權實體打印或者打印機傳輸。
