# 受限制時序視窗觀察

`scripts/md3/motion_temporal.py` 係供未來已安裝原生互動範圍選用嘅輔助，尚未接入驅動器或者工作流程。其源碼或者無產品合約唔聲稱任何執行時、擷取節奏、繪製動態或者合成結果。

## 介面同擁有權

現有託管驅動器可呼叫 `await capture_transition(binding, output_root=..., executable=..., package=..., tool_root=...)`。呼叫者必須已驗證發行、安裝收據、精確產品來源、執行檔／套件雜湊、請求語言／主題，同真實原生目標。輔助獨立檢查執行檔／套件位元組、驗證器工作目錄同輔助位元組、目前 run／attempt、目標程序開始時間、HWND、桌面、DPI、幾何同具名 Job 成員資格。產品來源中繼資料同語言／主題仍係呼叫者驗證綁定，唔係新獨立聲稱。

精確版本 1 綁定包含：

| 欄位 | 意義 |
| --- | --- |
| `schema`, `run_id`, `run_attempt`, `nonce` | 版本 1、託管呼叫同新 32 位十六進位 nonce |
| `source_commit`, `verifier_commit` | 獨立 40 位十六進位產品同觀察者提交 |
| `exe_sha256`, `package_sha256` | 之前已驗證發行位元組身分 |

| `roi` | `[left, top, right, bottom]`，客戶區內固定裝飾繪製區 |

使用 `RUNNER_TEMP` 下新輸出目錄。呼叫者必須喺自有桌面以 per-monitor-v2 執行緒 DPI awareness 執行輔助，位於現有 suspended-start、non-breakaway、kill-on-close 具名 Job 內。外層監督器硬限時最多 120 秒。只靠成員資格，輔助唔能證明監督器限時或者 Job 設定。

操作前準備兩個官方相容 MCP stdio session，使用固定於 `e6e42f2066d539256d6480401d7cef867f2b8dfe` 嘅現有工具 bootstrap。輔助將已安裝 `server.py`、`winio.py`、`process.py`、`processes.py` 與精確源碼 blob 比較，記錄 LF 正規化雜湊。接受 bootstrap 支援嘅 MCP SDK 1.x，最低 1.2，並記錄版本。唔安裝任何東西。觀察兩個伺服器 PID／開始身分同精確命令列，兩者都必須屬於呼叫者 Job。一個 session 擷取，另一個提交唯一授權點擊。冇加入直接原生擷取、輸入注入、widget 呼叫、桌面切換或者 UIA 遍歷。

## 四畫格觀察合約

輔助要求一個基線同輸入分派後約 25、60、180 毫秒三個畫格。呢啲係截止目標，唔係聲稱已達取樣時間。每個 MCP 請求記錄單調時間同 UTC 開始／結束界限。工具唔提供像素取得時間戳。慢畫格永不將餘下期限向後移，假裝達到預定節奏。

原生唯讀身分／幾何檢查包住畫格序列。輸入前同確認回覆時檢查精確目標子項。呢啲檢查同另一伺服器輸入分派唔係原子；目標改變令觀察失敗，呼叫者只可用可棄置自有產品桌面。每個 MCP 請求最多三秒；阻塞原生擷取或者 stdio 關閉，最終由外層 Job 期限限制。輸入作獨立非同步請求，喺 session 關閉之前等待完成，包括擷取例外。取消唔代表已提交輸入被撤銷。擷取呼叫內冇 sleep 或 UIA 遍歷。PNG 解碼同像素雜湊只喺連拍之後進行。

接受要求恰好四個有效畫格間隔、基線完全喺輸入之前、最終觀察喺分派至少 180 毫秒後開始，而且至少一個完整中間觀察間隔，喺輸入確認之後、分派後 100 毫秒之前。該中間區域實際 RGB 位元組必須與基線同最終區域都不同。兩個端點區域亦須不同；恰好返回基線嘅脈衝刻意排除於呢個初始兩狀態合約。量度只證明必要像素轉變，唔證明文字、顏色、對比、緩動、畫格率、無障礙或者語意操作正確。已提交輸入仍可能喺傳輸確認之後先消費。仍需人工審查真實畫格同驅動器負責嘅語意後置條件。

固定視窗擷取使用 `PrintWindow` 客戶區內容，輸出可能未合成。`native_layered_alpha_verified` 永遠為 false，呢啲畫格唔證明 `WS_EX_LAYERED` 進場透明度。要接受必須先有真實受控託管能力夾具。輔助永不擴大至整個桌面擷取填補缺口。由繪製擁有嘅控制項／選單轉場，如果真實畫格間隔同像素符合合約，可能合格。

## 限制、私隱同清理

只保留四張原始 PNG，每張最多 16 MiB、闊高各最多 8192、面積最多 16,777,216 像素。尺寸限制喺擷取前檢查；編碼大小限制喺每次返回後檢查。工具後端可喺知道編碼大小前配置有界點陣圖。畫格永不重建或者編輯。選定區域喺記憶體雜湊，唔產生裁切衍生圖。`temporal.json` 包含私有綁定、請求間隔、工具／驗證器雜湊、畫格雜湊同固定判定。收據同原圖都唔係公開輸出。

第一個伺服器啟動前已存在獨佔並 flush 嘅 `temporal-pending.json`。設定、輸入、觀察、session 關閉、伺服器退出證明或者外層期限失敗時，仍屬不確定。只有正常等待輸入完成，同驗證兩個伺服器退出，先容許改名為 `temporal-finished.json`。完成標記唔證明產品／桌面清理。外層呼叫者須證明整個 Job 已空，完成現有自有桌面還原／關閉，先以現有專用收件者加密證據。未知子程序或者桌面擁有權會阻止接受同加密。此輔助唔授權復原輸入，亦唔刪除任何東西。

返回摘要只有狀態、畫格數、處置要求同時序接受。`not_observed` 令時序接受失敗，但喺已驗證清理後保留真實畫格作受限制加密審查。`unverified` 同樣永不通過。唔列印原始協定輸出、例外文字、程序路徑同身分。整合前呼叫者須將此輔助納入驗證器雜湊 manifest，並明確白名單五個私有證據檔；現有證據限制唔可默默擴闊。
