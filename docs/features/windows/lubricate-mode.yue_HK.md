# 潤滑模式同打印旋律

潤滑模式會將熱床同打印頭行晒全程，等新上嘅油沿住導軌同絲桿搽勻。選項開咗嘅時候，每次開印都會行一次；喺 Device 頁亦可以隨時手動行。熱床郁緊嘅時候，Bambu Lab 打印機會好似貨車倒後咁嘀嘀聲，或者播你喺打印對話框揀嘅另一首歌。潤滑模式關咗嘅時候，揀咗嘅歌一樣會喺每次開印時播，任何模式都會，快速開印模式都唔例外。

呢個功能係為 Bambu Lab H2C 寫嘅，下面嘅例子全部用 H2C 嘅開始 G-code。

## 程序

`src/libslic3r/GCode/LubricateRoutine.cpp` 入面嘅 `lubricate_routine_gcode()` 按打印機嘅可打印範圍同可打印高度寫出移動，每邊留 5 mm：

1. `G90`，然後熱床去 Z 5 mm。
2. 熱床用 F1500 落到底再升返上嚟，行兩轉，每段最多 25 mm。每段開始前，蜂鳴器（`M1006`）播旋律嘅下一個音。
3. 打印頭用 F12000 行盡 X、行盡 Y，再行兩條對角線。
4. `M400`，然後再行一次打印機自己嘅歸零指令，因為熱床同打印頭已經停喺第二度。

## 每次開印

選項係流程設定 **其他** 頁 **特殊模式** 組入面嘅 `lubricate_mode`，喺 **快速開印模式** 下面。預設開啟，跟流程預設一齊儲存。**傳送打印工作** 對話框都有顯示，就係旋律列表上面嘅 **開印前潤滑**；喺嗰度開或者關會寫入流程預設同重新切片，所以送去打印機嘅 G-code 一定同個掣一致。開之前切好嘅打印板要再切一次先有程序，喺其他切片軟件切嘅檔案或者喺打印機螢幕開印就永遠冇。

開咗之後，`insert_lubricate_routine()` 會將程序放喺開始 G-code 最後一句完整歸零指令之後：即係 `G28`，唔係 `G28.<n>` 校準指令，亦唔係 `M622`/`M623` 韌體條件入面嗰句。H2C 上面係 `G28 Z P0 T250`，喺第一次歸零之後，所以程序喺已歸零嘅機上行。開始 G-code 冇普通 `G28` 嘅機（P2S 同 X2D）會喺程序前面加 `G28 ; home before lubricate mode`。

## 旋律

流程選項 `lubricate_melody` 記住揀咗邊首歌。喺 **傳送打印工作** 對話框入面、打印選項下面揀，個列表有搜尋欄。搜尋欄可以打普通文字，或者撳 `.*` 用正則表達式，撳調校掣就開共用嘅正則建構器；顯示名同英文名都會比對。揀歌會好似快速開印模式個掣咁寫入流程預設，所以傳送之前會重新切片。有冇接打印機都會顯示個列表。

| 旋律 | 音符 |
| --- | --- |
| 貨車倒後（預設） | 一個高音 B，重複 |
| 雙音警笛 | A 同 E |
| 上升嘀嘀聲 | C、E、G、高音 C |
| 歡樂頌 | 第一句 |
| 一閃一閃亮晶晶 | 第一句 |
| 給愛麗絲 | 開頭 |
| 西敏寺鐘聲 | 頭四分一 |
| 靜音 | 無聲 |

潤滑模式開咗，熱床每行一段就播一個音，循環播，所以貨車歌大約每秒嘀一聲。關咗嘅話，Bambu Lab 打印機會喺開始 G-code 之前完整播一次。揀靜音就兩樣都唔響。

## 喺 Device 頁

**潤滑** 掣喺 Device 頁搖桿下面。撳落會先問一次，因為行全程會撞到板上嘅嘢，確認之後就用打印機預設嘅可打印範圍同高度、流程預設嘅旋律，將 `G28` 同程序傳去打印機。佢同搖桿一齊停用，打印機忙緊嘅時候撳咗都唔會做嘢。

## 驗證

已檢查：程序同插入規則嘅獨立測試、所有 Bambu Lab 開始 G-code 模板嘅普查、喺砌好嘅程式為 H2C 切一粒正方體（程序落喺 `G28 Z P0 T250` 之後，熱床每段前一個音），同埋 [design/lubricate-2026-11/captures](../../../design/lubricate-2026-11/captures/README.md) 入面選項、Device 頁掣同打印對話框列表嘅截圖。未檢查：喺真打印機上面行。`M1006` 同移動嘅時間關係（`M1006 W` 會唔會等個音播完先行下一步）係要打印機先答到嘅問題。
