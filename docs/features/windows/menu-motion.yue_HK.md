# 選單動態效果

原生 Material 選單而家持有自己嘅進場控制器。打開或者重開會喺原生可見後排定 100 ms 進場；關閉同銷毀停止控制器並恢復透明度，之後先繼續正常清理。現有子選單／搜尋建構器關閉例外不變。冇離場延遲或者延後命令回呼。

原生清單將懸停層內插 100 ms，篩選結果改變時以 100 ms 淡化裝飾前緣更新。文字、快捷鍵同必要圖形顏色喺每個進度值保持精確。篩選即時改變真實結果清單、選擇同幾何。反轉由目前懸停權重開始。鍵盤選擇仍即時反白。減少動態效果畫出最終狀態；隱藏擁有者收定，銷毀擁有者透過共用弱擁有者動畫器取消。原有子選單懸停延遲仍係獨立互動規則，唔係動畫完成回呼。空結果文字同點陣圖圖示保持即時。

畫布彈出視窗由 ImGuiWrapper 持有以 context、window ID 同 popup ID 作鍵嘅有界時間線。popup ID 防止重用深度視窗繼承其他選單進場。活動可見彈出 draw list 由 60% 至完整透明度做 100 ms alpha 進場。實作唔改頂點位置、裁切矩形、輸入矩形、選擇或者生命週期。實際渲染前後儲存並恢復原有頂點顏色，包括例外展開。每次 render 最多保留 128 條彈出時間線、1024 個已訪 draw list 同 262144 個頂點顏色；超出表面保持完全可見。

版本庫內 ImGui API 提供 Active、Hidden、Appearing、PopupId、FrameCount 同 Time。現有 GLCanvas3D 閒置路徑喺 render 後消費 requires_extra_frame。只有未收定進場要求額外畫格；關閉彈出項會失去時間線，減少動態效果即時收定保留時間線。冇 ENABLE_ENHANCED_IMGUI_SLIDER_FLOAT 嘅建置保留即時繪製，因為其畫布唔消費呢條排程路徑。畫布結果清單變化同懸停層唔屬於呢個進場單元。

模態彈出項，包括滑桿 Custom G-code、Jump to Layer 對話框同量度距離彈出項，而家共用呢條路徑。模態輸入阻擋保持即時。模態 draw list 亦包含暗化背景矩形，所以喺 ImGui 原有 DimBgRatio 淡化上，再參與進場。活動子 draw list 透過 ParentWindow 繼承最近活動可見彈出祖先時間線。巢狀彈出項有獨立時間線。遍歷喺普通非子視窗、隱藏祖先或者深度 64 停止，永不淡化任意頁面內容。稍後出現嘅子項唔重啟擁有者進場。每個 draw list 只修改一次。

RegexBuilderPopup 而家為實際顯示生命週期持有暫態進場控制器。顯示／隱藏觀察只接受自己嘅事件物件；明確 Dismiss、原生 OnDismiss 同銷毀喺正常清理前停止／恢復控制器。PopupAndFocusPattern 保留原有原子焦點路徑，冇額外啟用擁有者或者延後模式操作。適用於原生 SearchField 同畫布建構器橋接。

## 驗證同剩餘覆蓋

呢個係源碼實作，唔係已驗證繪製行為。冇本機建置、測試或者 UI 執行。託管編譯同精確套件時序擷取仍待完成。驗證根同巢狀選單、反覆打開／關閉、搜尋替換、空結果、鍵盤選擇、快速懸停反轉、建構器焦點擁有權、銷毀，以及進場中減少動態變化。確認收定後閒置畫格請求停止，render 後原有頂點顏色冇遺留修改。真實擷取須綁定來源同執行檔雜湊、語言、主題、實測比例同視口。涵蓋英文、粵語、雙語、淺深色、正常／最低尺寸，同實際 100/125/150/200% 比例，包括中間文字對比同裁切。靜態圖片唔證明時序、畫格排程或者生命週期行為。

目標使用版本庫內原生設計參考。此任務冇 Material Designer 建立／匯出工具，而且禁止本機程式執行。原型或者源碼預覽唔取代必要託管時序同排列證據。實際原生頁面內容合成仍未解決；裝飾選擇回饋唔係內容交叉淡化。全介面動態尚未完成。

## 畫布列同篩選裝飾

畫布選單列即時保留最終文字、快捷鍵、圖示、背景同焦點繪製。獨立 100 ms 直線喺剩餘左內距內改變長度。共用自訂 selectable 涵蓋子選單標題同直向選單項目。明確產品掛鈎亦涵蓋畫布 combo 選項、Assembly Export 列同已篩選字體清單。冇足夠可見空餘內距嘅列會跳過裝飾，唔遮內容或者擴闊裁切矩形。點擊、關閉、篩選、選擇、排列同點擊區都唔等動畫。

wrapper 持有嘅 map 最多保留 128 個裝飾。鍵包含最近彈出視窗同彈出識別碼、目前子視窗、實際提交項目識別碼同裝飾類型。使用前檢查所屬 ImGui context。同一畫格重複提交唔會前進兩次；未見項目喺 render 到期。懸停反轉先取樣目前值，再選新目標。已儲存或者作業系統減少動態要求即時收定。只有可見活動內插要求額外畫格，冇計時器或者非同步回呼。

搜尋回饋使用現有分隔帶，以及目前查詢、已接受可見遮罩同不可用狀態嘅簽章。實際結果改變可以重啟裝飾；結果不變嘅反覆工作器輪詢唔可以。所有結果語意同最終內容顏色不變。Assembly Export 掛鈎喺工具提示替換最後項目中繼資料之前，保存已提交項目身分。

呢啲呼叫者掛鈎同時序行為只限源碼，仍需託管編譯同真實中間擷取。尤其驗證字體預覽內距、巢狀同子彈出身分、即時減少動態、懸停反轉、非同步正則完成、隱藏項目到期同閒置畫格收定。呢次變更冇聲稱新增已執行測試或者繪製覆蓋。

託管純政策執行檔包含 33 個新增結果，使用實際選單篩選繪製函式，合共 59 個。驗證四個進度值同兩種減少動態狀態下精確內容顏色、標題對比最少 4.5:1，以及拒絕低於門檻嘅舊 60% 混色。現有 59 個結果喺託管執行 `37101358501`、版本 `c7aefb4b84f31a4bc2519d8052ac78b3ccaa3a17` 通過。佢哋係源碼顏色算術，唔係像素，亦唔驗證上面較後加入嘅畫布列／篩選裝飾。
