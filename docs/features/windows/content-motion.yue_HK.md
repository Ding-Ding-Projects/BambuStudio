# 內容轉場擁有權同待完成覆蓋

內容擁有者喺源碼版本 `8a275071732f58b181e2e298eec493754d9c899a` 已作檢查。呢個單元喺現有橫向 notebook 底線同直向分頁按鈕標記實作有界選擇回饋，冇實作頁面內容透明度或者交叉淡化。原生暫態進場同其他分頁指示另有文件；兩者都唔代表頁面內容已有動畫。

## 已實作選擇回饋

`ButtonsListCtrl::SetSelection` 同 `TabButton::SetSelected` 即時更新選擇，然後用共用短時長同緩動，將現有標記顏色由 65% 強調至完整語意 Primary 顏色。標籤、已選頁面、焦點、操作分派同標記幾何唔會等待或者移動。標記永不完全透明。背景同目標顏色喺繪製時解析，保留目前主題同工作區配色。

每個控制項持有一個共用動畫器。替換選擇停止上一世代，取消選擇停止直向標記，銷毀停止計時器。弱擁有者綁定令隱藏控制項收定，並取消已銷毀擁有者。減少動態效果即時畫出最終標記；運行中計時器喺下一次交付觀察偏好。實作冇加入原生 alpha、頁面快照、覆蓋層、合成器或者隱藏輪詢迴圈。

## 舊 Markdown 工具提示

`MarkdownTip::ShowTip` 喺 `NDEBUG` 建置返回 `false`。目前 `src` 樹冇 `ShowTip`、`AttachTo` 或 `DetachFrom` 嘅外部呼叫者。剩低外部呼叫係 `PresetUpdater.cpp` 嘅 `Reload` 同 `MainFrame.cpp` 嘅 `Recreate`／`ExitTip`，佢哋唔會建立單例。因此，喺呢個實作加入動畫，唔會令可到達發行表面產生動畫。其進場效果係唔適用於目前可到達發行版本，唔係已完成動畫。目前原生參數工具提示另有自己嘅進場控制器。

如果將來功能刻意恢復呢個舊表面，網頁文件必須自己擁有內容透明度，唔可以向子控制代碼套用 alpha。安全實作需要精確目前檢視同文件身分、載入同顯示世代、已儲存同系統減少動態狀態，以及隱藏、替換、附加、重新載入同銷毀時取消。目前空白 `OnLoaded` 回呼、標題驅動待處理指令，同可替換 `_tipView` 唔提供呢個合約。本機 `styled.html` 容器同內附 `showMarkdown` 內容替換係可能實作點，唔係目前可到達或者轉場完成嘅證據。

## 原生頁面容器

`Notebook::DoShowPage` 同 `Tabbook::DoShowPage` 直接呼叫頁面嘅 `ShowWithEffect`／`HideWithEffect`。預設效果係 `wxSHOW_EFFECT_NONE`、零逾時，目前源碼冇呼叫者選擇其他效果。因此選擇、焦點同頁面變更事件保留原有即時行為。

呢啲容器唔持有任意子頁面嘅合成影像：

| 容器擁有者 | 實際內容 |
| --- | --- |
| `MainFrame` notebook | Home 網頁內容、裝置面板、專案內容同校準 |
| `MonitorPanel` tabbook | 狀態、儲存、韌體同診斷面板 |
| `CalibrationPanel` tabbook | Pressure advance 同流量精靈頁面 |
| `Auxiliary` tabbook | 專案資料、圖片、材料同組裝指引 |
| `MultiMachinePage` tabbook | 裝置同本機／雲端工作管理器 |

只靠呢兩個容器類別，冇安全通用內容透明度實作。向任意子控制代碼或者 OpenGL 控制代碼套用分層 alpha，唔係接受嘅轉場路徑。阻塞原生顯示效果、延遲已選頁面、移動即時點擊區，或者將擷取嘅舊頁面假作即時內容，都會改變互動合約。

下一單元必須選定一個可到達內容擁有者，具有實際繪製或者網頁合成器路徑。擁有者可以接受世代綁定視覺轉場，而選擇同焦點即時改變。原生控制項需要擁有者繪製裝飾或者真正支援嘅合成層；網頁需要自己已載入文件橋接；重型畫布頁面需要渲染器支援。呢啲係獨立實作範圍。已實作選擇回饋冇加入全域頁面掛鈎或者推測性原生效果。
