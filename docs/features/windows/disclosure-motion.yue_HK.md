# 展開狀態回饋

Prepare Filament 標題同 Monitor 連線詳情按鈕保留即時展開／收合。原有內容可見性、捲動、排列同點擊目標唔會動畫化。展開時，一條兩 DIP 闊裝飾直線由短置中標記增長成較長標記，使用共用 100 ms 標準轉場。收合由目前已繪製長度反轉。

## 擁有權同行為

`Plater.cpp` 嘅 `FilamentDisclosureHeader` 喺原有標題左內距內繪製。標題標籤點擊同背景點擊，都喺改變可見性同排列之後更新直線。AMS 同步展開耗材清單時亦更新直線。標籤同調色盤圖形喺轉場全程保留完整語意顏色。

`SideTools.cpp` 嘅 `ConnectionDisclosureBanner` 喺警告橫幅現有左 sizer 邊距繪製。獨立 `ScalableButton` 箭嘴保留原有點陣圖、懸停、鍵盤焦點繪製同幾何。橫幅 `StaticBox::doRender` 覆寫喺原有按鈕內容之前加入直線。箭嘴即時改變。展開狀態讀取真實詳情面板可見性；隱藏詳情嘅狀態更新會重設箭嘴同直線，唔重播動態。重複不變狀態更新唔會重啟或者停止轉場。呢個亦防止重新連線後過時展開旗標，令下一次點擊關閉本來已隱藏嘅面板。

每個控制項持有一個 `MD3::Motion::Anim` 並綁定自己視窗。重啟取消上一回呼，由目前長度開始。直接隱藏即時停止同收定。祖先隱藏透過共用擁有者可見性檢查，喺下一計時通知收定，唔會保留隱藏輪詢計時器。銷毀停止成員動畫。停用控制項同共用減少動態偏好收定至最終長度，包括轉場中偏好變更。繪製讀取目前語意顏色同 DPI，冇快取顏色或者實體像素幾何。

呢啲直線係補充狀態回饋，唔會調暗語意文字、動畫化焦點環、淡化子視窗、延遲命令或者移動點擊目標。冇新標籤、持久設定、網絡操作或者匯出。現有翻譯同個人詞彙處理不變。

## 驗證狀態

只作源碼檢查。冇本機編譯、測試或者程式執行。共用動畫事件迴圈夾具係獨立證據，唔證明呢啲控制項嘅繪製或者事件交付。

下一次已安裝 Windows 驗證須保留每次點擊圖片同有界時序序列：

- Prepare Filament 標籤同背景切換、快速反轉、AMS 觸發展開，以及轉場中切走。
- Monitor 連線警告、展開／收合、重複不變狀態、重新連線隱藏詳情，以及新斷線後一次展開。
- 互動前同轉場中減少動態效果、直接同祖先隱藏、銷毀、主題同 DPI 變化。
- 完整強度文字、圖形同焦點環對比；直線留喺原有內距而唔遮內容；排列、捲動同點擊區不變。

涵蓋正常同最低支援客戶區、英文／粵語／雙語、淺深色，同實際 100/125/150/200% 比例。Monitor 證據需要真實可到達斷線裝置狀態；不可用裝置夾具必須保留未驗證狀態。唔需要實體傳輸或者打印。
