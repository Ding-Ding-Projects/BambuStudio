# 介面動態基礎

偏好設定包括 **Interface motion**，使用現有可搜尋原生選擇控制項。**System** 為預設，跟隨作業系統客戶區動畫偏好。**Reduce motion** 亦要求支援嘅轉場即時顯示最終狀態。兩個選擇都唔會違反作業系統偏好強制動畫。本機設定鍵 `motion_preference` 儲存 `system` 或 `reduced`；缺少或者無效值正規化為 `system`。普通設定儲存／載入路徑跨重啟保留選擇。英文、粵語同雙語顯示使用現有翻譯路徑。

`MD3::Motion::reduced()` 每次呼叫讀取設定。活動中共用 `Anim` 喺下一次計時交付收定，通常 16 ms 後，視乎 UI 事件迴圈可用情況。冇阻塞等待或者延遲輸入操作。現有開關、相機同風扇呼叫者亦會觀察已儲存偏好。

新動畫呼叫者可提供弱視窗擁有者。隱藏擁有者收定至最終狀態，唔啟動另一計時器；動態中銷毀擁有者，喺下一次計時交付取消視覺同完成回呼。可選 `owner_lost` 回呼只作資源清理，永不執行使用者操作。`FadeIn` 使用此綁定，完成或者失去擁有者時延後刪除動畫器。冇擁有者嘅現有呼叫者保留原有語意。重啟同銷毀仍令上一回呼世代失效。

呢個係基礎，唔係完整全介面動態。面板切換、工具提示轉場、ImGui 選單轉場，同通知／進度政策整合，仍喺 [`design/interface-motion.md`](../../../design/interface-motion.md) 待完成。冇全域掛鈎將每個視窗動畫化，子控制項或者 OpenGL 表面亦唔可以隱含取得頂層分層視窗淡化。

呢次變更冇本機編譯、測試或者 UI 執行。託管編譯同政策結果仍待完成，之後須真實偏好選擇／重啟同時序證據。測試中斷／重啟動畫、擁有者銷毀、隱藏、動態中偏好變化、焦點／輸入同穩定最終狀態。使用精確已安裝執行檔雜湊同來源版本。擷取英文、粵語、雙語、兩個主題、正常同實測最低尺寸，以及實際量度 100/125/150/200% 比例。單張靜態圖片唔能證明轉場、時長或者冇閒置計時器。

## 原生狀態顏色同分頁指示

Button 同 StaticBox 繪製路徑而家向其 StateHandler 要求內插顏色。已登記邊框、背景同文字顏色轉場 100 ms；語意讀取、啟用狀態、焦點同輸入分派仍同步。反轉會快照目前繪製顏色，唔會跳返舊端點。未轉換 StateHandler 使用者保留即時繪製，唔啟動動畫計時器。未登記顏色保持即時。

橫向 TabStrip 啟用時，已繪製底線移動 250 ms。排列、排序、停靠同調整尺寸取消轉場並使用目前幾何。直向選擇膠囊內插 100 ms。文字粗幼、無障礙選擇、焦點環同所有點擊區即時改變。兩條路徑使用弱視窗擁有者綁定，並喺銷毀停止動畫器。動畫回呼只賦值視覺狀態同要求繪製，唔分派語意事件或者進入巢狀事件迴圈。共用世代檢查保障重啟同回呼中銷毀。

減少動態效果即時繪製最終顏色／指示。共用動畫器喺下一次事件迴圈交付收定隱藏擁有者或者變更偏好。現有互動卡子項離開監察器只喺可見時以 100 ms 運行，包括減少模式，因為進入子項可能抑制父項離開事件。佢做範圍觀察，唔係持續裝飾動態；隱藏或者停用卡喺下一次交付停止。減少模式顏色即時切換。

現有託管政策執行檔而家加入九個實際內插結果：端點同超範圍限制、中途反轉、雙向顏色捨入同精確通道端點。合共 26 個結果喺呢個版本仍未執行。唔證明 wx 計時交付、實際擁有者銷毀、轉場繪製對比、子項離開行為或者執行時分頁幾何。呢啲須上面描述嘅已安裝時序同排列矩陣。面板內容、未轉換控制項同其他清單項目仍待完成。
