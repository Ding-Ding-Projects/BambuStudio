# 安靜工作流程

切片啟動時唔再先彈首次使用影片邀請。自動切換器介紹、隨機切片提示、啟動食物卡、Helio 指導同新耗材標記唔再打斷工作。已儲存教學旗標亦唔會重新啟用佢哋。RFID 記錄仍透過同步服務進行。

背景程式檢查同自動安裝仍可用，但只有明確更新檢查會顯示下載、就緒或者後備提示。自動預設同步唔會打開更新邀請。說明、手動設定、已設定工作區提醒、驗證訊息、進度、取消同未儲存工作確認仍保留。

切片進度卡只含進度同其控制項，冇教學面板。材料同裝置診斷與推廣文案保持分開。

驗證包括針對已停用自動產生者嘅源碼邊界回歸合約。原生建置同執行時驗證另行記錄，唔會由呢個合約推定。

H2S 脆性耗材指引使用現有非阻塞通知卡。只有選取 Wiki 連結先會打開，亦永遠唔會取消切片。已儲存首次使用旗標唔會恢復舊模態視窗。
