# 安靜工作流程

切片開始時唔會再彈出首次使用嘅影片邀請。自動切換器介紹、隨機切片貼士、啟動時嘅食物卡、Helio 教學同新耗材標記都唔會再打斷你做嘢。以前儲存咗嘅教學旗標唔會再將佢哋開返。RFID 記錄仍然經同步服務運行。

背景應用程式檢查同自動安裝照樣可以用。背景更新只會顯示唔阻住你嘅通知：新版本準備好就出準備好橫幅；新嘅發佈準備唔到，就每個發佈出一次失敗通知。只有你自己撳檢查更新，先會開下載對話框或者「已經係最新版本」訊息（睇[應用程式更新](app-updates.md)）。自動預設同步唔會開更新提議。說明、手動設定、設定咗嘅工作區提醒、驗證訊息、進度、取消同未儲存工作嘅確認全部照樣保留。

切片進度卡只有進度同佢嘅控制項，冇教學面板。物料同裝置診斷同宣傳文字分開處理。

驗證包括一份針對已退役自動提示來源嘅原始碼邊界回歸合約。同一份合約要求應用程式更新路線入面每個下載對話框都要有明確請求先出現，而兩個背景更新通知都必須係唔阻住你嘅通知。原生構建同執行時驗證另外記錄，唔可以由呢份合約推斷。

H2S 脆身耗材指引用現有唔阻住你嘅通知卡。佢嘅 Wiki 連結只會喺你揀咗先打開，亦永遠唔會取消切片。已儲存嘅首次使用旗標唔會令以前嘅模態視窗返嚟。
