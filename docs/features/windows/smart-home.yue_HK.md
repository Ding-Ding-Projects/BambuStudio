> [!IMPORTANT]
> 打印機移交實作同聚焦嘅 Windows Release 目標喺目前嘅工作目錄中已經完成。30 個測試用例同 267 個斷言嘅原生測試套件同埋五個聚焦嘅 CTest 項目都通過咗；完整嘅 Release GUI 構建同英文原生 720×760/520×480 裁剪檢查都通過咗。原生雙語捕獲、實時 Home Assistant 執行時路徑、物理打印機成功、託管 CI/release 裁決同遠端發佈證明係分別記錄喺 [issue #16](https://github.com/Ding-Ding-Projects/BambuStudio/issues/16) 入面。本節記錄咗實現同本地驗證嘅邊界；佢冇聲稱呢啲係實時或託管嘅結果。

## 打印機選擇

兩條移交路徑都會收集 Bambu Studio 目前能夠訪問嘅打印機，嚟自本地同登入機器地圖。當所有呢啲值都可用時，先至會包括一部打印機：

- 非空嘅序列號；
- 目前嘅 LAN 地址；
- 目前嘅 LAN 訪問碼；同
- 喺活躍 Bambu Studio 會話中嘅訪問權限。

重複嘅序列號會被移除。當同一部打印機都出現喺登入賬户地圖時，本地發現記錄會勝出，因為佢通常有最新鮮嘅 LAN 地址。負載包含 `serial`、`host`、`access_code` 同可選嘅顯示 `name`。

對話方塊會清楚地說明訪問碼係一個認證憑證，喺任何一個操作之前。透過打開對話方塊，分享絕不會被啟用。

## 路徑 B：用已配置嘅 Home Assistant 令牌添加

**將我嘅打印機添加到 Home Assistant** 係一個明確嘅、用戶發起嘅傳輸：

1. 輸入 Home Assistant 基礎 URL 同一個長期有效嘅訪問令牌。
2. 選擇 **將我嘅打印機添加到 Home Assistant**。
3. 檢查認證披露。確認預設為 **否**。
4. 如果確認，Bambu Studio 會對每一部可訪問嘅打印機呼叫一次
   `POST /api/services/bambu_lab/add_printer`，內容如下：

   ```json
   {
     "serial": "printer serial",
     "host": "printer LAN address",
     "access_code": "printer LAN access code",
     "name": "optional printer name"
   }
   ```

認證確認使用共享嘅響應式訊息對話方塊殼。佢嘅可選「以後唔再顯示」文字係喺一個獨立嘅包裝頁腳行入面，而操作按鈕會喺可用嘅工作區寬度無法容納一行時堆疊。共享嘅行為有通過靜態裁剪協議。英文智能家居喺 720×760 同聲明嘅 520×480 最小值下嘅檢查都發現同修復咗一個相鄰嘅原生缺陷：`make_responsive_action` 曾經將 **Close** 同媒體操作等文字按鈕擠進咗 44 DIP 寬度，而唔係用 44 DIP 作為佢哋嘅最小高度。原生雙語確認捕獲仍然待定。

隨附嘅 [`Ding-Ding-Projects/ha-bambulab`](https://github.com/Ding-Ding-Projects/ha-bambulab)
集成提供咗該服務。冷啟動嘅 Home Assistant 安裝需要 `configuration.yaml` 入面嘅 `bambu_lab:`，咁嘅話服務先至會喺任何打印機被配置之前註冊。

操作係非同步嘅。按鈕會喺請求進行中時禁用，同進度、完全成功、部分成功或失敗會通過一個角落通知嚟報告（對話方塊狀態係備用）。計數會說明請求被 **處理** 咗，因為冪等性 2xx 回應可能表示打印機已經被配置而唔係新建立。失敗會識別打印機序列號同 HTTP 狀態碼，但唔會回顯回應體，佢可能包含認證憑證。一個匯入擁有一個單一工作者，第二個匯入會被拒絕直到佢完成，而一個請求最多處理 32 個去重嘅打印機。喺單一飛行匯入中，請求喺四寬波浪中執行。因此，完整批次嘅 32 個無法訪問嘅打印機最多佔用八個 30 秒超時波浪，而唔係 32 個序列超時。

### 令牌傳輸政策

每個 Home Assistant Bearer 令牌請求（唔只係打印機移交）都會喺打開網絡連接之前被拒絕，除非佢嘅基礎 URL 係：

- `https://…`；或
- `http://localhost…` 或明確嘅 IPv4 環回地址。

無加密嘅 HTTP 到 LAN 主機名或 LAN 地址、格式不當嘅 URL、不支援嘅協議同包含用戶資訊嘅 URL 都被拒絕。呢個政策都涵蓋實體列表、媒體控制、TTS 呼叫同警告燈服務。佢會防止 Home Assistant Bearer 令牌同打印機訪問碼通過無加密嘅遠端 HTTP 發送。裝有認證嘅請求都禁用咗 HTTP 重定向跟蹤，所以 Home Assistant 回應無法將 Bearer 或打印機負載重新播放到唔同或降級嘅目標。Libcurl 嘅冗長協議跟蹤對呢啲請求被禁用咗，所以授權標題唔會進入 stderr 或捕獲嘅診斷；未處理嘅 3xx 被報告為錯誤。回應喺解析之前被限制為服務呼叫嘅 1 MiB 同實體狀態列表嘅 4 MiB。

### 效能同關閉邊界

Home Assistant 工作唔會為每一次點擊建立一個操作系統線程：

- 普通服務呼叫使用四個擁有嘅工作者同最多 64 個等待嘅交易；
- 實體刷新使用一個擁有嘅工作者，而對話方塊允許一個活躍刷新同把重複嘅連接請求合併成一個最新重播；
- 實體請求接受最多四個唯一嘅域、解析最多 512 個匹配嘅後端結果，同通過一個 Freeze/Set/Thaw 更新最多渲染 256 個匹配嘅行；
- 音量變化被合併 200 毫秒，所以拖動滑塊會發送最新值，而唔係每個刻度一個請求；
- 揚聲器、燈同打印機列表喺工作被排隊之前都去重同限制為 32；路徑 B 喺四寬波浪中執行打印機請求；
- 持久化嘅揚聲器/燈列表最多檢查 256 個分號分隔嘅段同 64 KiB，拒絕超過 256 字節嘅值，最多保留 32 個唯一嘅活躍值，同唔會靜默重寫手動編輯嘅超出限制嘅配置；同
- 應用關閉會停止收入、取消活躍嘅 curl 傳輸、抑制遲到嘅 wx 回調、只刪除未開始嘅交易，同聯接每個擁有嘅工作者。

警告燈工作係一個不可變嘅、序列化嘅交易，而唔係無關嘅排隊呼叫：快照、閃光、還原，然後是第二個冪等性還原。特定於代的動態場景只有當至少一個還原成功時先至會被刪除；如果兩個都失敗，佢仍然可用於手動恢復。目標 URL、授權值同代絕對唔會遷移到另一個交易。如果關閉喺場景建立之後但閃光開始之前到達，冇野要還原，所以未使用嘅場景會立即刪除，帶有限制嘅關閉超時。一個回歸斷言咗確切嘅建立/刪除序列。
如果關閉中斷咗閃光，恢復會使用同一快照加兩秒還原/刪除請求邊界，限制恢復傳輸等待到大約四秒，當 Home Assistant 唔可達時。

## 路徑 A：冇 Home Assistant 令牌嘅短期本地發現

**分享發現五分鐘（冇 Home Assistant 令牌）** 喺選定嘅 LAN 介面上建立咗一個臨時功能：

- 切換預設為 **關閉** 同佢嘅狀態唔會被持久化；
- 啟用佢會快照目前可訪問嘅打印機數據；
- 一個包含超過 240 個隨機位嘅新鮮 URL 安全配對令牌被生成用於該分享視窗；
- Bambu Studio 綁定咗一個認證嘅 HTTP 端點到普通預設路由上嘅 RFC1918 或共享地址空間 IPv4 地址同一個操作系統選擇嘅非特權端口，而唔係宣傳一個主機專用嘅 WSL、Hyper-V 或容器適配器，即另一個 LAN 設備無法訪問嘅；
- 佢解析咗選定介面嘅真實前綴長度同只對該確切連結上可用嘅發送地址回答 mDNS，拒絕佢嘅網絡/廣播地址同公開、環回或連結本地發送；
- 佢通過 mDNS 宣傳 `_bambu-slicer._tcp.local.`，帶 `pairing` 同 `name` TXT 記錄加埋匹配嘅 PTR、SRV 同 A 記錄；
- Home Assistant 從確切嘅 `GET /bambustudio/printers` 端點取回打印機負載，帶 `Authorization: Bearer <pairing-token>`；同
- Home Assistant 仍然會呈現一個發現卡同要求用戶喺匯入之前確認。

對話方塊會自動喺五分鐘後關閉分享。更早關閉切換、關閉對話方塊、到達該到期或銷毀佢嘅服務對象都會停止 HTTP 服務、關閉活躍會話、發送零 TTL mDNS 再見同丟棄配對令牌。重新啟用分享會用唔同嘅令牌開始一個新嘅五分鐘視窗。

端點係刻意狹窄嘅。佢只允許一個確切嘅方法同路徑、需要恰好一個有效嘅授權標題、限制請求標題同目標長度、喺五秒後逾時請求、允許最多 16 個並發會話、限制回應為 64 KiB、限制優惠為 32 部打印機、同限制每個欄位為 256 字節。回應使用 `Cache-Control: no-store`、`X-Content-Type-Options: nosniff` 同 `Connection: close`。格式不當或超出限制嘅供應商數據得到一個通用 `503` 回應。授權嘅取回分享一個突發四、每秒一個請求嘅令牌桶，同喺佢耗盡時返回 `429` 加 `Retry-After: 1`。第一個有效嘅清理快照被快取用於分享視窗，所以重複授權嘅請求唔會重複序列化打印機認證憑證。配對令牌都唔會被記錄。

mDNS 查詢收入使用一個全球突發嘅八個，每秒補充一個令牌喺任何回應分配之前。回覆被端點/交易 ID 去重、排隊最多八個待定數據包帶一個發送活躍、同以 50 毫秒為間隔。停止同重新開始會取消舊計時器同丟棄舊隊列。

完整嘅 HTTP 協議同 Postman 工件係喺 [Home Assistant printer-discovery API](../api/home-assistant-printer-discovery.md)。

## 安全同隱私

打印機 LAN 訪問碼係認證憑證。兩條路徑都只會喺一個明確操作之後傳輸佢哋，但佢哋有唔同嘅信任邊界：

- **路徑 B** 通過 HTTPS 發送 Home Assistant Bearer 令牌同打印機數據，除了無加密嘅 HTTP 允許用於同一部電腦上通過 localhost 名稱或 IPv4 環回地址嘅 Home Assistant 進程。
- **路徑 A** 係一個最多五分鐘嘅無加密 LAN 移交。配對令牌喺 mDNS 中被宣傳，所以 Home Assistant 可以發現佢；任何能夠觀察該廣播域嘅設備都可以都冇通過 Home Assistant 嘅確認屏獲取令牌同請求負載。只喺受信任 LAN 上使用呢條路徑，同喺 Home Assistant 匯入打印機之後立即將其關閉，而唔係等待到期。

唔好將配對令牌、Home Assistant 令牌、打印機訪問碼、端點回應或匯出嘅 Postman 環境粘貼到議題、日誌、截圖或原始碼控制中。普通嘅 `BambuStudio.conf` 匯出警告仍然適用，因為佢包含已配置嘅 Home Assistant URL 同長期有效令牌。

## 現有嘅 Home Assistant 控制

- **實體瀏覽器：** 共享嘅 `SearchField`（包括正則表達式構建器）通過實體 ID、友好名稱同目前狀態過濾 `media_player.*` 同 `light.*` 實體。長嘅友好名稱喺原生列表中保持水平可達，而唔係喺對話方塊邊緣被靜默裁剪。後端最多返回 512 個過濾嘅實體，列表最多渲染 256 個匹配嘅行，同當有更多匹配存在時一條狀態行會要求用戶優化搜尋。
- **媒體控制：** 上一個、播放/暫停、下一個同音量對選定嘅媒體播放器操作。
- **公告揚聲器：** **用作公告揚聲器** 附加選定嘅播放器到 `ha_speakers`；語音播報同絲材掃描器可以喺嗰度說話。對話方塊會解釋同強制執行 32 揚聲器限制。
- **警告燈：** 任何選定嘅 `light.*` 實體都可以喺打印機錯誤時閃紅色或喺打印完成時脈衝綠色。對話方塊會解釋同強制執行 32 燈限制。
- **卡住顏色守護：** 喺閃現真實房間燈之前，Bambu Studio 快照佢哋到一個特定代嘅 `scene.bambustudio_light_restore_<generation>` 同喺大約四秒之後還原該確切場景。還原被觸發兩次，係冪等性。如果兩個嘗試都失敗，特定代場景仍然可用於手動恢復。喺閃光之前取消會刪除未使用嘅快照，而唔係留下一個無法幫助恢復嘅場景。

## TTS 語音播報

- 語音播報係 **預設關閉** (`narrator_enabled`)。
- 佢使用一個序列化隊列：一次一句，同同一類別中較新嘅一行會替換佢嘅排隊前任。
- 一個 20 秒嘅每類別冷卻時間限制喋喋不休。錯誤行唔會被抑制，同喺每個有趣等級保留實際嘅失敗同恢復資訊。
- 佢從選定嘅機器播報打印機狀態變化同打印機錯誤碼。
- 輸出係本地 Windows SAPI 聲音加已配置嘅 Home Assistant 公告揚聲器通過 `tts.speak`。

## 失敗模式

| 條件 | 行為 |
| --- | --- |
| 冇 Home Assistant URL 或令牌 | 路徑 B 唔打開連接同聚焦 URL 欄。 |
| 遠端 `http://` Home Assistant URL | 所有 Bearer 令牌操作都被本地拒絕。 |
| 冇打印機帶訪問權限、LAN 地址同訪問碼 | 兩條移交都唔開始；警告通知解釋哪啲係缺失嘅。 |
| 用戶取消路徑 B 披露 | 冇打印機請求被發送。 |
| 部分路徑 B 請求失敗 | 成功同失敗計數被報告；失敗嘅序列號保持可見以重試。 |
| 所有 32 個路徑 B 請求到達佢哋嘅 30 秒逾時 | 四個請求執行每波，限制批次最多八個逾時波浪。 |
| 冇可用嘅 LAN IPv4 地址、端口或 mDNS 套接字 | 路徑 A 將佢嘅切換轉回關閉同報告具體啟動錯誤。 |
| 缺失、錯誤或重複嘅路徑 A 授權標題 | 端點返回 `401`，而唔係請求打印機數據。 |
| 授權路徑 A 請求預算耗盡 | 端點喺詢問數據供應商之前返回 `429` 加 `Retry-After: 1`。 |
| 錯誤嘅方法或路徑 | 端點分別返回 `405` 或 `404`。 |
| 超過 32 個可訪問打印機 | 兩條路徑都處理前 32 個同清楚地陳述額外打印機冇被包括。 |
| 超過 32 個已配置揚聲器或燈 | 對話方塊保留前 32 個，報告限制，同要求清除一個項目先至可以添加另一個。 |
| 服務隊列已滿或匯入已經活躍 | 新工作被拒絕，而唔係建立另一個線程或靜默增長內存使用。 |
| 關閉喺警告燈場景建立之後但閃光之前開始 | 未使用嘅場景會用關閉恢復逾時被刪除；冇還原係必要嘅。 |
| 無效或超出限制嘅打印機優惠 | 端點返回一個通用 `503`，而唔係反映敏感數據。 |
| 對話方塊喺分享時關閉 | HTTP 同 mDNS 停止；零 TTL 再見移除廣告。 |
| 五分鐘分享生命周期結束 | 切換關閉、會話關閉、零 TTL 再見被發送、同一個通知說訪問碼不再被提供。 |
