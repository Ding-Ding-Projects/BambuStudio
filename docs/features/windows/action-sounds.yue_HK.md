# 操作提示音

喺 **設定 > 其他 > 音效** 開關短提示音。開關可以搜尋，亦會出現喺命令面板，
沿用現有設定儲存方式，即時生效。首次使用預設開啟，保留原有詞彙拖放提示音；
升級唔會覆蓋已儲存選擇，排程設定亦可以暫時覆蓋。

| 操作完成結果 | 提示音 |
| --- | --- |
| 詞彙拖放或設定上載成功，完成快取替換同畫面更新 | Windows `Media/tada.wav` |
| 詞彙拖放、上載被拒絕，或者清除失敗 | Windows `Media/Windows Critical Stop.wav` |
| 設定清除成功，恢復原有字眼 | Windows `Media/Windows Notify System Generic.wav` |

音檔來自已安裝嘅作業系統，唔會下載或隨程式重新分發。檔案缺失或格式唔支援就保持安靜。
取消檔案選擇同學校模式限制唔會要求播放。一般 `.3mf`、`.stl` 模型拖放保持原有處理，
唔會當成詞彙錯誤；非 JSON 嘅不支援拖放提示唔屬於今次改動。

所有指定提示音經同一背景工作執行緒，使用獨立 WinMM 輸出控制代碼，順序播放而唔重疊。
最多保留 32 個待播要求，超出上限就唔播放，操作本身結果不變；呢個超載情況唔保證每次都有聲。
改音效或安靜設定、套用排程有效設定，都會取消當前同待播提示音，唔影響旋律預覽或其他程式。

安靜旁白同旁白安靜時段亦會令提示音靜音。啟用尊重專注輔助時，忙碌、安靜、簡報、全螢幕、
使用者離開同由程式控制通知等狀態會抑制提示音。播放期間會再查安靜時段同系統狀態。
程式冇另外嘅總音量設定，沿用系統／工作階段音量同靜音，絕不更改主機音訊設定。
單獨關閉旁白唔會關閉音效。

工作執行緒只收到結果列舉值同非敏感設定，唔會收到匯入檔名、對照內容或資料。
播放失敗唔改變驗證、儲存、畫面結果、慶祝動畫或輔助技術通知。其他平台暫時保持無聲。

## 驗證狀態

`tests/action_sounds_behavior.test.mjs` 以無聲平台替身執行實際服務、WAV 解析、排隊、取消同排程更新前段。
涵蓋跨午夜安靜時段、有效設定覆蓋、儲存選擇重建、重複結果、裝置不可用、損壞音檔同開啟裝置期間關閉音效。
移除排程取消或最後播放前檢查，對應負向測試都會失敗。

`tests/action_sounds_outcomes.test.mjs` 執行實際拖放、上載同清除回呼，核對每個完成結果只要求一次提示音，
取消、學校模式同模型分類亦有檢查。全部測試唔會令主機發聲。

呢啲測試唔代表原生裝置播放、真正重新啟動後設定保留，或者實際設定畫面已驗證。
原生建置、本地化、鍵盤操作、重新啟動、靜音／音量、已安裝音檔同裝置不可用嘅實機驗證仍然待完成。
