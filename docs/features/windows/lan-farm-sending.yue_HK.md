# LAN 農場發送同裝置合格性

農場列表通過裝置 ID 結合賬户同本地發現打印機。配對本地實例喺兩個源報告同一個 ID 時優先。儲存嘅本地認證同地址允許一部先前配對嘅打印機喺離線時保持列出。選擇持久化到六個不同嘅裝置 ID。

多裝置發送器現在當佢能夠驗證佢哋時帶同一個單一打印機路徑嘅同一個 `nozzle_mapping` 同 `nozzles_info` 欄。材料 `nozzleId` 跟隨目前打印板嘅有效左/右分配。固定雙噴嘴打印機需要一個目前打印板帶完整分配同一個匹配雙噴嘴預設。帶動態噴嘴架嘅打印機都需要一個目前裝置映射結果，佢解析每個用過嘅材料。負載喺導出前同任務建立前被檢查。

一個不完整打印板分配、缺失噴嘴預設、無效直徑或流類型、陳舊架結果或不支援嘅多打印板選擇接收一個特定原因。呢啲個案唔被排隊。選擇器保留呢啲打印機可見同可選，因為一個刷新映射可能使佢哋合格；最後發送操作保持決定檢查。單一打印機流保持可用當農場路徑無法證明相容性時。

一個合格配對 LAN 打印機通過認證本地發送函數使用佢嘅本地地址同訪問碼。缺失配對、地址或本地傳輸喺導出前接收一個特定原因。LAN 傳輸係序列化，因為本地網絡模組允許一個傳輸會話喺一次。等待任務喺進入該會話前檢查取消；一個喺傳輸完成中被取消嘅任務被記錄為已取消，而唔係完成。單一任務結果喺任務列表中保持可見。

聚焦政策回歸涵蓋重複清單、六裝置限制、LAN 可用性、打印板噴嘴地圖有效性、取消感知完成同序列化本地分發。一個原生構建、UI 驅動、真實雙噴嘴 LAN 打印機同傳輸取消保持未驗證直到佢哋通過項目嘅發佈驗證路由執行。
