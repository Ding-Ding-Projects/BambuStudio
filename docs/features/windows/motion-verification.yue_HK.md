# 原生動態生命週期驗證

針對性原生介面工作流程有可選 `motion_runtime_only` 分派。佢以程式同一快取靜態 wxWidgets 依賴前綴建置產品 `MD3Motion.cpp`，然後喺新建立、非輸入 Windows 桌面測試真實 wx 計時事件同實際 wx 視窗銷毀。永不切換輸入桌面、安裝產品、連接打印機或者啟動產品執行檔。

`MD3MotionPreference.cpp` 包含不變嘅產品偏好查詢。分開翻譯單元，避免只為測試 `Anim` 而連結整個 `GUI_App`。夾具以受控輸入向產品 `reduce_motion()` 政策提供 `reduced()`，因此 **呢個夾具唔驗證 AppConfig 持久化同作業系統 API**。

## 十四個執行時個案

| 個案 | 必須觀察 |
| --- | --- |
| 完成 | 初始零、中間回呼、單調進度、最終一、恰好一次完成、計時器停止，之後冇回呼 |
| 明確停止 | Stop 即時停止計時器；之後唔執行完成或者擁有者清理 |
| 反轉 | 新視覺路徑由目前值開始、下降至零，取消已替代完成回呼 |
| 初始回呼中重啟 | 只有替代動畫完成；第一動畫之後唔能重啟自己計時器 |
| 初始回呼中刪除擁有者 | 真實弱參照失效，冇更多視覺回呼，清理一次，冇完成 |
| 最終回呼中刪除擁有者 | 擁有者存在時進行最終視覺更新，刪除後清理，抑制完成 |
| 回呼之間刪除擁有者 | 刪除後冇視覺回呼，清理一次，計時器停止 |
| 初始回呼中刪除動畫器 | 分離 run 狀態容許回呼安全返回，之後冇回呼 |
| 最終回呼中刪除動畫器 | 動畫器銷毀後冇完成回呼 |
| 回呼之間刪除動畫器 | 之後冇視覺或者完成回呼 |
| 隱藏擁有者 | 下一真實計時事件收定至最終值一次並停止 |
| 初始減少動態偏好 | 同步最終更新同完成一次，唔啟動計時器 |
| 動態中改變偏好 | 下一計時事件只加入最終更新同完成 |
| 系統減少動態優先 | 系統偏好下受控系統請求即時收定 |

夾具以 CSV 記錄有界數值回呼樣本。呢啲係產品動畫器嘅時序觀察，唔係畫面擷取或者已繪製介面證據。時間容差容許普通託管排程延遲：每次等待最多兩秒，獨立監察器 30 秒後終止夾具，現有程序 Job 輔助將每次呼叫限於 45 秒並要求完整程序樹退出。工作流程步驟最多三分鐘，整個快取建置工作最多二十分鐘。

斷言係明確執行時條件，唔受 Release `NDEBUG` 影響。兩個夾具都用 `wxDEBUG_LEVEL=0` 配合快取 wx ABI，唔會停用夾具條件。

## 刻意破壞取消

CMake 喺建置目錄建立獨立產品翻譯單元副本，只移除 `Anim::Stop()` 嘅 `wxTimer::Stop()` 呼叫。同一真實事件迴圈夾具，必須先通過普通完成個案，再喺 `explicit_stop` 以結束碼 1 退出。亦必須還原執行緒桌面並關閉自己桌面。編譯失敗、崩潰、逾時、錯誤失敗個案或者缺少收據，唔算拒絕變異。

工作流程之後執行不變產品翻譯單元。全部十四個個案同桌面清理必須通過。最終收據綁定來源提交、run／attempt、來源同執行檔雜湊、兩個程序結果，同有界數值輸出雜湊。只保留五個固定 JSON／CSV 檔，唔包含帳戶身分、桌面名稱、本機路徑、原始程序輸出或者畫面擷取。

```powershell
gh workflow run native-interface-verification.yml --ref feature/ui-integration -f motion_runtime_only=true
```

其他只跑合約開關必須為 false。預設工作流程行為不變。缺少原生依賴快取會明確失敗，唔會建置整套依賴或者改用純模型。

## 目前驗證限制

呢次變更未喺本機編譯或者執行。託管編譯、負面拒絕、全部十四個執行時個案同時序記錄，須等精確來源執行檢查後先有結果。

呢個夾具唔驗證計時器啟動耗盡、每個 widget 配接器、已儲存偏好來回、真實作業系統無障礙設定、減少模式通知可讀性、對比、動畫外觀、OpenGL 畫格排程，或者已安裝程式。呢啲需要自己嘅已安裝流程。真實逐輸入畫面同時序影像仍須正常／最低視口、英文／粵語／雙語、淺深色，同實測 100/125/150/200% 比例。回呼樣本唔能滿足呢個矩陣。
