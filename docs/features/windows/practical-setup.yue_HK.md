# 設定 Bambu Studio

**表面**：說明 > 設定 Bambu Studio、命令調色盤（`Ctrl+Shift+F`，打「Set up」），或者全部功能頁 → `SetupWizardDialog`（`src/slic3r/GUI/SetupWizard/SetupWizardDialog.{hpp,cpp}`）。規則（步驟、儲存咗嘅進度、導航、仲欠乜）喺冇 wxWidgets 嘅 `src/slic3r/GUI/SetupWizard/SetupModel.{hpp,cpp}`。

設計：[design/local-tools-2026-11](../../../design/local-tools-2026-11/README.md)，Setup 呢塊板。

新安裝會喺打印機指南之後打開佢。其他人想改嘢嘅時候，隨時喺說明度搵到。

## 步驟

| 步驟 | 類型 | 做乜 |
| --- | --- | --- |
| 語言同幽默 | | English、廣東話或者兩樣都要；英文同廣東話嘅搞笑程度（1 至 5）；對話框表情符號；個人用字檔 |
| 外觀同動態 | | 淺色或者深色；舒適或者緊湊；跟系統或者減少動態 |
| 打印機 | 必要 | 揀打印機（打印機指南）、搜尋網絡、匯入打印機設定檔 |
| 墨水同線材 | 必要 | 同步 AMS、揀線材（線材指南），睇吓打印板上而家有乜 |
| 備份 | 可選 | 開住嘅專案自動備份（關、2 分鐘或者 10 分鐘）同設定備份 |
| 擴充功能 | 可選 | 內置擴充功能，每個都有**檢查並允許**（同意提示）或者**關閉**；見[擴充功能](extensions.md) |
| 完成 | | 設定做咗啲乜；打開準備，或者行一轉功能導覽 |

每個動作都係真嘅，即刻生效，用嘅係偏好設定同一套設定。每個動作都會喺 **每個動作嘅結果** 加一行，等你睇到發生咗乜，連被拒絕嘅都有：冇套用到嘅用字檔會講原因，匯入咗但冇帶到打印機亦會講明。

- **語言** 會重新載入視窗，同偏好設定一樣。設定會將呢步標做完成、記住位置，然後用新語言喺下一步再打開。
- **學校模式** 喺度一樣會收埋幽默、表情符號同用字設定。
- **搜尋網絡** 會列出喺你網絡度回應咗嘅打印機，每部都有 **連接**，會儲存設定再喺裝置分頁打開嗰部打印機。連接要用打印機嘅存取碼，喺嗰度輸入。
- 匯入咗但冇帶到打印機，會提供 **揀另一個檔案**。
- 步驟數字下面有條進度條，顯示幾多步已經完成或者跳過。
- **備份** 會打開設定檔同備份：「即刻快照」會喺本機保留一份完整嘅設定，「匯出」就會將所有嘢（包括秘密資料）搬去另一部電腦，有佢自己嘅確認。

## 必要步驟

至少有一部打印機同一個線材預設，設定先可以完成。**下一步** 永遠唔會變灰：喺未滿足嘅必要步驟，佢會解釋欠乜，然後變做 **照樣下一步**，等你可以繼續，遲啲先返嚟。標題會數仲剩幾多個必要步驟，完成嗰步亦會列出仲需要乜。

## 儲存同繼續

每次改動都會即刻儲存進度（`BambuStudio.conf` 入面嘅 `setup_wizard_progress`）：而家嘅步驟、邊啲步驟完成或者跳過咗，同埋時間。隨時都可以關（Esc 會儲存再關），再喺說明度打開；佢會講喺邊度停咗，例如「歡迎返嚟。設定喺 2026-11-07 23:58:12 停喺第 3 步（共 7 步）；已完成嘅 2 步會保留」，仲有 **繼續** 同 **重新開始**。

## 鍵盤

| 按鍵 | 動作 |
| --- | --- |
| `Alt+N` | 下一步 |
| `Alt+B` | 上一步 |
| `Alt+S` | 跳過可選步驟 |
| `Esc` | 儲存再關 |

左邊嘅步驟亦都可以撳。

## 儲存嘅值

| AppConfig 鍵 | 值 |
| --- | --- |
| `setup_wizard_progress` | JSON：而家嘅步驟、步驟狀態、時間、完成咗未、係咪第一次執行 |
| `setup_wizard_reopen` | 因為改語言而重建視窗期間係 `1` |

步驟本身寫嘅係偏好設定本來已經用緊嘅設定：`language`、`funny_level_en`、`funny_level_yue`、`dialog_emojis`、`dark_color_mode`、`ui_density`、`motion_preference`、`backup_switch` 同 `backup_interval`。

## 檢查

`tests/setup_model.test.mjs` 會編譯 `tests/setup_model_test.cpp`：步驟、必要條件、完成同跳過（必要步驟永遠跳唔到）、繼續，同埋儲存，連一份人手改過、想跳過必要步驟嘅紀錄都包括。負面建置會容許跳過必要步驟，一定要失敗。
