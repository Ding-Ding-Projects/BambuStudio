# 打印模擬播放（進料速率真實）

預覽標籤嘅水平移動時間表播放切片打印作為一個模擬，其節奏跟隨真實、進料速率衍生打印時鐘代替舊固定六秒掃。

## 行為

- **進料速率真實時鐘**。每個移動滑塊刻度被映射到佢嘅 G-code移動累積打印時間（`MoveVertex::time`、前綴總和由 G-code處理器喺完成期間計算）。只有移動擁有一個時間塊攜帶一個值、所以表前進充滿。喺播放時、模擬打印時鐘 `t` 由 `牆時鐘 dt x 速度乘數` 推進；顯示移動係執行喺 `t` 嘅（二進位搜尋超累積表、每幀 O(log n)）。一個一小時打印因此耗時一小時喺 1x──使用速度晶片。
- **速度乘數**。速度晶片喺運輸欄右側集群循環 1x → 10x → 100x → 1000x。乘數縮放模擬時鐘、所以慢周邊可見爬行同快速行進喺任何設定下閃過。
- **運輸欄**。播放/暫停（圓形主要按鈕）、跳到開始 / 跳到結束、速度晶片、一個 `已用 / 總計` 模擬打印時鐘讀出同 `移動 N / M` 計數。喺窄視窗鉻逐漸脫落
  ──讀出首先、然後速度晶片、然後跳過按鈕同計數──所以擦軌道從不覆蓋剩餘嘅。
- **擦軌道語意**。用戶永遠贏：拖動手柄、點擊追蹤或使用跳過按鈕使滑塊索引對嗰個幀權威同重新錨定模擬時鐘到選定移動嘅時間。
  播放（如果執行）喺下一幀從擦位置恢復。到達結束暫停模擬（佢唔停止）；喺結束按播放重新啟動從開始。
- **標記透層**。喺一個模擬執行或暫停時、噴嘴標記（序列視圖）保持可見甚至喺位置，佢會正常隱藏（例如附帶滑塊喺最大值）、所以虛擬噴嘴可被連續跟隨透層邊界。
- **渲染器範圍**。兩個 G-code渲染器被支援。喺進階渲染器移動時間表涵蓋目前頂層（佢嘅刻度係按層分段索引）；喺舊渲染器佢涵蓋整個可見層範圍。

## 舊渲染器節流

舊渲染器重建佢嘅渲染路徑每個序列視圖尋。
當一個快進幀（通常 1000x）跳超約 5000 刻度、
滑塊只推動序列視圖更新每隔其他幀；跳過
幀仲然重繪畫布所以時鐘同讀出保持平滑。最後幀嗰個暫停喺結束係永遠推動。進階渲染器需要無節流。

## 減少動作 / 可存取性

播放永遠唔自動啟動：冇自動播放、同一個新切片、層
變更或視圖變更讓時間表停止。動作只永遠開始
從用戶按播放按鈕、同暫停或擦軌道立刻停止佢、所以特徵係惰性對用戶迴避環境動作。

## 在地化

運輸控制嘅用戶可見字串（「播放打印模擬」、「暫停
打印模擬」、「模擬速度」）係翻譯喺英文同香港
粵語目錄例如每個其他預覽字串。

## 故障模式

- **冇時間數據**。如果已載入結果攜帶冇可用移動時間（例如
  進階渲染器可見分段清單空）、速度
  晶片同讀出隱藏同播放按鈕回滾到一個平原六秒
  索引掃、所以運輸永遠唔死端。
- **圖示地圖集不可用**。冇合併 Material Symbols 地圖集
  整個運輸欄已回滾到舊溝槽加值晶片；
  模擬控制係簡單地缺席嗰度、匹配前面存在
  回滾行為。

## 驗證

涵蓋由一個 Windows 構建加手動預覽互動：切片一個盤、
開啟預覽、按播放喺每個速度、擦軌道喺播放期間、跳到兩個
結束同縮小視窗以確認脫落順序。i18n 門
（`compile_translation.py` 然後 `--check` 喺 `bbl/i18n/yue_HK`）驗證新
目錄項。
