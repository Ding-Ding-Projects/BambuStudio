# 停止打印安全互鎖

**介面：** 設備 ▸ 打印任務 ▸ 停止按鈕 → `StopPrintGateDialog`（`src/slic3r/GUI/StopPrintGate.{hpp,cpp}`），取代前一個係/否確認。

## 行為

停止打印依家行過啟動控制台互鎖、嚴格次序：

1. **轉兩個鑰匙開關**：繪製旋轉鑰匙；點擊旋轉鑰匙插槽從垂直（關）到水平（開）。
2. **按每個三個武裝按鈕兩次**：按鈕面計數 `Arm n (2)` → `Arm n (1)` → `Armed n`。
3. **滑動確認**：共享 `SlideToConfirm` 門（拖或鍵盤：箭頭前進、`End` 完成）只係啟用一旦階段 1–2 完成。
4. **提起安全蓋**：一個危害條紋瓣；點擊佢喺滑動後揭示實際**停止打印**按鈕。只係呢個按鈕中止任務（`command_task_abort`）。

一個階段說明（「Step n of 4: …」）敍述確切咩係左邊，所以流係戲劇但永唔會模糊，根據破壞性動作複本規則，每個標籤平常陳述打印會被捨棄。「保持打印」（或者以其他方式關閉對話盒）停止冇一樣。

## 考慮

- 互鎖故意交換速度用於確定。佢係鍵盤可達到終端到終端（按鈕同滑塊係可聚焦；蓋打開喺點擊後滑動）。
- 冇都狀態持久化：重新打開對話盒開始互鎖從零。
- 相同兩鍵然後滑動解剖被概括用於每個其他不可逆轉動作（刪除全部、刪除預設、刪除墨水、刪除板）由錨定 `SuperConfirmGate`：睇 [破壞性動作超級確認](super-confirmation.md)。呢個對話盒保持佢額外武裝按鈕同安全蓋因為停止打印都捨棄材料同時間已經花。

## 確認

- 編譯進入 `libslic3r_gui`。完整流需要一個連接打印機帶著活躍任務到達實際停止按鈕，所以終端到終端確認針對硬件被記錄做待命；對話盒邏輯（階段制門、重設、取消停止冇一樣）由構造被練習。
