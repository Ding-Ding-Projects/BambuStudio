# 本機工具頁

**表面**：檔案 > 本機工具、指令面板（`Ctrl+Shift+F`，打「Local tools」）、全部功能頁，或者本機工具分頁嘅第一頁 → `LocalToolsHubPanel`（`src/slic3r/GUI/FeatureFinder/LocalToolsHubPanel.{hpp,cpp}`）。規則喺冇 wxWidgets 嘅 `LocalToolsHub`（`src/slic3r/GUI/FeatureFinder/LocalToolsHub.{hpp,cpp}`）度；工具經 `LocalToolsActivity` 寫最近活動。

設計：[design/local-tools-2026-11](../../../design/local-tools-2026-11/README.md)，Main 板。

## 顯示乜嘢

每件喺呢部電腦度運行嘅工具都係一張卡：名、而家有啲乜或者做緊乜、同選單項目一樣嘅描述、喺選單邊度，仲有**打開**同**釘選**。呢頁乜都唔會上載。

本機工具分頁同以前一樣，第一次有工具打開先會出現；無論係邊件工具打開個分頁，呢頁都一定係第一頁。

工具名下面嗰行係喺呢頁顯示嗰陣、撳**重新讀取每件工具嘅狀態**嗰陣，同埋有工具做完嘢嗰陣，喺工具自己嘅檔案同狀態度讀出嚟。冇嘢報告嘅工具就冇嗰行；一行都唔會靠估。

| 工具 | 嗰行 |
| --- | --- |
| 實用設定精靈 | 未開始、已儲存第 3 步（共 7 步），或者完成 |
| Base64 工具箱 | 記錄入面有幾多項 |
| 虛擬磁碟 | 清單入面有幾多個磁碟 |
| Minecraft 伺服器 | 而家有幾多個運行緊（共幾多個），或者總共有幾多個 |
| 畫板 | 幾多個盤有畫 |
| 擴充功能 | 有人答過任何同意提示之後：開咗幾多個、幾多個等你答覆 |
| 元素鎖 | 鎖咗幾多個元素 |

## 搵工具

- 搜尋欄會對名、描述、喺邊度、額外字眼同名下面嗰行（打「running」會搵到運行緊嘅伺服器）。`.*` 掣會轉做正規表達式，用共用嘅正規表達式建立器。無論揀咗邊個籌碼，搜尋都會搜晒所有工具。
- 籌碼可以顯示釘選咗嘅工具、所有工具，或者一組：檔案同資料、打印機、Windows、畫畫、遊戲、擴充功能、設定同安全。每個籌碼都數住佢有幾多件工具。揀咗邊個籌碼會記住。
- 喺呢個系統打唔開嘅卡，會講原因而唔係顯示打開，同全部功能頁一樣。

## 釘選

新安裝會釘選九件工具：Base64 工具箱、擴充功能、設定精靈、虛擬磁碟、Minecraft 伺服器、畫板、本機檔案轉換器、本機模型套件同驗證器。任何卡上面嘅**釘選**同**取消釘選**都會改張清單；最多可以釘選 12 件。喺「已釘選」籌碼度，卡上面嘅箭咀可以將佢移前或者移後。釘選同次序存喺 `local_tools_pinned`；全部取消釘選都會記住。

## 最近活動

工具旁邊嗰欄（窗口窄嗰陣喺工具下面）列出工具最近做完嘅八件嘢，每件都有工具、時間（「今日 00:52:41」、「尋日 23:41:02」或者日期），唔係順利完成嘅話仲會講點樣收尾。會記低嘅嘢：

| 工具 | 幾時 |
| --- | --- |
| Base64 工具箱 | 編碼或者解碼咗文字或檔案、整咗或者讀咗 data: URL；記檔名或者類型，永遠唔記內容 |
| 虛擬磁碟 | 每個操作完結嗰陣（掛載、卸載、建立、放大、壓縮、子磁碟、合併、重新連接、新 ID、快速打包），連點樣收尾 |
| Minecraft 伺服器 | 開始、停止、按排程重新啟動、建立、加入、備份、還原、換版本、開始世界生成器、移除 |
| 擴充功能 | 每次真正運行有冇回覆；試行永遠唔會記 |
| 畫板 | 每次匯出，連檔名 |
| 設定精靈 | 完成咗設定 |

**打開記錄**會顯示最多 200 項，最新嘅排先，搜尋用正規表達式建立器。**保留最近活動**可以開或者關記錄；關咗就乜都唔寫，嗰欄亦會講明。**清除活動...**要扭兩條鎖匙再推到尾，先會刪除每一項；工具本身同佢哋自己嘅記錄唔會改。

活動存喺資料夾入面嘅 `local-tools-activity.jsonl`，每行一項，最多 200 項（最舊嘅先走）。控制字元會移除，長過 120 位元組嘅名會喺完整字元度切斷。

## 檢查

- `tests/local_tools_hub.test.mjs` 會建置同運行 `tests/local_tools_hub_test.cpp`：每件工具都係一個準備好、會打開工具嘅全部功能項目，組別同籌碼，釘選（預設、保留空清單、移除唔識嘅 ID、上限、切換同移動），篩選，清理，檔案格式同 200 項上限。一個喺滿咗嘅記錄度丟走最新一項嘅反向建置一定要失敗。佢仲會檢查每個描述都係 `MainFrame.cpp` 入面工具自己嘅選單說明。
- `tests/local_tools_hub_wiring.test.mjs` 會檢查呢頁喺分頁度第一個打開、檔案 > 本機工具會打開佢、每件工具會記低做完嘅嘢（Base64 淨係記名、擴充功能永遠唔記試行、設定只記一次）、關咗記錄就乜都唔寫，同埋清除要等兩條鎖匙確認。每項檢查喺一份改壞咗嘅副本度都會失敗。

## 未做

- 實時圖表、轉換器、模型套件、驗證器同上面冇講嘅其他工具，暫時未會寫最近活動。
