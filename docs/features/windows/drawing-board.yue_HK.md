# 畫板

**表面**：檔案 > 畫板、指令面板（`Ctrl+Shift+F`，打「Drawing」）同全部功能頁 → `src/slic3r/GUI/Drawing/DrawingPanel.{hpp,cpp}`。規則喺冇 wxWidgets 嘅 `DrawingModel` 度（`src/slic3r/GUI/Drawing/DrawingModel.{hpp,cpp}`）。

喺打印板嘅相上面畫嘢：圈住要加邊緣嘅部件、標低支撐掂到嘅位、寫張便條俾下一個打印嘅人。畫板會喺你而家做緊嗰塊打印板打開，專案入面每塊打印板都有自己嘅畫。你一路畫，所有嘢一路儲喺呢部電腦，永遠唔會上載。

## 筆

| 鍵 | 筆 | 點畫 |
| --- | --- | --- |
| 1 | 鉛筆 | 幼身，有少少透；畫得快啲，線就幼啲 |
| 2 | 筆 | 實色墨水；畫得快啲，線就幼啲 |
| 3 | 針筆 | 一個平均嘅闊度，快慢都一樣 |
| 4 | 箱頭筆 | 一個平均嘅闊度，筆頭係平嘅 |
| 5 | 螢光筆 | 闊、平頭、透明。一筆同自己交叉都唔會深色啲，因為成筆係一齊淡落去 |
| 6 | 畫刷 | 闊，有少少透；畫得快啲，線就幼啲 |
| 7 | 鋼筆 | 跟方向變粗變幼，好似斜住拎嘅筆咀咁 |
| E | 擦膠 | 只會擦走佢掂到嘅嘢。喺一筆中間擦過去，就會變成兩筆 |

每支筆會記住自己嘅**闊度**同**不透明度**。**平滑**（0 至 90%）會穩定手震，對每支筆都有效。畫嘅時候撳住 **Shift**，筆畫就會保持喺由起點計最近嘅八個方向之一，畫到直線同乾淨嘅斜線。

## 顏色

顏色行先係呢個專案嘅線材顏色，跟住係你最近揀過嘅八隻顏色。**顏色...** 會打開完整嘅揀色器，揀咗嘅顏色會加入嗰行。拎住擦膠嘅時候揀顏色，會轉返用箱頭筆。

## 復原、版本同清除

- **復原**同**重做**（`Ctrl+Z`、`Ctrl+Y`）可以行返最近 200 個改動：筆畫、擦嘢、攞返一個版本同清除。
- **保留呢個版本**會將而家嘅畫儲起。每塊打印板保留最近 20 個版本，有時間同筆畫數目。雙擊一個版本，或者揀咗佢再撳**攞返呢個版本**；呢樣都可以復原。
- **清除...** 要經過兩匙確認先會移除所有筆畫，而且會先保留一個叫「清除之前」嘅版本。

## 打印板嘅相

畫板第一次喺一塊打印板打開嘅時候，會由 3D 視圖影一張嗰塊打印板嘅相。郁過或者改過物件之後，**再影一次打印板**會影張新嘅；你嘅筆畫留喺原位。如果 3D 視圖仲未顯示過，畫板會講明：開一次準備，再影一次就得。**另一塊打印板...** 會將畫板轉去專案入面另一塊打印板。

## 匯出

**匯出...** 可以用六種形式儲存畫：

| 選擇 | 結果 |
| --- | --- |
| PNG 圖片 | 打印板嘅相加上面嘅畫，用相嘅尺寸 |
| 兩倍大嘅 PNG、三倍大嘅 PNG | 一樣，但放大，而筆畫係用嗰個尺寸重新畫過，唔係淨係拉大 |
| 透明背景嘅 PNG | 淨係筆畫，其他地方全部透明 |
| 連打印板相嘅 SVG | 向量筆畫疊喺打印板嘅相上面，張相會嵌入檔案 |
| 淨係筆畫嘅 SVG | 淨係向量筆畫 |

匯出出嚟嘅嘢同畫板顯示嘅一模一樣，擦過嘅都計埋。

## 鍵盤

畫板有焦點嘅時候（撳一下佢，或者用 `Tab` 行過去）：

| 鍵 | 做乜 |
| --- | --- |
| `1` 至 `7`、`E` | 揀筆或者擦膠 |
| `C` | 打開揀色器 |
| `S` | 跳去手上嗰支筆嘅闊度 |
| 畫嘅時候撳住 `Shift` | 將筆畫保持喺八個方向之一 |
| `Ctrl+Z`、`Ctrl+Y` | 復原同重做 |
| `Ctrl+Shift+E` | 匯出 |
| 方向鍵 | 郁鍵盤筆，每步 12 像素，撳住 `Shift` 就係 2 |
| `Space` | 鍵盤筆落筆或者提筆；落咗筆嘅時候方向鍵就會畫 |
| `Esc` | 提起鍵盤筆 |
| 撳右掣、`Shift+F10` 或者選單鍵 | 一個選單，有每支筆同佢嘅鍵、顏色、闊度、復原、重做、保留版本、匯出同清除 |

啲鍵、提示同選單都係由同一個表嚟，所以喺邊度見到嘅鍵都一定用得。畫板攞住鍵盤嘅時候會有焦點框。

## 畫儲喺邊

喺數據資料夾嘅 `drawings` 入面：

| 檔案 | 載住 |
| --- | --- |
| `plate-<n>.json` | 打印板 `n` 嘅筆畫同版本，會先寫去 `plate-<n>.json.partial`，再搬去正確位置 |
| `plate-<n>.png` | 打印板 `n` 最近影嘅相 |

畫係跟打印板編號儲嘅，所以佢哋跟住打印板編號，而唔係跟住某一個專案檔案。

## 檢查

`tests/drawing_model.test.mjs` 會編譯 `tests/drawing_model_test.cpp`：啲筆同佢哋嘅鍵、每個闊度規則（平均、跟速度、跟方向）、平滑、八個方向嘅鎖定、擦膠淨係擦走掂到嘅嘢同將一筆分開兩筆、復原同重做同佢哋嘅上限、儲存同讀返（爛嘢會跳過）、顏色解讀，同 SVG 匯出嘅尺寸、透明圖層、平頭同嵌入嘅打印板相。佢嘅反向建置會俾擦膠攞走佢從來冇掂過嘅筆畫，必須失敗。
