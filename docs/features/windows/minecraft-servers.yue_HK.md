# Minecraft 伺服器

**位置**：檔案 > Minecraft 伺服器、指令面板（`Ctrl+Shift+F`，打「Minecraft」）同全部功能頁 → `src/slic3r/GUI/GameServers/ServersPanel.{hpp,cpp}`。規則（設定、版本、控制台訊息、備份、世界產生器）喺 `ServerModel.{hpp,cpp}`，掂到呢部電腦嘅嘢（Java、連接埠、檔案、ZIP 檔、下載、伺服器程序）喺 `ServerSystem.{hpp,cpp}`，全部喺同一個資料夾。

喺呢部電腦度建立或者由資料夾收編嘅 Java 伺服器，每部都有控制台、每個設定、玩家、世界、版本、備份、排程、世界產生器同記錄。呢個版本要喺 Windows 先可以運行伺服器；淨係讀檔案嘅功能喺邊度都用得。

## 清單

**建立伺服器...** 會設定一部新嘅原版伺服器，**尋找同收編...** 會加入已經存在嘅伺服器，**由清單移除...** 只會忘記佢；佢嘅資料夾、世界同備份會留喺原位。每行會顯示狀態（已停止、啟動緊、運行緊同幾多人在線、停止緊）同版本。標題下面嗰行會列出搵到嘅 Java 同呢部電腦嘅記憶體。

Java 會喺 `JAVA_HOME`、`PATH`、常見安裝資料夾（Oracle、Eclipse Adoptium、Microsoft、Zulu、BellSoft、Amazon Corretto 等等）同 Minecraft 啟動器自己嘅執行環境度搵，每個版本由安裝資料夾嘅 `release` 檔讀出嚟，乜都唔使運行。裝咗新 Java 之後，喺概覽撳**再搵 Java** 就會重新讀。

## 建立

先讀取 Mojang 版本清單（版本、**讀取 Mojang 清單**），然後揀一個正式版、名、放喺邊個資料夾（必須係新嘅或者空嘅）、最多記憶體同連接埠（由 25565 開始第一個空嘅）。伺服器需要接受 Minecraft EULA：對話框嘅剔選框就係做呢樣，旁邊有連結俾你睇，冇剔就乜都唔會建立。

官方伺服器檔案會被下載，再同 Mojang 嗰個版本紀錄入面嘅 SHA-1 核對；唔吻合嘅檔案唔會保留。之後會寫 `eula.txt`（已接受，連日期）同 `server.properties`（連接埠，同用個名做每日訊息）。其餘設定由伺服器第一次啟動時自己寫。

## 尋找同收編

揀一個資料夾：會向下搜尋三層，搵有伺服器 jar 同 `server.properties` 或者 `eula.txt` 嘅資料夾。每個搵到嘅都會列出佢嘅 jar、類型同版本；收編只係加入清單，佢個資料夾乜都唔改。原版、Paper、Purpur、Spigot、Fabric、Forge、NeoForge 同 Velocity 會由 jar 嘅名、入面嘅 `version.json` 同 manifest 認出嚟。

## 啟動同停止

**啟動**會先檢查晒所有嘢，每個唔過嘅檢查都會講點做：

- Java 夠新：1.17 之前要 8，1.17 要 16，去到 1.20.4 要 17，由 1.20.5 開始要 21，或者照 jar 自己 `version.json` 講嘅。會自動揀夠新而最接近嗰個 Java。
- 伺服器檔案喺度，而 `eula.txt` 已經接受 EULA。
- 連接埠係空嘅，最多記憶體最少要留 1 GB 俾呢部電腦其他嘢用。
- 冇其他程式開緊個世界（佢嘅 `session.lock`）。

伺服器會用 `java -Xms -Xmx` 運行，控制台用 UTF-8，關閉 log4j 嘅查找（`-Dlog4j2.formatMsgNoLookups=true`，保護舊版本），加你自己嘅 JVM 參數、`-jar` 同 `nogui`。佢冇自己嘅視窗，交俾佢嘅只有控制台嘅管道。

**安全停止**會傳 `stop`，伺服器會儲存世界。**重新啟動**會停咗佢再開返。**強制停止...** 要經過兩匙確認，會即刻結束程序，唔會儲存。

呢頁閂咗伺服器都會繼續運行。程式結束時，每部運行緊嘅伺服器都會被叫停，最多有 20 秒儲存。

## 概覽

卡片顯示狀態、邊個在線、記憶體（程序用緊幾多對比最多可以用幾多）、運行咗幾耐、版本同類型、用緊嘅 Java、下次備份同重新啟動。**最近事件**會列出啟動、加入、離開、進度、備份同錯誤。**打開完整記錄**會打開 `logs/latest.log`。

## 控制台

伺服器印出嚟嘅所有嘢（最近 3,000 行）同一個指令欄。上同下鍵可以叫返之前嘅指令；**list** 同 **save-all** 撳一下就得。指令以伺服器控制台身份執行，擁有所有權限。

## 屬性

呢個程式識嘅 `server.properties` 設定（超過 60 個）每個都有自己嘅控制項：開關、選項、有範圍嘅數字、文字或者隱藏嘅密碼。佢哋會分組（遊戲玩法、世界、玩家、網絡、效能、資源包、進階），搜尋可以搵標籤、鍵或者說明，滑鼠停喺一行會顯示佢做乜、預設值同由邊個版本開始有。伺服器版本冇嘅設定唔會顯示：例如 1.18 之前嘅 `simulation-distance`，或者由 1.21.2 開始嘅 `spawn-animals` 同 `spawn-npcs`。

**儲存變更**會先檢查每個值嘅範圍。檔案重寫時，你冇改過嘅每一行都會完全保持原樣：註解、呢個程式唔識嘅設定、轉義同換行方式都一樣。改咗嘅值會用 Java 寫 properties 嘅方式寫（`\:` 同 `\=`，ASCII 以外嘅字用 `\uXXXX`，每個版本都讀得到）。

標示**即時**嘅設定喺伺服器運行時即刻生效：難度（`difficulty`）、新玩家嘅遊戲模式（`defaultgamemode`）同允許名單開關（`whitelist on` 或者 `off`）。其他要下次啟動先生效，儲存後嘅提示會講有幾多項。**還原上次儲存**會將檔案變返今次上次儲存之前嘅樣。

## 玩家

允許名單、管理員（等級 1 至 4，每級都講明可以做乜）同封禁。伺服器運行時，**加入...** 同**移除**會經佢自己嘅指令（`whitelist add`、`op`、`ban` 同相反嘅指令），由佢查找玩家同寫佢自己嘅名單。停止咗嘅時候，**移除**會直接改名單檔案，亦可以改管理員等級（伺服器運行時會將名單保留喺記憶體）。唔係有效 JSON 嘅名單檔案會照搵到嘅樣顯示，永遠唔會被重寫。**而家在線**嚟自控制台：加入、離開同 `list` 嘅回覆。

## 世界

伺服器資料夾入面每個有 `level.dat` 嘅資料夾。**運行呢個世界**會設定 `level-name`，下次啟動生效。

## 版本

**讀取 Mojang 清單**會讀 Mojang 發佈嘅每個版本（留低俾下次用），分成正式版、快照同舊 Alpha 同 Beta，每個都會講需要邊個 Java，同呢部電腦有冇。**轉用呢個版本...** 只適用於停止咗嘅原版伺服器：會先整完整備份，然後下載 `minecraft_server.<版本>.jar` 再用 SHA-1 核對，伺服器由下次啟動開始用佢。舊嘅伺服器檔案會留喺資料夾。退返舊版本之前會先問：新版本儲存嘅世界未必載入到，備份就係返轉頭嘅方法。

## 備份

**即刻備份**會將世界（`level-name` 同佢嘅 `_nether` 同 `_the_end` 資料夾）同設定、玩家檔案整成一個 ZIP。伺服器運行時，複製期間會暫停儲存：`save-off`、`save-all flush`，等伺服器話已儲存先開始 ZIP，之後 `save-on`。`session.lock` 唔會放入去。ZIP 會先用暫時名寫入，完成先改名，入面每個檔案都會讀返嚟同 CRC 核對過先算數。

備份名係 `<伺服器> <日期> <時間>.zip`，自動備份最尾有 `auto`，放喺伺服器嘅 `backups` 資料夾，或者你自己揀嘅資料夾（每部伺服器一個資料夾，**備份放喺...**）。

**還原...** 只適用於停止咗嘅伺服器，要經過兩匙確認。備份會先解壓到一個暫時資料夾；之後入面每個世界同檔案會取代伺服器資料夾嗰個，而家嘅會改名做 `before restore` 加時間放喺旁邊。乜都唔會刪除。**刪除...** 一樣要兩匙確認。

## 排程

每 1 至 168 小時自動備份，保留最新嘅 1 至 100 個自動備份（較舊嘅自動備份會刪除；手動備份永遠唔會），同每日喺你揀嘅時間重新啟動，提前 0 至 30 分鐘喺聊天提醒。Bambu Studio 開住時排程先會運行。第一次自動備份係儲存排程之後一個週期，失敗咗嘅會喺 10 分鐘後再試。

## 世界產生器

用揀咗嗰部伺服器自己嘅伺服器檔案同版本整一個新世界，唔會掂到嗰部伺服器嘅世界。整嘅過程喺資料資料夾入面一個自己嘅資料夾進行，用一部只監聽呢部電腦嘅伺服器（`127.0.0.1`，由 25600 開始一個空嘅連接埠），唔俾任何人入（空嘅允許名單），而 EULA 只係由剔選框為今次運行接受。

- **種子**（骰仔會隨機揀一個 64 位元嘅）、**世界類型**（普通、平坦、巨型生態域、極端地形、單一生態域；每個版本自己嘅 `level-type` 值）、**模式**、**難度**、**極限模式**（會令難度一直係困難）同**結構**。
- **平坦**：層，由頂層開始（加、排序、移除，或者由經典平坦開始）、生態域、湖泊、地物同放邊幾個（共 20 個）結構組，寫成 1.19 或者更新嘅 `generator-settings` JSON，照伺服器讀嘅次序由底層開始。1.19 之前只可以整經典平坦世界。
- **單一生態域**：生態域（1.19 或者更新）。
- **遊戲規則**：版本有嘅每條規則，分類型輸入；只有你改過嘅會喺伺服器啟動後用 `gamerule` 套用。
- **範圍**：每邊 0 至 1,000 個區塊，以你揀嘅點為中心。會分批整，每批 16 x 16 個區塊，即係一個 `forceload` 最多處理嘅數量：每批會被強制載入，喺四角同中間問 `execute if loaded` 直到全部通過，然後釋放。預先生成範圍需要 1.19.4 或者更新；舊版本只會整重生點附近。有一批用咗超過四分鐘就會停止。估算大約每秒 40 個區塊、每個區塊 12 KB。

全部批次完成之後，世界會儲存（`save-all flush`），伺服器停止，然後世界會被複製到一個新資料夾，或者先用暫時名壓縮成 ZIP 再檢查；永遠唔會覆蓋任何嘢。之後會刪除今次運行嘅資料夾。**取消**會停止今次運行，乜都唔會寫。預覽會畫出範圍，每 4 個區塊一條幼線，每批一條粗線，每完成一批就填色。

## 記錄

每部伺服器嘅每次啟動、停止、儲存設定、玩家變更、備份、還原、轉版本同整世界。保留最近 300 項。

## 檢查

`tests/game_servers.test.mjs` 會編譯 `tests/game_servers_test.cpp`：版本 ID 同佢哋嘅次序（資料版本，同按日期排嘅快照）、每個版本需要嘅 Java、`server.properties` 讀入再逐個位元組寫返出嚟（Windows 換行、註解、續行、轉義、同一個鍵出現兩次）、設定表（冇重複嘅鍵、每個預設值有效、範圍、即時指令同版本）、EULA、玩家名單、八種類型嘅伺服器 jar、控制台訊息、Mojang 清單同版本紀錄、啟動檢查同指令行、備份名同清理、排程、世界產生器嘅設定、問題同屬性、佢嘅批次（100 x 100 個區塊會分成 49 批，每批最多 256 個區塊，範圍剛好每處覆蓋一次）、資料庫檔案同 SHA-1。佢嘅反向建置會重寫 `server.properties` 每一行，同用 17 x 17 個區塊分批，必須失敗。
