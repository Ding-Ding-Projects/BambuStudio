# Quiet workflow

Slicing starts without first-use video invitations. Automatic switcher introductions, random slicing tips, startup food cards, Helio coaching and new-filament badges no longer interrupt work. Existing saved tutorial flags do not enable them again. RFID recording still runs through the synchronization service.

Background application checks and automatic installation remain available. A background update shows only non-blocking notices: the ready banner when a new version is staged, or one failure notice per release when a newer release could not be staged. Only an explicit update check opens the download dialog or the newest-version message (see [app updates](app-updates.md)). Automatic preset synchronization does not open an update offer. Help, manual setup, configured workspace reminders, validation messages, progress, cancellation and unsaved-work confirmations remain available.

The slicing progress card contains progress and its controls without an educational panel. Material and device diagnostics remain separate from promotional copy.

Verification includes a source-boundary regression contract for retired automatic producers. The same contract requires every download dialog in the application update route to sit behind an explicit request and both background update notices to be non-blocking notifications. Native build and runtime verification are recorded separately and are not implied by that contract.

H2S brittle-filament guidance uses the existing non-blocking notification card. Its Wiki link opens only when selected and never cancels slicing. Saved first-use flags do not restore the former modal.
