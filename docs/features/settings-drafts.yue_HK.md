# 獨立設定草稿

Prepare 同 Preferences 分區列嘅加號會開啟可搜尋選擇器。現有頁面仍係原有頁面嘅檢視。新增 Process、Ink 預設同印表機預設項目，會由目前所選預設建立獨立設定草稿。Duplicate 將草稿連同未套用修改，複製至另一份獨立擁有設定。

草稿欄位使用原有具型別設定控件同驗證。草稿編輯永遠唔會取代應用程式全域預設組合。每份草稿保留原始基準、來源名稱、穩定專案分頁身分同目標預設身分。刪除或重新命名來源預設，唔會丟棄草稿自有設定。

## 套用同復原

Apply 將即時目標同完整原始基準比較，並檢查專案同目標身分。確認會列出有改動設定、之前值同建議值。由於對話框執行巢狀事件迴圈，確認後會再次檢查目標。有衝突時即時目標保持不變。

Apply 前會建立一個原有 Undo／Redo 快照。可選設定附件擁有完整 Process、Ink 同印表機已編輯設定。Undo 同 Redo 會同原有模型狀態一齊還原呢啲設定。附件跟隨快照修剪；歷史改變前按專案世代同預設身分檢查。草稿編輯器亦提供範圍較窄嘅 Undo Apply；如果會覆寫之後嘅設定或目標改動，就拒絕還原。

即時改動期間發生例外時，會嘗試還原完整之前已編輯設定。唔涉及印表機指令或實體裝置操作。

## 儲存為預設

Save as preset 寫入獨立使用者預設，並喺唔選取嘅情況下插入集合。唔會啟用預設或改即時已編輯設定。現有名稱受保護，唔會被取代。失敗會保留草稿供重試。

## 持久化同私隱

草稿喺本機應用程式設定 `settings_drafts` 下持久化，每個主表面分開儲存。具版本儲存保留基準同目前設定、來源身分、搜尋文字同捲動位置。分頁列負責順序、群組、釘選、停靠邊同目前分頁檢視狀態。關閉已改草稿需要明確捨棄確認。關閉內建分區只隱藏檢視，唔會銷毀。

類似憑證嘅選項鍵，排除於草稿快照、持久化、比較同差異。還原屬交易式，限制 64 份草稿、總共 16 MiB、每快照 4,096 個選項，以及每序列化選項 1 MiB。不相容儲存唔會取代有效現有記憶體儲存。

## 驗證狀態

`settings_drafts_tests` 涵蓋自有複本隔離、複製獨立性、專案／預設／修訂衝突拒絕、即時改動拒絕、來源缺失仍持久化、交易式損壞處理同憑證排除。呢項改動需要真實建置同執行驗證，涵蓋具型別控件、兩個主分頁列、關閉確認、持久化、Apply、Save as preset 同完整 Undo／Redo。原始碼審閱或後端測試通過，唔能夠證明呢啲執行結果。

## 本機歷史交付

草稿編輯記錄為已清理嘅本機設定版本。喺本機歷史瀏覽器選草稿版本，可以還原至相符、已開啟獨立草稿。專案分頁同預設目標必須仍相符。Apply 仍係獨立需確認操作。儲存預設亦建立本機版本；還原需要選中確切預設，結果保持可編輯，唔會啟用另一預設。設定比較顯示每個新增、更改同移除鍵。

Undo 設定附件使用穩定專案分頁身分，所以檔名改變唔會令其他方面相符嘅目標失效。附件儲存估算參與 Undo 記憶體淘汰。呢項快速交付改動冇執行測試或畫面擷取。
