# 畫布選單搜尋

層滑桿新增同編輯選單、每個耗材子選單、SVG 檔案操作、方向方法選擇器、一般畫布組合方塊同已篩選畫布組合方塊，都有本地搜尋。可到達嘅 Assembly Export 彈出選單，亦用同一標頭顯示三種匯出格式同匯出參數操作。搜尋標頭預設提供字面比對、明確正則運算式開關、完整錨定正則建構器同清除搜尋。窄彈出選單會將呢啲控件放到第二列，並將尺寸限制喺視窗範圍內。

每個欄位以自身 ImGui ID 作鍵，屬於其 ImGuiWrapper。最多保留 128 個欄位。非活動欄位按最舊優先移除，但工作程序執行期間唔會移除。每個欄位有獨立查詢、旗標、橋接回呼同結果。查詢同候選內容唔會寫入持久儲存或經網絡傳送。

正則比對透過原有受限工作程序非同步執行。結果按完整查詢、旗標同有序標籤快取。待處理或無效搜尋會顯示所有操作同明確狀態；有效但空結果顯示「No matches」。過期或未完整結果唔能夠隱藏部分操作。暫時工作程序啟動或競爭問題（`WorkerUnavailable`）會先等 250 ms，再等 1000 ms 重試；同一輸入最多三次嘗試。無效模式、複雜度限制、逾時同協定錯誤唔會重試。等待期間畫布排程定時畫格，唔會持續重畫；更改查詢會重設呢個有界限重試規則。字面搜尋喺程序內作有界限比對。比對用原始本地化標籤；可選顯示詞彙只改畫面文字，唔改 ID、操作、已儲存資料或紀錄。

第一次 Escape 會清除非空搜尋，下一次先關閉彈出選單。按住 Escape 唔會一次做晒兩件事。開啟選單會將焦點放喺搜尋欄。ImGui 保留導航同停用操作行為。平台螢幕閱讀器公開狀態仍需另外用已建置應用程式驗證；只見到結果文字，唔代表有作業系統無障礙通知。

Preview 播放同層滑桿顏色，解析同周圍應用程式一致嘅 Brand 配色，保留主題角色同透明度，唔用固定顏色。

## 必須完成嘅驗證

呢項改動所有執行都交畀 GitHub 託管 Windows 執行器。冇進行本機產品建置、測試、執行或畫面擷取。

- 建置整合 PersonalVocabulary 實作嘅應用程式。
- 用 C++17 同 `src` 包含路徑編譯並執行 `tests/canvas_menu/search_state_tests.cpp`，測試繪畫使用嘅實際標頭模型。
- 用空白、字面、正則、無效、無結果、Unicode 同完整詞輸入，驗證每個列明根選單同子選單，保留順序同停用狀態。
- 交替操作控件同建構器、關閉／重開，再喺評估期間快速改查詢。確認查詢或遲到結果唔會跨越控件擁有權。
- 驗證鍵盤開啟、焦點、方向鍵、Enter、清除、第一次同第二次 Escape。檢查鍵盤建構器定位喺啟動畫布控件附近。
- 喺兩種主題、100%、125%、150%、200% 縮放同最小支援畫布尺寸，擷取英文、廣東話同雙語選單。檢查捲動、彈出邊界、長標籤、主題一致性同平台無障礙。

以上係待完成驗證要求，唔係已完成執行證據。

## Assembly Export 彈出選單

組裝至少有一個真實 Normal 或 FinalAssembly 步驟時，Export 按鈕先啟用。彈出選單按原有順序搜尋四個原始本地化標籤：Export PDF、Export Markdown、Export MP4 同 Set export file parameters。可見遮罩永遠唔會重新編號操作。PDF、Markdown 同 MP4 保留原有匯出回呼；最後一列保留匯出設定對話框。Markdown 說明喺指標懸停或鍵盤焦點時仍可取得。選取列後仍會關閉彈出選單。

搜尋擁有權包含 AssemblyStepsUtils 實例同彈出選單身分。共用標頭提供字面／正則比對、建構器、清除同無結果狀態。列參與鍵盤導航。彈出高度按篩選內容同搜尋標頭調整，實際顯示邊界限制尺寸；放唔落時可以捲動。原有停用 Export 狀態同說明保持不變。

必要託管測試場景：載入真實模型，建立至少一個實際組裝步驟，再返回已啟用 Export 嘅整體組裝視圖。驗證每列保留嘅身分、字面同正則篩選、無結果、清除、建構器返回、Down／Up 導航、Enter 同 Escape。另行驗證空組裝嘅停用按鈕。擷取正常同最小尺寸、支援語言／主題同實測顯示縮放。唔可以只因選取或篩選一列，就報告匯出完成。冇執行本機建置、測試或介面；編譯同呢個測試場景仍待完成。

呢個彈出選單嘅動態效果仍係獨立未完成要求。修正保留原有 ImGui 彈出生命週期同共用搜尋標頭行為，但呢個呼叫點冇明確開啟、關閉或篩選列轉換掛鈎。唔會聲稱已驗證動畫或減少動態效果。全介面動態審查必須建立合適共用實作，並喺已建置應用程式驗證彈出開啟、關閉同篩選狀態轉換。
