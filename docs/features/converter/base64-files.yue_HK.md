# 喺原檔旁邊轉換 Base64

喺導覽或者命令選單開啟本機檔案轉換器，使用編碼或解碼按鈕揀最多 1,000 個檔案，亦可以拖到對應按鈕，之後執行佇列。呢兩個目標使用原有封裝工作程序路徑同本機佇列，唔會使用一般輸出資料夾欄位。

`report.pdf` 編碼後會喺原檔旁邊產生 `report.pdf.base64.txt`。解碼會還原 `report.pdf`；如果檔案已存在，就改用 `report (1).pdf` 等編號，唔會覆寫。編碼時產生嘅 `report.pdf.base64 (1).txt` 亦保留原名關係。其他名稱會依次參考允許嘅 data URL MIME 類型、有限位元組特徵，最後先用 `.bin`。程式唔會自動執行解碼內容。

結果表會顯示實際寫入路徑。選取已完成項目，再用顯示輸出資料夾按鈕，可以喺原生資料夾檢視揀中結果，唔會將檔名拼成命令。

## 驗證同限制

編碼來源同解碼結果最多 16 MiB。同資料夾解碼輸入最多 22,370,649 位元組，即 16 MiB 嘅補位編碼，加最多 1,024 位元組標頭同逗號。其他配接器保留原有輸入限制。使用有界記憶體，並非串流處理。目前只支援帶補位、無空白或換行嘅標準 RFC 4648 Base64。解碼可接受以 `;base64` 結尾嘅有限 data URL 標頭。URL-safe 變體、寬鬆解碼、文字編碼選擇、串流暫停及繼續、預覽同完整工具匯出及歷史仍未完成。

中介程序會透過工作程序作 SHA-256 往返比對，再檢查來源，將結果寫入獨佔暫存檔，重新讀取及比對雜湊之後先發佈。遇到另一個程序同時建立輸出，就另揀編號，最多檢查 10,000 個名稱。發佈前取消唔會產生完成結果；短暫原子寫入期間無法中斷，呢時取消可能仍會完成該檔。內容唔會記錄到日誌或者傳送上網。本機佇列保留來源、輸出路徑同固定結果代碼。

`tests/local_converter/run_base64_files.ps1` 會用已安裝 MSVC 編譯正式轉換核心、封存配接器同工作程序，以中性檔案、真實佇列同程序內轉換執行器測試。`-Mutant` 移除往返雜湊比較，必須失敗。呢啲證據唔代表已驗證封裝 AppContainer 啟動或者真正選檔及拖放介面。
