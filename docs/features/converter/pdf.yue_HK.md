# 本機 PDF 工具

類型化 PDF 轉接器喺隔離嘅轉換器工作程序入面，使用隨附嘅 qpdf 12.4.2 C API。佢只接受位元組陣列。中介程序會先按已編譯嘅雜湊值驗證每個隨附 DLL，先至載入確切已安裝嘅引擎。PATH、shell 指令、網絡服務同開發者安裝嘅工具永遠唔會啟用佢。

## 操作

| 操作 | 選項 | 結果 |
| --- | --- | --- |
| 檢查 | 一個來源 | 頁數、標準化旋轉角度、支援嘅中繼資料 |
| 分拆 | 一個來源 | 每頁一個已驗證嘅 PDF 位元組陣列 |
| 合併 | 多個來源 | 按來源次序排列頁面；中繼資料必須一致 |
| 抽取 | 明確、由 1 開始、唔重複嘅頁碼 | 按要求次序排列已揀頁面 |
| 重新排序 | 由 1 開始嘅完整頁碼排列 | 按要求次序排列全部頁面 |
| 旋轉 | 絕對 0、90、180 或 270 度；可選頁碼 | 已揀頁面旋轉；冇揀即係全部 |
| 中繼資料 | Title、Author、Subject、Keywords、Creator、Producer、CreationDate、ModDate、Trapped | 取代提供咗嘅欄位；其他支援欄位保留 |

轉接器支援靜態頁面樹。目錄動作、表格、註釋、大綱、頁面標籤、XMP 中繼資料、簽署、加密同其他不支援嘅文件層功能，都會安全咁失敗。佢永遠唔會靜靜咁丟棄呢啲功能。簽署權限字典會產生 `pdf_signed`；不支援、以表格為基礎嘅簽署容器會產生 `pdf_unsupported_catalog`。支援嘅中繼資料值必須係字串。其他表示方式，包括以名稱表示嘅中繼資料，都不可用。

輸入總共最多 16 MiB，輸出總共最多 64 MiB，來源/頁數最多 1,000，圖結構深度最多 64，每頁圖結構走訪最多 100,000 個項目。中繼資料值上限係 4,096 位元組。工作程序嘅記憶體、CPU、取消同零功能隔離，由中介程序嘅程序界線執行。

每個輸出都會重新開啟。驗證會將頁數、標準化旋轉角度、中繼資料，以及每頁連同資源同原始串流嘅結構表示，同要求嘅次序比較。間接物件編號同頁面父連結唔參與比較。唔相符會棄置所有傳回嘅輸出，並發出穩定代碼，例如 `pdf_validation_page_order`。解析器診斷同文件內容永遠唔會變成公開錯誤訊息。

轉接器只傳回位元組，永遠唔會寫目的地。中介程序必須驗證已安裝套件、經有上限嘅工作程序協定傳送要求，並透過獨佔嘅原子目的地發佈。多輸出分拆需要中介程序擁有嘅交易，或者明確揀選嘅封存輸出。類型化 API 測試唔能夠證明打包好嘅介面或者多輸出發佈已經完成。

## 驗證

`tests/local_converter/pdf_tests.cpp` 用真正嘅合成 PDF 文件，測試全部七個操作、重新開啟、選擇範圍、格式錯誤嘅輸入、不支援嘅目錄動作、中繼資料衝突同引擎可用性。測試會收到已暫存 qpdf DLL 嘅絕對路徑；正式載入必須用已驗證嘅套件。
