# 空白編輯器嘅「由預設開始」

**表面：** **由預設開始**揀選視窗
（`src/slic3r/GUI/Presets/StartFromPicker.{hpp,cpp}`）、預設模型
（`src/slic3r/GUI/Presets/BlankEditorPresets.{hpp,cpp}`）同出廠預設值總表
（`src/libslic3r/PresentationDefaults.hpp`）。

本來一開就乜都冇嘅編輯器，而家會先俾你揀預設，等新項目由真實嘅數值開始，而唔係由空白表格或者作出嚟嘅數值開始。

## 預設嘅數值從邊度嚟

預設只可以由以下其中一個來源攞數值：

- **出廠預設值。** 程式出廠時嘅數值，由出廠預設值總表讀取。`AppConfig::set_defaults()`（補返缺少嘅設定）同 **偏好設定 ▸ 外觀 ▸ 將外觀重設返預設值** 都係讀同一張表，所以預設同重設對出廠數值嘅講法一定一致。冇單一固定出廠數值嘅設定會唔包括喺入面，並會顯示原因：介面語言第一次開啟時會跟隨你嘅系統語言。
- **你已儲存嘅設定。** 你自己儲存咗嘅數值。如果某個設定未有可用嘅已儲存數值，預設會由呢個設定嘅出廠預設值開始，並標示「（出廠預設值，未有儲存）」，而唔會抄一個無效數值過去。
- **由空白開始。** 建立項目但唔設定任何嘢，每個數值都由你揀。
- **程式附帶嘅範本。** 例如程式附帶嘅外觀預設。

預設模型冇任何方法接受其他起始數值；佢嘅測試會檢查每個預設設定嘅數值，一定係出廠預設值或者你已儲存嘅數值。

## 揀選視窗會顯示乜嘢

- 預設會喺清單入面列出，用共用搜尋欄篩選。預設係純文字搜尋；搜尋欄亦可以開正規表示式建立器。搜尋亦會比對每個預設設定嘅內容，所以搜尋「Theme」會搵到所有會設定主題嘅預設。冇嘢符合時，視窗會講明，並話你知點樣再睇返全部預設。
- 對已標示嘅預設，喺套用任何嘢之前：會講明佢會建立乜嘢、每個會設定嘅設定同寫入嘅數值，以及每個唔包括嘅設定同原因。
- **由呢個預設開始** 會套用已標示嘅預設。**取消** 會關閉視窗，乜都唔會建立。

## 鍵盤同無障礙

- 視窗打開時，焦點喺預設清單。方向鍵會移動標示，說明會跟住更新。
- 喺清單入面撳 **Enter**，或者雙擊，就會由已標示嘅預設開始。撳 **Escape** 取消。
- 俾螢幕閱讀器用嘅名稱：清單叫「可以用嚟開始嘅預設」，說明叫「已標示預設會建立同設定嘅內容」。
