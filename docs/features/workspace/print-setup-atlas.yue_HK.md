# 打印設定同儲存傳送外觀

Studio Atlas 呢次原始碼更新涵蓋現有 `SelectMachineDialog`、打印機清單彈出視窗嘅行，
同 `SendToPrinterDialog`。只改外觀同局部尺寸，冇新增字串、設定、傳輸路徑或提交邏輯。

## 檢閱層次

打印工作檢閱將現有摘要、材料配對同選項分成有外框嘅色調卡片。材料標題同專案名稱
採用分組字體。名稱編輯用量度後嘅密度下限，唔再用 24/25 DIP 高度封頂。最後嘅
Send 按鈕沿用共用大型按鈕尺寸同 DPI 縮放；確認／進度區按頁面量度，唔再將按鈕
限制喺 32 DIP 高度。

原有捲動容器嘅高度，取內容高度、650 DIP 理想高度，以及目前螢幕工作區扣除實際
標題、頁尾、診斷、原生外框同留白後空間之中最細嘅值。計算會喺加入標題後，以及
DPI、進度高度或診斷版面改變時執行。原有置中後唔會再搬動視窗，亦唔改檢閱頁面。
剩餘空間不大於零就分配零高度，唔會發生無號整數回繞，亦唔會硬塞一個放唔落嘅
正數下限。如果螢幕細過固定控制本身，仍然要原生檢查；算式唔會憑空變出螢幕空間。

儲存傳送先顯示專案名稱，再顯示真正縮圖同統計。縮圖改為 198 DIP，留多啲位置俾
目的地同儲存選項。打印機同儲存控制用同一套卡片，Refresh 用色調樣式，明確嘅
Send 保留填色主按鈕。儲存項目、傳送進度同取消控制仍然係原有物件。

打印機清單嘅行會填滿現有可視範圍，行高按密度量度，游標停留同焦點用帶色調背景
同圓角外框區分。狀態圖示保留原本意思；編輯／解除綁定嘅繪畫位置同點擊範圍、
裝置識別、鍵盤操作、篩選、正則表達式工具、計時器同連線路徑全部保留。分組標題
更清楚，清單喺現有彈出視窗內彈性分配高度，唔再同搜尋行一齊硬塞舊有完整高度。

## 保留嘅動作

目前／所有打印盤輸入、AMS 同噴嘴配對、相容性／就緒檢查、最後確認、改名驗證、
傳輸提交、取消同等候工作結束、儲存選取同復原邏輯都冇改。開啟或重設樣式唔會
發送或打印，幾何回呼只會調整現有控制嘅尺寸同排列。

同 `7602228306b7dba316a2d7a91c1f2a195de0e43b` 比較後，32 個敏感函式內容完全
相同，包括打印／儲存提交、取消、打印盤準備、AMS 配對、就緒啟用、鍵盤選取，
同現有實體動作確認分支。呢個係原始碼保留證據，唔代表已經真正操作過原生介面。

## 尚待檢查嘅內層畫面

以下現有延續流程喺呢次保留原有實作，仲要分別做外觀同執行時檢查：

| 類別 | 內層畫面 |
| --- | --- |
| 材料同噴嘴 | `AmsMapingPopup`、`AmsMapingTipPopup`、`AmsTutorialPopup`、`AmsReplaceMaterialDialog`、`ReselectMachineDialog` |
| 最後打印決定 | `ConfirmBeforeSendDialog`、局部縮時錄影儲存選擇同警告對話框、噴嘴／耗材 `MessageDialog` 警告 |
| 連線同帳戶 | `ConnectPrinterDialog`、`InputIpAddressDialog`、`BindMachineDialog`、`UnBindMachineDialog`、登入 `SecondaryCheckDialog` |
| 裝置管理 | `EditDevNameDialog`、PIN 碼同直接連線行 |
| 傳送復原 | `SendFailedConfirm`、改名／傳送 `MessageDialog` 提示、原有狀態列進度／取消內容 |

清單根據原始碼呼叫同彈出視窗成員整理。實際可達路徑、內層各種狀態、新卡片容器
嘅鍵盤導覽同無障礙輸出仍未驗證，唔代表呢啲內層畫面已重新設計，更唔代表全個
應用程式都已經符合 Studio Atlas。

## 驗證同私隱

集中檢查合共十個測試通過。實際 C++17 高度工具通過 106 個斷言，涵蓋較矮螢幕、
100/125/150/200% 縮放、自然內容大小、進度／診斷預留空間、零或負空間同整數邊界。
刻意忽略可用螢幕高度就會令反例測試失敗。現有 Print 狀態模型另外通過 30 個行為
斷言，包括忙碌／過時狀態唔准輸出。對話框標頭引用同標題同步檢查亦通過。

呢次冇完整原生建置、啟動應用程式、執行安裝程式、實體指令或截圖。英文、廣東話、
雙語、兩個主題、一般同最小支援視窗、四種縮放、傳送中取消同最後確認操作，全部
仲要真正建置後驗證。儲存傳送繼續用原有共用對話框，呢次冇聲稱替佢新增完整內容
捲動。冇新增資料流或持久設定。之後截圖要用隔離嘅非私人裝置／專案名稱，唔可以
露出存取碼或帳戶資料。
