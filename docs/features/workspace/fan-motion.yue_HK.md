# 裝置風扇運動

裝置頁面獨立預覽部分冷卻和輔助風扇。每行保持可訪問百分比滑桿並為指令打開現有風扇控制對話框。葉片圖像文字以與報告風扇速度成正比嘅速率旋轉，為零件和輔助冷卻提供不同形狀和速率。滑桿軌跡喺報告數值之間緩和。按壓環本地確認輸入，而單獨的漣漪標記已發送指令，直到匹配嘅遙測到達。

初始遙測設定顯示而無軌跡過渡。相同民意調查唔重新啟動運動、零速度停止旋轉，新速度重新定位目前過渡。計時器喺控制項被隱藏時停止。視圖喺斷開連接或打印機改變時重設，減弱運動顯示最新報告值而無動畫。對話框保持負責風扇可用性、打印警告、空氣管道模式和指令提交。

預覽儲存無用戶設定或指令歷史記錄，唔進行網絡請求。如果遙測停止，最後報告嘅速度保持可見，待處理指令漣漪保持待處理而不係暗示確認。

`tests/native_gui/fan_motion_math.cpp` 檢查 PWM 轉換、指令匹配、重新定位和零速度。原生裝置構建和互動捕獲仍然係渲染、可訪問性和計時嘅檢查。
