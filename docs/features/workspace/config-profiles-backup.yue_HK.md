# 設定檔案同完整資料備份

**表面：** `檔案 ▸ 設定檔案同備份…` → `ConfigProfilesDialog`（`src/slic3r/GUI/ConfigProfilesDialog.{hpp,cpp}`、大門組件 `src/slic3r/GUI/Widgets/SlideToConfirm.{hpp,cpp}`）。

## 行為

- **匯出所有嘢…** 打包**整個活動資料目錄** ： 預設、物理打印機主機、訪問碼、網絡外掛登入狀態、API 權杖、快取 ： 到一個單一 `.zip` 由用戶選擇。冇嘢係被編輯：要點係一個位元組忠實遷移檔案另一部電腦可以匯入。鎖定/臨時檔案（實時日誌、鎖定檔案）被跳過代替失敗匯出。
- **匯入備份…** 拆開這樣一個存檔到一個**新檔案** 喺 `<data-dir-parent>/BambuStudio-profiles/<name>/`。實時資料目錄永遠唔被一個匯入觸及；一個 zip 滑移守衛拒絕存檔帶著路徑逃脫條目。
- **檔案** 係無限兄弟資料目錄。清單（可搜尋 ： 丸子帶著共享正則表達式構建器）總係包括活動資料目錄作為「目前（活躍）」。**啟動檔案** 開始第二個竹子工作室實例帶著 `--datadir` 指向選擇檔案。
- **立即快照 / 歷史…** 給**每個**檔案一個本地、Git 支援快照歷史由相同引擎驅動作為項目版本歷史（`ProjectHistoryManager`）：每個快照係檔案嘅一個完整壓縮影像提交到一個隔離裸露倉庫喺檔案根。恢復**總係建立一個新檔案**（`<name>-restored…`）；冇嘢被覆蓋或倒帶。

## 安全考慮

- 傳輸卡片係用 MD3 錯誤容器角色同狀態樣式明確陳述存檔**包含機密**（打印機訪問碼、登入狀態、權杖、物理打印機密碼）。
- 兩個匯出同匯入都住喺一個**滑到確認**大門背後（`SlideToConfirm`）：一個有意圖拖動（或方向鍵走 ： 控制係完全鍵盤可操作：右/上推進、結束完成、主頁重置）必須完成按鈕啟用前；每個完成行動重新武裝大門。一個流浪點擊無法匯出或匯入。
- 存檔本身係**未加密** ： 對話框說所以同告訴用戶安全儲存/轉移佢。快照同歷史倉庫保持本地；冇嘢被同步或推動。

## 失敗模式

- 無法寫入目標 / 滿磁碟 → 明確錯誤、大門重新武裝。
- 無法讀取存檔、唔安全（路徑遍歷）存檔、或無法寫入檔案資料夾 → 匯入中止帶著一個具體訊息；冇部分檔案被啟動。
- 歷史引擎無可用（倉庫初始化失敗）→ 快照/歷史按鈕禁用；匯出/匯入保持工作。

## 驗證

- 用 Mesa llvmpipe 無頭構建同通過 Lowlevel MCP 便宜 CLI 驅動：對話框從檔案選單打開、滑動大門帶著鍵盤 `End` 武裝、匯出寫一個 zip 條目計數符合資料目錄嘅常規檔案、匯入往返相同 zip 到一個新檔案即時列出。
- 語言模式：所有用戶面向字串係喺策劃 `yue_HK` 目錄（`compile_translation.py --check` 綠、494 條目）。

## 復原安全更新

壓縮檔會拒絕父目錄跳轉、絕對路徑、替代資料串流同設定檔範圍外嘅輸出。解壓時唔會覆寫已存在嘅檔案，讀寫串流錯誤會明確報告。偏好設定復原亦會保留既有復原檔案，唔會先刪除再嘗試複製。

背景工作期間關閉對話框，會先保留對話框生命週期及回應能力，直到取得 future 結果。失敗操作仍然可見。託管 Windows 上嘅實際操作仍要驗證。

目錄以原子方式預留，檔案以獨佔方式建立，避免第二個執行個體共用同一輸出。報告成功之前，會核對 ZIP 項目 CRC、長度同中央目錄結尾。失敗時只移除今次呼叫建立嘅檔案及空目錄，保留既有或未記錄項目。保留裝置名稱、尾隨句點或空格、磁碟機前綴及替代資料串流，都喺建立輸出之前拒絕。

`profile_archive_tests` 涵蓋新建及既有目的地、兩個並行操作、路徑跳轉、重複項目、非 ZIP、截斷目錄結尾同錯誤 CRC。測試已寫入但未喺本機執行，仍須由託管 Windows 編譯及執行。
