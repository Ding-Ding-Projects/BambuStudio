# 工作空間套件和規劃

一個 `.bambu-workspace` 檔案係一個相關項目集合嘅版本化 ZIP 容器。佢嘅 `Metadata/workspace.json` 清單有穩定嘅套件 ID、成員 ID、概覽標題和註釋、待辦清單和規劃打印槽。成員項目放喺 `Members/<id>/project.3mf` 下；可編輯源檔案放喺 `Sources/<id>/<relative-path>` 下。每個項目 3MF 複製一次，包括已內嵌喺該 3MF 中嘅任何歷史記錄。工作空間唔會複製項目嘅歷史記錄作為單獨嘅套件。

項目螢幕有一個原生工作空間子視圖，喺現有嘅在線項目視圖旁邊。原生子視圖提供概覽、檔案、待辦清單、註釋和月份／議程分頁。佢可以打開和儲存套件、加入擁有嘅項目 3MF 和可編輯源、編輯和重新排序待辦項目、加入規劃槽，和匯出待辦清單或日曆資料。切換視圖唔會替換打印畫布上嘅目前模型。打開成員進入該畫布和寫入其幾何狀態回到套件需要下面所述嘅應用程式級別移交。

## 行為

- 套件儲存對每個擁有嘅檔案進行雜湊、喺目的地旁邊暫存 ZIP、重新打開佢、驗證每個列出嘅項目，並原子性地替換目的地。失敗嘅儲存保留先前的檔案和待處理 ZIP 以供恢復。
- 加載喺提取任何項目前驗證整個 ZIP。提取僅進入呼叫者嘅私有暫存根嘅新建子項。呼叫者擁有成功加載嘅暫存目錄嘅清理。
- 帶有內嵌便攜式歷史記錄嘅成員使用一次性私有存儲中嘅已界定歷史記錄檢查器進行檢查，然後發佈套件。損壞嘅歷史記錄阻止替換有效套件。加載外部更改嘅套件時，成員字節保持暫存，因此有效幾何仍然可以恢復，並且面板明確報告任何損壞嘅成員歷史記錄。
- 待辦清單項目有穩定嘅 ID、順序、完成、可選嘅日期限制和到成員或規劃槽嘅連結。截止日期帶有佢們選擇嘅 UTC 偏移量，用於 09:00 本地提醒，包括夏令時過渡。規劃槽儲存 UTC 開始和結束瞬間、IANA 區域標籤和為其牆上時間選擇嘅偏移量。
- 計劃人喺打印機 ID 不可用或一台打印機嘅兩個啟用槽重疊時發出警告。佢永遠唔會提交打印。應用程式執行時，工作空間面板每分鐘檢查一次提醒，打開或重新出現時檢查。佢使用現有嘅非阻止通知表面。已恢復或重新打開嘅工作空間將被遺漏嘅提醒分組為一個補救通知。其最後交付嘅檢查按套件 ID 本地儲存。延遲和駁回喺有儲存路徑時立即更新套件，而未儲存嘅新工作空間仍需明確儲存。預設值係規劃槽前 15 分鐘和日期限制嘅 09:00 本地時間。
- 日期限制保持套件和 iCalendar 匯出中嘅日期。喺 Windows 10 版本 1903 及更新版本上，計劃人使用作業系統嘅 ICU 時區資料為該到期日期解析已儲存 IANA 區域中嘅 09:00。佢驗證已儲存嘅偏移量，喺衍生當前區域規則嘅提醒瞬間時標誌分歧清晰可見。未知、自訂或不可用區域保持日期完整，並暫停受影響嘅提醒，並提示警告。計時槽保留 UTC 瞬間和命名區域。佢們嘅編輯器分別解析開始和結束，拒絕不存在嘅時鐘時間，並喺夏令時變化期間時鐘時間重複時詢問使用哪一個發生。喺其他平台上，命名區域解析保持不可用並被報告；UTC 和 Etc/UTC 繼續工作。
- 待辦清單 JSON 和 CSV 匯出和 UTC iCalendar 匯出僅包含規劃資料。佢們唔包含項目檔案、認證或打印指令。
- 打開成員會複製佢到私有分頁擁有 3MF 路徑。儲存喺該穩定路徑下提交其快照一次，發佈完整便攜式歷史記錄到該位置，然後複製已驗證嘅檔案到原子套件發佈嘅不可變候選項。失敗嘅套件儲存保留舊套件完整，並保留已完成嘅私有檔案和候選項以供恢復。重複儲存喺無其他實時文件擁有時保留內嵌文件 ID；真正分岐嘅實時副本會收到單獨嘅 ID。

## 限制和驗證

清單限制為 1 MiB、ZIP 為 256 項目和 2 GiB 展開，每個檔案為 1 GiB。加載器拒絕未列出或重複項目、不安全路徑、無效 ID 和類型、不受支援嘅版本、變更長度或 SHA-256 雜湊，和過度壓縮比。ZIP CRC 驗證喺每個項目流式進行雜湊時執行。

## 驗證

初始後端修訂通過四個重點案例和 58 項聲明，用於往返 ID 和檔案、遍歷拒絕、失敗儲存後嘅先前檔案保留、缺少打印機和重疊警告、提醒補救，以及 JSON、CSV 和 ICS 匯出。後來嘅源驗證和原生 UI 編輯尚未編譯或本地執行，因為構建已移動到 CI。加入嘅竄改成員、無效 3MF 和穩定工作空間成員身份檢查待處理該 CI 判決。喺活躍畫布中打開成員、將其儲存狀態返回到套件，和最近項目整合現在有應用程式連接。實時提醒分派有源整合但仍需託管構建和執行時驗證。
