# 帶選項卡嘅設定同埋共用嘅選項卡條

應用程式入面每個帶選項卡嘅表面都會經由一條共用嘅、似瀏覽器咁嘅 Material Design 3 選項卡條來展示：`src/slic3r/GUI/Widgets/TabStrip.{hpp,cpp}`。
項目選項卡條（`ProjectTabBar`）而家係佢上面一個簡單嘅、基於索引嘅介面，
而「偏好設定」對話框就將佢嘅各部分展示為同一條選項卡上面嘅選項卡，
而唔係一個特製嘅導航欄。數據規則係放喺一個只有頭文件嘅、冇 GUI 嘅模型裏面，`Widgets/TabStripModel.hpp`，所以佢哋可以喺冇執行應用程式嘅情況下進行單元測試（`tests/tab_strip`）。

## 行為

### 停靠邊

- 選項卡條可以停靠喺**左、右、頂部或底部**。邊係從選項卡條嘅右鍵選單入面揀（**停靠選項卡條 ▸**），並且係按個別表面來儲存嘅。
- **左邊係設定表面嘅預設邊**（一個螢幕寬度比高度要大，而標籤寬度亦比高度要大，所以一條豎直選項卡條可以展示更多選項卡）。**頂部係項目選項卡嘅預設邊。**
- 停靠係一種方向改變，唔係旋轉：標籤從來唔會被畫成側向。一條豎直選項卡條係一條 230 像素寬嘅欄（SurfaceContainerLow，1 像素 OutlineVariant 分隔線喺內容邊，44 像素 NavItem 藥丸型按鈕帶着 SecondaryContainer 嘅選中樣式）；一條橫向選項卡條係一條 52 像素高嘅欄（Surface 填充、Brand-primary 活動下劃線）。主機會喺 `EVT_TABSTRIP_DOCK_CHANGED` 時重新排置選項卡條（`MainFrame::place_project_tabbar`、`PreferencesDialog::place_settings_strip`）。

### 溢出

- 當顯示嘅選項卡超過選項卡條嘅主軸時，冇位置放嘅選項卡會進入一個溢出「更多選項卡」Material 選單入面，而唔係被剪裁。計算方法（`MD3::Tabs::compute_overflow`）係由兩個方向共用嘅：呼叫方會為橫向選項卡條傳送寬度，為豎直選項卡條傳送高度。已固定嘅選項卡總係保持可見；溢出按鈕本身嘅空間只有喺有嘢溢出時先至會被預留。
- 喺隱藏時關閉嘅表面（設定）上面，同一個選單亦會列出用家由選項卡條藏起嚟嘅選項卡，各個都標記著 *（已隱藏，按此以恢復）*。

### 重新排序

- 沿著選項卡條嘅軸拖拽一個選項卡來重新排序；**Ctrl+Shift+方向鍵**（匹配方向嘅方向鍵）可以用鍵盤將焦點選項卡移動。
- 移動會受限於選項卡自身嘅區域：一個未固定嘅選項卡永遠唔可以掉進固定區域裏面，反之亦然。

### 固定

- **固定選項卡 / 取消固定選項卡**（右鍵選單、**Ctrl+P**）。固定嘅選項卡會佔據一個專用領先區域，喺其他選項卡溢出時保持可見，攜帶一個固定標記，失去佢哋嘅關閉功能，並且會被排除喺單個關閉、**關閉包含 / 不包含文字嘅選項卡**（預設情況下）、Delete 同埋 Ctrl+W 之外。批量關閉對話框有一個明確嘅**包含固定選項卡**揀項，其效果會喺關閉任何嘢之前被預覽。

### 分組

- **用呢個選項卡新建組…**會建立一個有名字、有顏色嘅組；**移入組…**會打開一個選擇器對話框（唔係一個內聯選單列表），列出現存嘅組，帶着名字、顏色同埋成員數量，一個誠實嘅空狀態、一個**新建組…**路徑，同埋佢自己嘅 `SearchField` 同埋錨定嘅正則運算式構建器。方向鍵、Enter 同埋 Escape 可以操作佢；焦點返回到選項卡條。
- 組頭會出現喺每個組執行之前（一個顏色芯片、名字同埋一個雪佛龍）。按一下頭可以摺疊或展開組；佢嘅右鍵選單提供**重新命名組…**、**改變組顏色…**（MD3 無限色譜選擇器）、**摺疊 / 展開組**、**搜尋呢個組入面嘅選項卡…**、**移除組（保持選項卡）**同埋**編輯組外觀…**。
- 一個摺疊嘅組只會展示佢嘅活躍成員。一個摺疊組入面嘅搜尋結果會被*揭示*（同活躍成員一起展示），而唔需要改變摺疊偏好；呢個揭示係臨時嘅，永遠唔會被儲存。
- 將一個選項卡移入一個摺疊組會將該組保持摺疊。

### 持久性

順序、固定狀態、隱藏狀態、組成員、組名稱 / 顏色 / 摺疊狀態、停靠邊同埋活躍選項卡會作為一份 JSON 文件，按表面儲存喺 `BambuStudio.conf` 嘅 `[tab_strips]` 下面（`preferences`、`projects`）。選項卡係由代碼構建嘅表面（偏好設定）會呼叫 `TabStrip::LoadLayout()`，佢會將儲存嘅佈局應用到選項卡上面，使用穩定嘅 id（`adopt_layout`：唔識嘅儲存 id 會被丟棄，新部分會喺已知部分之後按建立順序排列）。項目選項卡條將佢嘅選項卡完全儲存喺佈局入面（`LoadTabsFromLayout`）並一次性匯入舊版嘅 `[project_tabs]` / `[tab_groups]` 部分。

### 關閉

- **設定表面**：「關閉」係指*由選項卡條隱藏*。部分會保留喺模型同埋搜尋索引裏面，可以由溢出選單恢復，並且喺設定搜尋傳送到佢嘅一行時重新出現。
- **項目選項卡**：關閉係真實嘅。選項卡條會升起 `EVT_TABSTRIP_CLOSE_REQUEST`（被翻譯為 `EVT_PROJECT_TAB_CLOSE`），MainFrame 會喺移除選項卡之前執行佢嘅未儲存工作確認。

### 批量關閉

有兩個操作係住喺每個選項卡條 / 選項卡 / 組右鍵選單裏面：
**關閉包含文字嘅選項卡…**同埋**關閉不包含文字嘅選項卡…**。兩個都會打開同一個對話框：一個 `SearchField`（預設為純文字，「.*」切換同埋 `tune` 構建器用於正則運算式）、一個**關閉「不」包含文字嘅選項卡**開關，這樣反面運算會對正好相同嘅述語進行反運算、**包含固定選項卡**揀項，同埋一個實時預覽，顯示匹配模式（「包含文字 · 純文字」 / 「不包含文字 · 正則運算式」）、精確數量同埋每個受影響嘅標題。喺空查詢、無效模式或零匹配時，關閉按鈕保持禁用。匹配只會針對可見嘅選項卡標籤。

### 四個選項卡發現搜尋

每個都係一個對話框，帶着佢自己嘅 `SearchField` 同埋錨定嘅正則運算式構建器，位置喺打開佢嘅選項卡條旁邊：

1. **搜尋選項卡…**（**Ctrl+Shift+K**，喺選項卡條有焦點時、搜尋圖示喺選項卡條嘅尾端，或右鍵選單）、 當前選項卡條。
2. **搜尋呢個組入面嘅選項卡…** 、 只得一個組（從該組入面嘅選項卡或組頭）。
3. **搜尋選項卡組…** 、 組（按佢哋嘅可見名稱）。
4. **搜尋所有選項卡…** 、 應用程式擁有嘅每條選項卡條上嘅主搜尋（`TabStrip::Registry()`：項目選項卡加每個打開嘅設定選項卡條）。

結果會讀成 `Surface › strip › group (摺疊) › title [固定] [隱藏]`；
Enter 或**前往選項卡**會啟動命中，揭示摺疊組入面嘅選項卡，而唔需要破壞摺疊偏好，同埋取消隱藏已隱藏嘅選項卡。

### 右鍵選單同埋快捷鍵

每個有正常快捷鍵嘅項都會展示佢，靠右對齐，同埋快捷鍵係選項卡條自己嘅鍵盤處理程式喺選項卡條有焦點時實現嘅：**Ctrl+P** 固定 / 取消固定、**Ctrl+W** 或 **Delete** 關閉 / 隱藏、**Ctrl+Shift+K** 搜尋選項卡、**Ctrl+Shift+E** 編輯選項卡外觀、**Ctrl+Shift+方向鍵**重新排序、**Enter / Space** 啟動、**Home / End**、**Shift+F10 / Menu** 打開選單。選單攜帶**編輯選項卡外觀…**、**編輯組外觀…**同埋**編輯選項卡條外觀…**；喺選項卡、組頭或選項卡條上 Shift+右鍵會直接打開匹配嘅編輯器。

### 外觀編輯器鉤子

編輯器係經由弱鉤子來連接嘅，所以呢條車道唔需要依賴外觀編輯器車道：

```cpp
TabStrip::SetAppearanceEditorHook([](wxWindow *anchor, const std::string &element_id) {
    AppearanceEditor::open_for(anchor, element_id);
});
```

`element_id` 係 `tabstrip:<surface>`、`tab:<surface>:<tab id>` 或
`group:<surface>:<group id>`。直到鉤子被安裝為止，選單項係存在嘅，但係冇作用（`TabStrip::HasAppearanceEditorHook()` 會報告狀態，這樣主機就可以按需要標籤佢哋）。

### 無障礙性

- 選項卡條會公開一個 `PAGETABLIST`，每個顯示嘅選項卡都有一個 `PAGETAB` 子項（`TabStripAccessible`），名稱包括固定狀態同埋組、選中 / 焦點狀態、螢幕位置同埋一個*開關*預設操作。
- **方向遵循軸，唔係標記**：一條豎直選項卡條宣佈自己係一個豎直選項卡列表，並用**上 / 下**移動焦點；橫向嘅用**左 / 右**（`MD3::Tabs::arrow_step`）。焦點係迴旋式嘅（選項卡條擁有鍵盤焦點，並喺焦點選項卡上繪製一個主要焦點環），所以 Tab 係一步就離開選項卡條。
- 選項卡條冇自己嘅動畫，所以減速運動偏好係簡單地被尊重；Material 選單同埋佢打開嘅對話框遵循 `MD3::Motion::reduced()`。
- 標籤會喺末端縮略，並攜帶完整標題作為工具提示；冇嘢被旋轉，豎直欄會摺疊選項卡進入溢出選單，而唔係喺短高度時被剪裁。

## 表面

| 表面 | 選項卡條 | 預設邊 | 關閉意思 |
| --- | --- | --- | --- |
| 項目選項卡（`ProjectTabBar`、MainFrame） | `projects` | 頂部 | 真實關閉，MainFrame 確認 |
| 偏好設定部分（`PreferencesDialog`） | `preferences` | 左 | 由選項卡條隱藏，由溢出選單恢復 |

偏好設定嘅**外觀**部分係偏好設定選項卡條嘅一頁，所以佢係由同樣嘅選項卡覆蓋嘅。偏好設定現存嘅設定搜尋（行過濾、高亮、傳送）係唔變嘅：另一頁上嘅一場匹配會切換書*同埋*揭示該頁嘅選項卡喺選項卡條入面（`Activate(id, emit=false)`）。程式化部分選擇，包括由命令板進行嘅設定跳轉，使用同一個穩定嘅選項卡 ID，所以已重新排序或隱藏嘅選項卡保持同步。

### 故意唔帶選項卡嘅表面

- **配置檔案對話框**（`ConfigProfilesDialog`）：一份檔案嘅列表，帶着搜尋欄同埋操作；佢冇用家需要導航嘅部分，所以冇嘢可以帶選項卡。佢會保持佢嘅帶正則運算式構建器嘅 `SearchField`。
- **預設編輯器**（`Tab.cpp`、打印 / 墨水 / 打印機參數頁面）：佢哋嘅部分形成一個階層式頁面樹（`TabCtrl`），由預設系統驅動，頁面按打印機能力出現同埋消失。將該樹轉換為一條平坦條帶係一條獨立嘅車道；佢被記錄喺呢度，這樣空隙讀起嚟係一個決定，而唔係一個遺漏。

## 配置

`BambuStudio.conf` 入面嘅 `[tab_strips]`，每個表面鍵一份 JSON 值。刪除一份值會將該表面重置為佢嘅發運順序、未固定、未分組、所有部分都展示、預設停靠邊。

## 故障模式

- 格式錯誤嘅佈局 JSON 會被忽略（`Model::from_json` 返回 false 而模型保持唔變）；表面從佢嘅代碼順序開始。
- 一份儲存嘅佈局命名一個不再發運嘅部分時，會丟棄該項；一份儲存嘅組 id，冇選項卡引用佢時，會被保留（空組只有喺用家移除佢哋時先至被移除）。
- 批量關閉對話框故障時會閉合：無效嘅正則運算式或空文字會禁用該操作同埋說明原因；共用匹配器喺無效模式上嘅故障開放行為因此永遠唔會從呢個對話框被達成。
- 如果一個隱藏嘅設定部分係一份設定搜尋嘅唯一匹配，傳送會取消隱藏佢，這樣行就可以被展示。

## 安全考慮

佈局 JSON 只持有選項卡 id、標題同埋（針對項目）檔案路徑。正則運算式求值會經由邊界式、隔離嘅 `BoundedRegex` 工作者，使用與每條其他搜尋欄相同嘅限制。

## 驗證

- `tests/tab_strip/tab_strip_tests_main.cpp`（Catch2、wx 核心專用）：固定區域不變量、區域夾持重新排序、組建立 / 指派 / 連續 / 摺疊 / 揭示 / 移除、隱藏選項卡、JSON 往返（順序、固定、組、顏色、摺疊、邊、活躍；臨時揭示未持久化；穩定序列化）、拒絕格式錯誤嘅 JSON、將 `adopt_layout` 變換到代碼構建選項卡、橫向（寬度）同埋豎直（高度）選項卡條嘅溢出，固定總係可見、批量關閉拒絕空同埋無效模式、述語加反面分割，固定被排除，包含固定覆蓋、搜尋結果形狀（表面 / 選項卡條 / 組 / 固定 / 隱藏 / 摺疊、組過濾、組搜尋）同埋方向鍵方向規則。構建方法：睇 `tests/tab_strip/CMakeLists.txt`。
- 每份被改變嘅 `.cpp` 都用 `cl /Zs` 針對 GUI 項目嘅包含目錄同埋定義進行咗語法檢查。
