# 類瀏覽器項目標籤

一個瀏覽器風格標籤欄喺工作區上方：一個標籤按項目、一個 `+`
新標籤按鈕、按標籤關閉同快照基礎切換──喺切片器嘅單一文件架構內。

## 行為

- 標籤條帶（`src/slic3r/GUI/ProjectTabBar.{hpp,cpp}`）顯示一個標籤按
  開啟項目（分組：一個標籤*係*一個項目）。活躍標籤被突顯
  附帶 MD3 主要下劃線處理。
- `ProjectTabBar` 係項目面嘅共用瀏覽器風格條帶
  （`Widgets/TabStrip`、見 [標籤設定同共用標籤條帶](tabbed-settings.md)），
  所以項目標籤攜帶整個標籤合約：一個**停靠邊緣**（預設頂部；左 / 右變條帶成側邊欄旁邊工作區、
  底部放佢喺下面──`MainFrame::place_project_tabbar` 重新放置佢）、
  一個**溢位選單**何時標籤超越寬度、**拖動同鍵盤
  重新排序**、**固定**（固定項目保持無關閉優惠同
  預設被排除出批量關閉）、**分組**附帶
  「移動入分組…」選擇器、**四個標籤搜尋**（呢個條帶、一個分組、
  按名稱分組同橫越每個條帶主搜尋包括
  設定部分）、兩個**批量關閉**動作、情境選單嗰啲
  顯示佢哋嘅快捷方式同攜帶**編輯標籤外觀…** / **編輯分組
  外觀…** 同 `tablist` / `tab` 可存取角色，其箭鍵
  跟隨條帶嘅方向（左 / 右何時停靠頂部或底部、
  上 / 下何時停靠左或右）。
- 激活係主機確認：一個點擊、回車、一個溢位選擇或搜尋
  命中只*要求*（`EVT_PROJECT_TAB_SWITCH`）；條帶標記標籤活躍
  一次 `MainFrame::switch_project_tab` 已儲存外傳快照同
  載入入來快照、所以一個失敗開關永遠唔讓條帶指向
  一個項目嗰個唔係喺螢幕。
- **切換**（`MainFrame::switch_project_tab`）：外傳項目係
  序列化到臨時 `.3mf` 快照（`Plater::save_snapshot_to`、完整
  備份策略存檔）、入來標籤嘅快照係載入
  （`load_snapshot_from`）同項目身份（檔案路徑、髒狀態）係
  恢復按標籤。標籤同步事件喺開關期間被門控以防止
  重入。
- **關閉**（`MainFrame::close_project_tab`）：髒標籤──包括
  背景（非活躍）髒標籤──提示確認關閉之前
  （一個真實決定、所以一個模態對話按設計）。
- **新標籤**（`+`）：開啟一個鮮新未命名項目標籤。

## 配置

條帶佈局──標籤順序附帶每個標籤嘅檔案路徑、固定狀態、分組、
折疊狀態、停靠邊緣同活躍標籤──係一個 JSON 值喺
`[tab_strips] projects` 喺 `BambuStudio.conf`。舊 `[project_tabs]` 同
`[tab_groups]` 部分係匯入一次何時冇佈局存在。每個標籤嘅
項目保持佢個人版本歷史透過按項目身份（見
[項目版本歷史](project-version-history.md)）。

## 故障模式

- **切換時快照儲存/載入故障** → 開關異常同目前
  項目保持活躍（冇部分交換）。
- **恢復髒恢復標籤嘅復原**：檔案身份被重新應用在快照之後
  載入（`set_project_filename`）、所以儲存仲然目標正確
  路徑（喺敵對性審查之後修正）。

## 安全考慮

快照被寫到應用程式臨時/分階段位置只；關閉標籤
刪除佢嘅臨時快照。

## 驗證

- 運送在一個三項發現敵對性審查之後（身份復原、外傳
  快照損壞、背景髒關閉確認）──全部修正。
- 標籤條帶、新標籤按鈕、活躍/非活躍狀態擷取喺截圖
  矩陣喺 `docs/screenshots/project-tabs/` 底下。
