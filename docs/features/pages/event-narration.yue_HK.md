# 瀏覽器事件旁白

旁白預設關閉。可以揀英文、香港廣東話或兩者，兩者先讀英文再讀廣東話，唔會重疊。一般訊息有 15 秒同類別冷卻期，隊列入面較舊嘅一般文字由新文字取代。警告同錯誤唔受此冷卻期影響。隊列最多 12 段，每段最多 2,000 字元，唔會暗中截短事實。

每種語言有獨立聲音選擇器，同自己嘅搜尋及正規表示式建構器。預設自動選擇；清單按已安裝聲音更新，收到 `voiceschanged` 會再查。選擇用 `voiceURI` 儲存，聲音移除後保留選擇並列明替代聲音。廣東話接受 `yue` 同 `zh-HK`，唔會改讀普通話。

速度 0.1 至 10，音高 0 至 2，兩者預設 1。自動選擇優先本機聲音；網絡聲音會講明平台服務處理旁白文字，離線可能未能使用。網頁本身唔會為旁白發送 fetch。

暫停取消現時同隊列旁白。瀏覽器未能可靠偵測屏幕閱讀器，此控制係避免旁白同輔助技術爭聲嘅明確途徑。停止只清隊列，關閉亦清隊列，取消後嘅遲來回呼唔會重新播放。

9 個旁白來源測試同 24 個既有用字及網頁測試通過。指令面板、共享 School 模式、歷史同實際瀏覽器證據仍未完成。
