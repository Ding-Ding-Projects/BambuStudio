# 本機個人用字

設定有一直可見嘅本機 JSON 檔案選擇器、更換同清除控制。預設未載入檔案。有效檔案只改變此瀏覽器嘅介面用字同無障礙名稱，唔會改網址、程式碼、路徑、輸入值或發行事實。替換只行一次。

格式係 `schemaVersion: 1` 同 `entries` 字串映射。限制：262,144 UTF-8 位元組、深度 3、1,024 項、鍵 160 個 UTF-16 單位、值 320 個單位。空字串、重複鍵、不安全鍵、未知欄位、控制字元、錯誤 JSON 同未知版本全部先被拒絕，唔會部分套用，之前有效嘅檔案仍生效。

只快取已驗證內容，唔儲存原檔名或路徑，每次載入重新驗證。唔會發送網絡請求或加入匯出、診斷、通知及歷史。清除會刪快取並即時還原。儲存不可用時會講明只於今次瀏覽生效；清除失敗保留現況，並指出瀏覽器網頁資料重設途徑。

設定搜尋包括此控制同旁邊嘅完整正規表示式建構器。指令面板、共享 School 模式同實際瀏覽器證據仍待整合。
