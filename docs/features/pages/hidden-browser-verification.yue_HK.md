# 隱藏瀏覽器驗證

`ui-md3/scripts/site-wording-runtime.mjs` 從指定提交建構候選版本，計算每個輸出檔案嘅雜湊，透過已安裝嘅低成本隱藏桌面途徑，用全新 Microsoft Edge 訪客設定檔啟動瀏覽器。整份除錯目標清單必須有且只有預期嗰個頁面。每批互動同每次截圖之前，都會呼叫標準 `verify-edge-target.mjs`。測試上載中性本機 JSON、重新載入後保留設定同清除功能，再記錄桌面同模擬手機版面嘅英文、廣東話、雙語，以及淺色同深色設定。只截取頁面嘅 PNG 會清楚標示。呢個集中測試冇驗證實體鍵盤、實體觸控裝置或者高過 100% 嘅系統縮放。

呼叫端要提供已安裝嘅低成本命令列工具、同一個安裝途徑嘅可選直接 Python 入口、無主控台 Python、Edge 執行檔、標準目標驗證器同一個新私人執行資料夾。伺服器只綁定回環位址，拒絕越過目錄同透過符號連結走出目錄，每項資源上限 16 MiB。輸出包含帶雜湊嘅清單、綁定候選版本嘅建置記錄、確切頁面記錄同擁有權清單。唔會重用瀏覽器設定檔或者目標。

截圖唔會使用真實個人用字。中性測試檔只存在私人執行資料夾，保留任何截圖前會先清除。頁面唔會儲存原檔名。原始執行中繼資料會保密，直至審閱後匯出已移除敏感資料嘅證據摘要。

## 已觀察到嘅限制

候選版本 `79c98fdab8b4cded442a823e0ff8b864dd92a590` 嘅隱藏啟動途徑有回傳程序 ID，但 Edge 同伺服器喺觀察到程序身分或者監聽埠之前已經退出。有限次數嘅嘗試涵蓋主控台 Node、無主控台 Python、先啟動 GUI，以及已安裝途徑嘅直接 Python 入口。冇產生瀏覽器目標或者截圖。一般命令列提供靜態內容成功，只可以用作診斷。每次嘗試均記錄所屬程序同埠已不存在、確認設定檔不存在或者移除自己建立嘅設定檔，再關閉指定桌面。來源測試通過；瀏覽器互動、響應式版面、無障礙、播放同截圖仍未驗證。相關啟動途徑修好先值得重試。

確切頁面驗證失敗就會停，唔會喺混有其他目標嘅清單入面揀其中一頁。收尾先正常要求瀏覽器關閉。要按 PID 處理之前，會再核對已記錄嘅建立時間同執行檔，確認所屬程序同埠已不存在，並只移除解析後確定喺指定目錄內嘅設定檔。收尾失敗會保留清單，唔會聲稱完成。
