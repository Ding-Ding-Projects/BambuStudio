# 帶選項卡嘅導航

網站會將佢嘅內容分成八個選項卡，係由標頭下面嘅一條持久條帶到達，以瀏覽器 chrome 為模型，而唔係以文件大綱。實現：
[`ui-md3/site/tabs.js`](../../../ui-md3/site/tabs.js)。

## 選項卡

| Id | 標籤 | 預設組 | 面板 |
|:---|:---|:---|:---|
| `overview` | 概覽 | 產品 | 英雄、四份計算事實、網站係咩 |
| `screens` | 螢幕 | 產品 | 十份重新設計螢幕、圖像領先卡片 |
| `materialyou` | Material You | 產品 | 即時主題、密度同埋重音種子控制 |
| `download` | 下載 | 產品 | 最新發行版本、佢嘅真實資產、驗證命令 |
| `changelog` | 變更紀錄 | 項目 | 每份發行版本 |
| `regex` | 正則實驗室 | 工具 | 全寬度嘅完整正則構建器 |
| `settings` | 設定 | 工具 | 每份偏好，帶着佢自己嘅搜尋 |
| `build` | 佢係點樣構建嘅 | 項目 | 四個步驟，包括佈局門禁 |

一個選項卡係可尋址嘅：`?tab=<id>` 係喺加載時選中佢，活躍選項卡會被鏡像進 URL 雜湊，所以一份指向 `#changelog` 嘅連結會打開變更紀錄。

## 行為

- **溢出。**唔適合嘅選項卡會進入溢出選單；佢哋永遠唔會被剪裁。選單亦攜帶每個選項卡操作同埋選項卡搜尋。
- **重新排序。**將一個選項卡拖到另一個上面來移動佢，或喺一個選項卡有焦點時按 <kbd>Shift</kbd> + <kbd>←</kbd>/<kbd>→</kbd>。順序會持久化。
- **固定。**一個固定選項卡會丟棄佢嘅標籤、保持佢嘅圖示、同埋喺未固定選項卡前排序。<kbd>Alt</kbd> + <kbd>P</kbd> 係切換佢；選項卡嘅右鍵選單亦係咁。
- **組。**每個選項卡屬於三個組中嘅一個，展示為選項卡條中嘅一條縫同埋選項卡搜尋中嘅一個標籤。一個選項卡嘅組可以由佢嘅選單重新指派，指派會持久化。
- **搜尋。**放大鏡會打開一份可搜尋選項卡列表，連接到共用正則構建器：預設為純文字、正則作為明確選擇，匹配英文同埋粵語標籤同埋選項卡 id。喺冇其他嘢適合嘅寬度上，搜尋會進入溢出選單。
- **持久化。**順序、固定、分組同埋活躍選項卡係儲存喺 `bambuStudio.site.v1` 下面，只係喺呢個瀏覽器入面。

## 無障礙性

選項卡條係一份真實嘅 `tablist`，包含 `tab` 按鈕控制 `tabpanel` 部分。活躍選項卡係唯一一個喺選項卡順序中嘅（`tabindex="0"`，其他 `-1`）；<kbd>←</kbd>/<kbd>→</kbd> 移動同埋啟動、<kbd>Home</kbd>/<kbd>End</kbd> 跳到兩端、<kbd>Escape</kbd> 關閉任何打開選單，同埋右鍵選單鍵打開選項卡自己嘅選單。焦點喺每個控制上都係可見嘅，組重新指派係公開為帶着 `aria-checked` 嘅 `menuitemradio` 項。

## 佈局演算法

佈局係被測量，永遠唔係估計。`fits()` 問每個可見選項卡**同埋**尾部搜尋同埋溢出按鈕係仍然喺第一行共享佢；`runLayout()` 然後透過四個階段升級，直到佢哋係咁樣：

1. 每個選項卡帶着佢嘅標籤，冇溢出按鈕；
2. 溢出按鈕展示；
3. 標籤丟棄（只得圖示選項卡）；
4. 選項卡從尾部推入溢出選單，永遠唔係活躍嘅；
5. 最後選項卡搜尋按鈕被撤回進選單。

兩個詳情係負載型嘅，兩個都係先至被蟲化：

- **選項卡條喺 CSS 中環繞。**`.tabstrip` 同埋 `.tabstrip-tabs` 上嘅 `flex-wrap: wrap` 意思係即使包括腳本被破壞，選項卡都會移到第二行，而唔係重疊或被剪裁。
- **去抖係一個計時器，唔係 `requestAnimationFrame`。**一個永遠唔會被繪製嘅頁面、 一個背景選項卡、無頭截圖、部署門禁、 永遠唔會執行 rAF 回呼，所以一條去抖咁樣嘅選項卡條會保持凍結喺佢喺圖示字體仍然載入時所處嘅任何狀態。圖示連字名稱係遠闊於佢哋嘅字形，所以該狀態係「一切溢出」。

圖示同埋體字面亦被額外經由 `document.fonts.load(...)` 被要求同埋選項卡會喺佢哋到達時重新測量；`fonts.ready` 單獨可以喺一個面呢頁仲未繪製過嘅面開始載入之前安定。
