# 設定同外觀

實作：[`ui-md3/site/settings.js`](../../../ui-md3/site/settings.js)，由 [`ui-md3/site/core.js`](../../../ui-md3/site/core.js) 裏嘅 `applyAppearance()` 應用。

每一個控制直接寫到偏好儲存並立即生效；冇野等待「套用」按鈕。偏好儲存喺訪客自己嘅瀏覽器裏，喺 `bambuStudio.site.v1` 下 ， 冇帳戶、冇同步、冇伺服器。當瀏覽器阻擋本地儲存時網站仍然對工作階段工作同講住咁一次，喺一個通知裏，反而唔係假裝設定被儲存。

## 組群

| 組群 | 設定 |
|:---|:---|
| 語言同語調 | 語言模式（一個包裝無線電組），英文搞笑級別、粵語搞笑級別，每一個帶著真實字串嘅實時預覽 |
| 外觀 | 主題、密度、重點種子樣本、自訂種子色彩 |
| 排版 | UI 字型，從束縛同安裝臉孔、文字大小 85、140%、主體粗細 |
| 元素外觀 | 每元素圓角、間距、文字大小同文字色彩，帶著每元素重設 |
| 通知 | 顯示通知 |
| 儲存資料 | 重設所有設定 |

## 每元素外觀編輯器

四個介面可以獨立重新造型 ， 分頁條、內容卡、英雄標題同通知。每個元素嘅值儲存喺佢自己嘅鍵下，同寫出作為 `--el-<element>-<property>` 自訂屬性；每個使用網站喺樣式表提供佢自己嘅預設，所以一個未設定屬性簡單回到。「重設呢個元素」移除該元素嘅儲存值同相應自訂屬性，而唔係接觸其他。

大小控制儲存一個**無單位比率**，同只顯示一個百分比。佢被消費作為裸乘數喺 `calc(44px * var(--site-font-scale) * var(--el-hero-size, 1))` 內，同 `calc(44px * 100%)` 喺計算值時間係無效 ， 整個聲明被拋棄，佢摺疊英雄標題到繼承主體大小同保留佢。長度 × 百分比唔係長度。

## 排版

字型列表包含束縛 Roboto 同 Roboto Mono 加上通過 `document.fonts.check` 確認存在嘅臉孔。不論選擇咩，一個 CJK 有能力堆疊自動附加（`Noto Sans HK`、`PingFang HK`、`Microsoft JhengHei`、`Microsoft YaHei`），因為一個拉丁臉孔單獨會將粵語副本呈現為備用湯。大小控制縮放每一個文字風格通過一個 `--site-font-scale` 乘數，而唔係重新造型每一個規則。

## 搜尋 ， 喺每一個調整介面，唔係只有呢一個

四個介面讓你調整或尋找野，同**每一個擁有一個搜尋列**，由相同元件建造，而唔係延遲到一個共用列：

| 介面 | 佢嘅搜尋涵蓋 |
|:---|:---|
| 設定 | 每一個組群，加上住喺其他分頁嘅控制 |
| Material You | 佢嘅三個控制列，由標籤**同當前值** ， `dark` 尋找主題、`#22c55e` 尋找重點 |
| 更新日誌 | 每一個發佈版本，組合帶著日期篩選 |
| 分頁條 | 每一個分頁，由英文標籤、粵語標籤同 ID |

純文字係預設喺全部四個；正則表達式係明確選擇加入；完整構建器係一個按鈕走，離開每一個。

## 詳細設定搜尋

設定搜尋係共用正則表達式有能力元件。佢篩選每一個組群由標籤、描述同當前值喺兩種語言，同佢亦都索引住喺**其他分頁**嘅控制 ， 主題、密度同重點喺 Material You；更新日誌嘅搜尋同日期欄位；正則表達式實驗室嘅旗標同樣本。當一個比對係其他地方時結果講佢係喺邊一個分頁同提供去嗰度，反而唔係傳回冇野。

## 唯一阻擋對話

「重設所有設定」開啟一個模態 `alertdialog` ， 唯一阻擋對話喺網站上。該係規則，唔係例外佢：一個模態被保留為一個決策，使用者一定做，喺任何野發生前，同所有純粹通知嘅係非阻擋通知。對話陷害焦點、恢復佢到開啟佢嘅按鈕、喺 <kbd>Escape</kbd> 關閉，同命名喺佢嘅主體確切咩會被刪除：語言模式、兩個搞笑級別、主題、密度、重點、字型、每元素造型、分頁順序、釘同分組 ， 帶著冇取消，同冇野在呢個網站外被接觸。該列表喺每一個搞笑級別存活。
