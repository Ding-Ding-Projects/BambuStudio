# 訪客設定排程

[English](scheduled-settings.md)

「設定」分頁提供本機規則，有名稱、開關、優先次序、可選日期、指定星期或每日，以及
全日或開始同結束時間。新規則預設停用。全部使用所選 IANA 時區，開始包括在內，結束
唔包括。跨午夜按開始嗰日計算。夏令時間重複嘅時間配對兩次，跳過嘅時間唔會發生。

目標包括語言、各自嘅幽默級別、主題、密度、強調色、字體、比例同粗幼、已登記元素樣式
快照、訊息裝飾、五項專注選項，以及旁白開關、暫停、語言、速度同音調。呢個初步清單
唔代表未來設定或原生控制已支援。符合規則按優先次序由低至高，再按儲存次序套用；每項
以最後值為準。原本選項保留，時間結束就恢復，過期 CSS 屬性亦會移除。頁面啟動、改動
同開啟期間每 30 秒重新計算，瀏覽器關閉時唔會執行。

每個清單同選單都有相鄰正則搜尋。刪除要完成該次操作嘅雙重確認同滑桿。第 1 版 JSON
匯入拒絕重複或未知欄位、無效日期時間時區或類型、未登記目標、多過 128 條規則或大過
262144 bytes 嘅檔案。無效匯入保留上次有效值；儲存失敗會先還原，唔套用新值。檔名同
路徑唔保存。匯出有規則名稱同所選值，分享前請檢查。

API 同 Home Assistant 清楚顯示未能使用，仍需已整合嘅原生配對通道同憑證保管庫。
瀏覽器唔自行建立網絡橋樑或保存 API 秘密，本機儲存亦唔冒充共用學校模式或原生憑證。

`node --test ui-md3/tests/site-schedule.test.mjs` 有 13 個案例，涵蓋跨午夜、優先次序、
夏令時間、嚴格匯入、原本值恢復、過期 CSS 移除同儲存失敗回復。呢啲係原始碼檢查，
實際隔離瀏覽器操作同畫面證據仍等待經審核嘅執行通道。
