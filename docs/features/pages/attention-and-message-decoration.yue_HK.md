# 專注介面調整同訊息裝飾

集中現時項目、減少刺激、顯示經過時間、一次一件事同靜置提醒都係獨立開關，全部預設關閉並於此瀏覽器儲存。佢哋係介面調整，唔係診斷、醫療承諾、評分或自動任務推斷。

集中模式突出按下或聚焦嘅項目，其他仍可讀、可見同可用，一個清除焦點動作就還原。減少刺激移除裝飾動畫、令介面色彩靜啲、暫停一般彈出通知同旁白；歷史仍保留，警告同錯誤照顯示，平台減少動畫仍有效。符合條件嘅啟動照片驚喜亦於安靜模式暫停，冇獨立取消驚喜開關。

經過時間顯示瀏覽分鐘同上次更改後分鐘，每 30 秒更新，唔會每次都叫屏幕閱讀器讀。下一步由使用者揀，轉分頁同重新載入後仍保留，編輯掣跳到確切設定。最多 512 個字元，無效值唔會覆蓋。

靜置提醒於 20 分鐘冇更改後提供可關閉嘅事實提醒。暫時唔需要會停足 30 分鐘；設定亦有同一控制，減少刺激亦暫停提醒。

訊息表情符號預設開啟，裝飾用 `aria-hidden=true`。事實文字、按鈕、標籤同無障礙名稱保持原樣；關閉即時移除並儲存。

7 個調整及裝飾來源測試、24 個既有網頁測試同 11 個偏好及通知測試通過，共 42 個。五模式清單逐個移除都要變紅，還原後變綠。指令面板、歷史、共享 School 模式同實際瀏覽器證據仍未完成。
