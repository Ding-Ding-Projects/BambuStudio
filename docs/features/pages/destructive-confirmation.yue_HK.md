# 雙鑰匙破壞性確認

重設此瀏覽器嘅設定會開啟只屬於該操作嘅確認面板，列明受影響資料。鑰匙 1 確認理解資料，鑰匙 2 獨立要求確切操作。兩個未完成前滑桿停用；滑桿由 0 開始，去到確切 100 先授權。部分移動、單一鑰匙、錯誤輸入、取消同重複事件都唔可以執行。

有空間時面板靠近原控制上方或下方，跟住捲動同大小變化。空間唔夠就用有界限嘅模態途徑，內容喺面板內捲動，鍵盤焦點可以循環。緊急離開同 Escape 於授權前取消，並將焦點交返原控制。面板有自己嘅搜尋同旁邊嘅正規表示式建構器。

進度講實際授權狀態，並尊重減少動畫。授權完成只表示列明操作開始，唔表示結果成功。操作失敗會講明未成功，重試需要重新檢查同新確認。每個提示各自持有鑰匙狀態，只可以執行一次。

7 個來源測試涵蓋未操作、單一鑰匙、兩個鑰匙、部分及完整滑桿、撤回、錯誤輸入、取消、單次執行同提示隔離。負面測試逐個移除獨立鑰匙檢查，觀察到未授權執行；還原後阻止執行。真瀏覽器幾何、鍵盤同畫面證據仍待背景途徑修復。
