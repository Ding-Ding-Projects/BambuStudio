# Regex 構建器

一個實現喺 [`ui-md3/site/regex.js`](../../../ui-md3/site/regex.js) 用作三個角色；完整寬度嘅 **Regex lab** 標籤、喺 **每個** 網站上嘅搜尋欄下面嘅披露面板，同埋嗰啲搜尋欄實際過濾嘅匹配器。

## 引擎同埋方言

引擎係訪客自己嘅瀏覽器 `RegExp`；ECMAScript，唔係 PCRE，唔係 RE2。網站喺構建器本身上說咁。值得知道嘅後果；

- 提供嘅標誌恰好係呢個引擎接受嘅；`g i m s u y`；
- `\p{Script=Han}` 只喺 `u` 標誌下意味著 Unicode 屬性；冇佢 ECMAScript 嘅附件 B 以默示編譯佢為字面字符 `p{…}` 並報告乾淨「無匹配」，呢係最差可能嘅答案因為冇嘢睇起嚟唔啱。插入類別籌碼轉 `u` 上，一個 `\p{…}` 模式冇佢話邊個標誌缺失；
- 命名組用 `(?<name> … )` 同埋喺結果中按名稱顯示。組身份嚟自引擎；一個冇參與嘅組保持佢嘅號碼同埋渲染為 `—` 而唔係被丟棄，因為丟棄佢重新編號之後每個組；
- 通過引導控制插入嘅字面文字用 `escapeLiteral` 轉義，覆蓋 `\ ^ $ . | ? * + ( ) [ ] { } /`，所以類型化 `.` 意味著完整停止。

## 引導構造

每個部分喺插入號插入，或包裹當前選擇當包裹有意義時；

| 部分 | 提供 |
|:---|:---|
| 字面文字 | 一個輸入，其值喺插入時轉義 |
| 字符類 | `\d \D \w \s .` `[a-z] [A-Z]` `\p{Script=Han}` |
| 錨點 | `^` `$` `\b` `\B` |
| 組 | 捕捉、非捕捉、命名、正前視、負前視 |
| 替代 | `\|` 同埋包裹 `(?: … \| … )` |
| 量詞 | `*` `+` `?` `{n}` `{n,}` `{n,m}` 同埋惰性 `+?` |

靠埋佢哋；一個原始模式編輯器、標誌複選框、樣本文字區域、實時狀態行、帶捕捉組同埋偏移嘅匹配列表，同埋複製 / 匯出 / 使用呢個模式 / 清除。

匯出寫一個 Markdown 檔案命名引擎、模式、標誌、佢嚟自嘅頁面同埋佢被測試反對嘅樣本；足夠讓別人重現結果。

## 搜尋欄

網站上每個搜尋欄係 `createSearchField(...)`；一個輸入、一個 `.*` 切換，同埋構建器按鈕。純文字總係預設；正則表達式只喺切換被按下後適用。兩個方向保持同步；喺字段中輸入更新構建器嘅模式，同埋應用一個來自構建器嘅模式填充字段、將佢切換到正則表達式模式、**並帶來構建器嘅標誌**，所以過濾結果無法矛盾用戶剛批准嘅預覽。一個無效模式報告引擎嘅消息喺字段下同埋匹配所有嘢，所以一個半類型化模式永遠唔會清空用戶正在讀嘅列表。

過濾係基於 id 而唔係基於謂詞；呼叫者提供 `items() -> [{id, text}]`同埋接收匹配嘅 id。嗰個迂迴存在，所以一個選擇加入正則表達式可以喺工作者內評估而唔係喺繪製頁面嘅線程上。

連接到佢嘅搜尋欄；標籤列表、設定、Material You 外觀編輯器，同埋更新日誌。每個供應佢自己嘅表面作為構建器嘅樣本文字，所以構建器係測試反對真實內容。每個調整表面擁有一個；設定標籤上嘅單個共享搜尋框會係一個指向控制嘅指針，唔係一個尋找佢實際位置嘅方法。

## 限制同埋拒絕服務姿態

一個用戶編寫嘅模式可以災難性回溯，同埋一個正則表達式引擎無法喺中途中斷`exec`。兩個限制適用。

- **評估同埋搜尋過濾兩者都執行喺一個 Web Worker** 建立從一個 blob URL 同埋**終止後 400 毫秒**。一個失控模式花費一個丟棄工作者，唔係凍結頁面。結果說邊個路徑執行。一個超時離開前面結果喺螢幕上，並解釋為什麼佢哋冇移動；佢唔會默默顯示一個未過濾列表。
- **當冇工作者可以被建立時**（一個強化瀏覽器、一個 `file://` 預覽），搜尋欄嘅`.*` 切換係 **禁用** 同埋純文字保持工作。提供一個不可中斷引擎喺繪製頁面嘅線程會係一個上膛槍；一個誠實「唔可用」更好。
- **實驗室嘅後備** 喺嗰個情況係內聯匹配反對一個更小樣本，同埋佢**拒絕一個量詞嵌套喺一個量化組內**；`(x+)+` 形狀；喺編譯前，因為一個鐘無法中斷一個單個 `exec()`。按輸入限制係唯一嘅限制那工作喺嗰度。
- **一個啟動失敗嘅工作者唔係一個對模式嘅判決。** 嗰個案例後備到內聯路徑同埋說沙箱評估者無法啟動，引用瀏覽器報告嘅嘢，而唔係報告一個有效模式為無效。
- 模式長度上限 512 字符，樣本 20 000（2 000 內聯），匹配 500，同埋零寬匹配推進 `lastIndex` 所以 `a*` 無法旋轉。

冇嘢被傳輸。模式同埋樣本文字喺頁面中被評估，永遠唔會離開佢。
