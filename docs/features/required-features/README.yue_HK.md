# 必備功能覆蓋範圍

呢份已審核清單列出 117 個穩定嘅公開功能識別碼，涵蓋九類介面同交付範圍。清單唔代表所有功能已經完成或通過驗證。矩陣位於 `design/required-feature-coverage.json`；現有原生介面交付記錄同缺口記錄會保留，唔會被覆蓋。

## 先揀實際工作流程

由你使用嘅介面開始：原生工作區、自有內嵌頁面、第三方內嵌頁面、區域網絡傳送頁面、區域網絡設定工具、建置工具、文件工具，或者公開文件網站。建置、發佈同專案記錄另外由儲存庫交付範圍負責。每項功能喺每類介面都有獨立記錄；有條件適用、由外部產品負責、暫停同唔適用嘅情況，都要寫明原因。

清單冇列出某個識別碼，唔等於程式冇實作。歷史分類只保留喺 `historicalReferences`，唔會令原生或內嵌介面自動變成 `partial`。`source-verified` 只用於明確連結嘅原始碼工作單元。所有分類嘅執行狀態仍然係 `unverified`。

獨立嘅 `nativeIndividualSurfaces` 清單保留歷史記錄全部 28 個準確識別碼、原始碼位置同必要狀態，包括原生同內嵌介面，唔係 28 個純原生視窗。九個分類只用嚟整理工作，唔代表個別介面已完成。內嵌頁面擁有權、每項功能喺個別介面嘅適用範圍、巢狀對話框同逐個狀態驗收都仍待核實。1,053 筆分類記錄唔係完整嘅個別介面矩陣。

區域網絡設定、建置同文件工具有明確單一可攜執行檔例外，唔適用 Squirrel 安裝程式要求；原生應用程式仍然需要原有安裝格式。全視窗個人詞彙拖放要求明確排除公開文件網站，但其他上載、私隱同還原原文要求仍然獨立適用。第三方頁面需要逐項審核擁有權同整合能力，自有容器責任仍然保留，唔可以一概話無法實作。

## 保留現有發現

十五個舊功能分類都有明確對照。有啲會對應多個公開識別碼，例如文件交付同隨附字型。呢啲係語意對照，唔係自動等同，亦唔代表舊問題已解決。獨立審核已確認識別碼完整保留、28 個歷史介面來源相符、格式例外同未完成狀態如實記錄，但未證明個別介面適用範圍完整或實際執行通過驗收。擴充清單時唔可以刪除舊發現，或者順手提高佢哋嘅完成狀態。

已知原始碼工作單元包括偏好設定視窗尺寸驗證文件、Base64 轉換，同區域網絡直接傳送。每份證據都有自己嘅範圍，必須逐一檢查先可以填入實際執行驗收結果。完整矩陣仲需要真實操作、語言模式、適用嘅設定保存、負面測試，同真實建置介面證據。

## 檢查清單一致性

執行 `node scripts/ci/check-required-feature-coverage.mjs --self-test`。檢查程式有獨立手寫嘅 117 個功能識別碼、九個分類、28 個個別介面同 15 個舊分類清單，唔會由矩陣反推答案。九項負面變更涵蓋遺漏、缺少可攜格式責任、錯誤網站拖放聲稱、繼承歷史完成狀態同未經證明嘅第三方豁免。呢啲檢查唔會證明其餘適用原因正確、功能已完成、視覺品質合格，或者實際執行已通過驗收。

## 下一批有界工作

1. 完成個別介面適用範圍同巢狀對話框探索。
2. 完善每項有條件或唔適用嘅原因，同時保留歷史記錄。
3. 為已完成嘅優先工作連結準確證據。
4. 完成已批准嘅區域網絡設定工具缺口，驗證實際套件。
5. 列出設定同首次使用流程嘅真正操作入口，再分開安排工具功能實作。
6. 透過真實介面同讀回記錄，核實文件、發佈同外部交付要求。

清單只係規劃同證據地圖，唔係指令目錄，亦唔可以代替可用嘅操作介面。公開原始碼唔包含私人指示摘錄或私人合約連結。
