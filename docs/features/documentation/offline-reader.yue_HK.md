# 離線文件閱讀器

原生閱讀器會將 `docs/features` 下面全部 Markdown 文章包入執行檔，沿用現有 Material Design 對話框、分頁、搜尋、清單同 HTML 檢視元件。冇網絡或者冇安裝原始碼，一樣可以睇文章。

## 閱讀同導覽

喺應用程式嘅說明入口開啟「離線文件」，再喺分類結果揀文章。文章連結同標題錨點都會喺閱讀器內打開。每篇文章都有目錄，按「返回」可以返到之前嘅文章或者錨點。閱讀器開住時最多保留 12 個文章分頁同 100 項導覽記錄。關閉分頁後至少會留低一篇文章。

搜尋會比對標題同正文，包括已提供嘅廣東話譯文。共用搜尋欄支援純文字、正規表達式、區分大小寫同全字匹配，亦可以開啟引導式正規表達式編輯器。冇相符結果時會清楚提示。

## 語言

可以揀英文、廣東話或者雙語。廣東話內容只會取自對應嘅 `.yue_HK.md` 檔案。如果冇嗰份譯文，閱讀器會講明缺少翻譯並顯示英文原文。初始選擇跟應用程式嘅語言設定。文章語言覆寫同最近睇過嘅文章會儲存喺應用程式設定入面。

## 選取同匯出

文章核取方塊支援多選，按 Shift 可以揀一段範圍，按空白鍵可以切換選取狀態。「全選相符項目」同「反向選取」都只限當前搜尋結果。改搜尋會清除選取。「複製所選文章」用系統剪貼簿。匯出所選文章可以用 UTF-8 Markdown 或者純文字，輸出會列明所選範圍同編碼。要覆寫已有檔案，必須喺儲存對話框確認。匯出或者複製失敗時會喺閱讀器副標題提示，唔會關閉當前文章。

## 信任內容同連結

建置時嘅轉譯器會轉義原始 HTML，只產生原生閱讀器支援嘅 HTML 子集，包括標題、段落、連結、清單、表格同圍欄程式碼。`docs` 內受支援嘅 PNG、JPEG、GIF 圖片會按 SHA-256 識別碼嵌入。原生轉譯器只容許讀取嗰啲指定嘅記憶體內圖片，唔會載入文章網址、任意本機檔案、外部圖片、指令碼或者樣式表。

已知嘅文章相對連結會變成內部路徑。不明、外部、不支援或者套件以外嘅參照（包括文章清單以外嘅原始碼連結）會顯示離線未能使用，亦會記入產生嘅清單。閱讀器唔會自動打開瀏覽器。進階 Markdown 同原始 HTML 唔會當做通用 CommonMark 內容解讀。

## 建置同驗證

文章變更後執行 `python scripts/documentation/build_bundle.py`。建置時執行 `python scripts/documentation/build_bundle.py --check`，遇到遺漏或者過期嘅產生檔就會停止。清單包含文章路徑、標題、來源 SHA-256、圖片識別碼同產生嘅標頭檔雜湊。產生器限制文章數目、單篇位元組、全部正文位元組同嵌入圖片位元組。

執行 `python -m unittest discover -s tests/documentation -v` 可驗證安全、格式同完整度。原生建置、真實介面互動、設計一致性同截圖都需要另外驗證。

## 目前整合限制

主介面整合層負責說明入口、指令面板接線同建置呼叫。套件內共用同一個文章格式器，但未同現有網頁提示共用轉譯引擎。完整共用功能、其他可忠實保留內容嘅匯出格式、外部編輯器交接同經驗證嘅實際介面截圖仍未完成，所以未能聲稱整套文件功能已交付。
