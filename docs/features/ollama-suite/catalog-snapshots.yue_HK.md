# 官方目錄快照

喺「Models」部分揀「Refresh official catalog」，就會讀取官方 Ollama 模型庫：系列索引、每個系列嘅標籤清單，同埋呢啲頁面上每一個分頁連結。套件會將結果保存成快照，等模型商店離線都用得到，亦都等你清楚睇到目錄有幾完整、有幾新。

## 評估結果

每次更新都會得出一個結果：

- **已完整走訪**：每個系列、標籤同頁面連結都已經下載同解析。官方網站冇公佈總數，所以完整性係靠跟晒每條連結得出，並未經認證。
- **已認證完整**：同上，而且每個集合都公佈咗總數，同分頁入面搵到嘅項目對得上。目前嘅 HTML 來源冇公佈總數，所以通常會係**已完整走訪**。
- **失敗**：更新中途停咗。原因係以下其中一個：用「Stop current operation」停止咗；連唔到官方目錄（呢部電腦可能離線）；有一頁驗證唔到；或者目錄超出咗 10,000 頁或 200,000 個標籤嘅安全上限。

失敗嘅更新唔會保留佢讀到嘅任何嘢。顯示出嚟嘅目錄永遠唔會將一次未完成嘅更新同已儲存嘅目錄混埋一齊，亦都永遠唔會估一個項目出嚟。

## 記錄咗啲乜

每次已完整走訪或者已認證嘅更新，都會用以下內容取代已儲存嘅目錄（套件資料夾入面嘅 `catalog.json`）：

- 評估結果；
- **修訂版本**：用每頁嘅位址、回應身份（收到嘅原始位元組嘅 SHA-256）、公佈數目、項目同連結計出嚟嘅 SHA-256 摘要，所以修訂版本一樣就代表來源頁面逐個位元組都一樣；
- 頁數、系列數目同標籤數目；
- 更新時間，亦即係上次成功更新嘅時間。

每次更新嘗試，無論成功與否，都會另外記錄（`catalog-attempt.json`），包括時間、結果、失敗原因同讀咗幾多頁。

## 你會見到啲乜

模型清單上面嗰行會顯示目錄嘅評估結果、頁數、系列同標籤數目、修訂版本嘅頭十二個字元、核實時間同已經過咗幾耐。超過 24 個鐘之後，目錄會顯示為**已過時**，並提示你更新。套件開住嘅時候，時間會一直更新。

如果已儲存嘅目錄核實咗之後，最近一次更新失敗，嗰行會講低幾時同點解失敗，同埋只會顯示上次已核實嘅目錄同已安裝嘅模型。無論有冇儲存目錄，已安裝嘅模型都會一直列出。

## 讀返已儲存嘅目錄

套件開啟嘅時候，會好似真正更新咁再走訪一次已儲存嘅頁面，並重新計算修訂版本。如果已儲存嘅目錄缺咗一頁、有項目被改過，或者修訂版本對唔上，就唔會當成已核實嚟顯示。套件會報告已儲存嘅資料無效，並保留檔案俾你檢查。

## 驗證

`tests/ollama_suite_model/catalog_snapshot_tests.cpp` 測試已走訪同已認證嘅結果、每個失敗原因、失敗唔會保留項目、修訂版本嘅敏感度、儲存後讀返（包括拒絕被改動同缺頁嘅目錄）、嘗試記錄，同埋時間同過時嘅計算。`tests/ollama_suite_model/ollama_catalog_wiring.test.mjs` 檢查對話框會儲存每次已核實嘅走訪、另外記錄嘗試，同埋顯示已翻譯嘅狀態。
