# Studio Atlas 確認介面同一般訊息對話框

## 只涵蓋源碼嘅範圍

呢個單元實作 `3c8fe2708ba03470c1b171e2fce12fcbdfaab0fc` 嘅確認／一般對話框外觀合約，由獨立工作目錄嘅 `71170bc334656d51af49d3ae682ae14320a110f5` 開始。產品改動只涉及 `Widgets/SuperConfirmGate.cpp`、其 `.hpp` 入面嘅呈現可用狀態成員，同較早嘅 `MsgDialog.cpp` 外觀單元。空間足夠時，兩條獨立鎖匙、完整滑桿、預設動作同取消語意保持不變。空間不足嘅呈現會明確封鎖所有最終授權路徑。

未有啟動程式、執行完整原生建置、擷取畫面、執行安裝程式或者操作硬件。源碼檢查唔能夠證明原生編譯、文字容納、對比度、鍵盤行為或者執行時無障礙支援。

## 介面組合

- 強化確認介面使用中性外框、保持可見嘅後果標題、內縮低層容器嘅受影響名稱詳情、清晰步驟標題、兩條各自標示嘅鎖匙、原有進度／滑桿，以及獨立而穩定嘅緊急取消頁尾。
- 控制項容納得落時，只有受影響名稱詳情放入元件組嘅捲動區。後果、總數、兩條鎖匙、充能顯示、滑桿同緊急離開全部留喺外面。詳情按內縮後闊度量度，預留捲軸位置。外框初始尺寸受顯示器工作區限制，只有詳情視口可以縮細。原有錨點擺位仍然有效。
- 一般訊息嘅純文字同 HTML 分支都有跟密度調整嘅內縮閱讀面。量度前先扣除內距同捲軸空間，設定視口闊度時再加返。原有雙語內容仍然喺量度之前組合。
- 頁尾量度同實際網格間距使用相同嘅目前密度值，之後重新排列亦一樣。按鈕次序、文字、預設焦點同結果保持不變。
- 備註對話框使用語意化主要／輔助文字角色同原有闊度限制函式。輔助備註由 body-12 改用較易讀嘅 body-13。主要外框繼續負責動作分隔同工作區尺寸配合。

## 行為保留證據

`ui-md3/tests/confirmation-atlas-preservation.json` 記錄基準版本經換行正規化嘅源碼 SHA-256 指紋。`confirmation-atlas.test.mjs` 計算括號層次時遮住註解同字面值，抽取完整方法本體；比較嘅係實際實作，唔只係回呼登記名稱：

- 九個確認方法：阻塞同非同步入口、步驟文字、步驟刷新、鎖匙輸入、進度輸入、完成、最終派發同焦點返回。
- 五個訊息方法：樣式／預設選擇、按鈕建立／派發、按鈕文字更新、加入按鈕同讀取核取方塊狀態。
- 完整鎖匙輸入／無障礙類別、`SuperConfirmState.hpp` 同 `SlideToConfirm.cpp`。
- 記憶體內負面變異會移除最後授權條件、容許進度直接到完成，以及令兩個輸入都操作第零條鎖匙。各項都必須被相應行為指紋拒絕。
- 源碼排版檢查要求受影響詳情留喺捲動區，而授權／取消控制項留喺外面。訊息內距同頁尾幾何檢查會核對量度常數一致。

執行：

```sh

```

尺寸修復後結果：**26 項檢查通過**，其中兩項來自原有雙語測試。呢組指紋刻意作為外觀單元嘅嚴格保留證據；日後如有合理行為改動，必須先經獨立語意審查先更新。佢哋唔可以代替狀態機執行測試或者原生編譯。尺寸修復新增一條空間不足解說，加入英文、粵語同範本目錄，並更新粵語覆蓋記錄。`git diff --check` 通過。

## 尚待執行時驗證

要驗證未操作、一條鎖匙、兩條鎖匙、部分滑動、已授權同已取消狀態，包括鍵盤完成、失去啟用狀態、關閉、Escape、回呼只執行一次同焦點返回。亦要驗證長名稱、八個名稱後嘅省略加總數、空名單、長後果文字、雙語披露同全部步驟文字。喺最低／正常顯示範圍及 100/125/150/200% 縮放下，確認詳情可以捲動，同時兩條鎖匙、完整滑桿同緊急離開仍可到達。低於固定控制項量度最低尺寸嘅工作區會採用只可取消嘅呈現；其原生可讀性、指標目標同輔助技術讀取仍需執行時檢查。

一般對話框要檢查純文字、雙語、已標記 HTML、表格、等寬內容、連結同備註，以及全部預設動作組合、長翻譯按鈕、「唔再顯示」文字、窄闊度動作堆疊同跨顯示器重新排列。現有訊息家族亦包括文字／數值／多選輸入、後處理腳本審閱、刪除確認、較新專案版本提示、網絡說明同耗材警告子類別。共用閱讀路徑改咗，唔代表呢啲巢狀排版已全部更新或者有證據。裝置／網絡派發同破壞性動作條件仍由原本呼叫者負責。

## 空間不足修復

對 `33958f9673677886c4a15f2834a1619aaa1cf738` 嘅獨立審查發現，披露文字太長時，單純限制整個外框尺寸可能會遮住必須顯示嘅固定控制項。修正後先移除詳情最低尺寸，按實際最終闊度換行，預留最高翻譯步驟文字嘅高度，再量度真正固定最低尺寸。最終排版後亦檢查控制項矩形同文字量度。顯示範圍未知、高／闊超標，或者任何必須控制項越界，都會喺顯示前選擇不可授權呈現。

不可授權呈現將明確可用旗標設成 false，並將現有模型鎖定為已取消。隱藏鎖匙或者滑桿事件因此唔能夠授權。兩條阻塞返回路徑同最終回呼派發亦各自要求呈現可用。只有移除呢個已審查嘅可用條件之後，正常最終方法先會同舊指紋一致；其餘受保護輸入同轉移方法，經換行正規化後仍然逐位元組相同。

替代呈現會喺捲動區顯示完整供應嘅動作、後果、總數披露同每一個受影響名稱，另有翻譯解說。緊急離開係獨立具名控制項，Escape／關閉繼續取消。極細範圍會限制出口分配高度，以預留披露空間；實際目標尺寸同無障礙行為仍未驗證。唔會為咗容許授權而縮短任何披露。

測試執行源碼尺寸條件，涵蓋正常、溢出、極細同零範圍。亦會喺呈現不可用但模型刻意設為可執行嘅情況，執行全部三條最終表達式；所有結果都係 false。移除任何可用條件，都會令相應負面檢查拒絕變異；原有派發表達式喺相同合成狀態會返回 true。源碼順序檢查要求零詳情分配之後先按最終闊度換行，最終排版矩形檢查亦不可移除。

目錄驗證：未修改嘅嚴格粵語驗證器，會喺既有 `Interface motion` 項目停低，因為呢個工作目錄嘅英文來源目錄冇該項目。父版本已有相同不一致。`compile_translation.py --check --allow-unreferenced` 通過 **8,022 條翻譯**同精確覆蓋數量，並冇寫出編譯目錄。新解說本身喺三個獲授權目錄都有。呢個例外唔代表整份目錄嚴格驗證通過；較舊而無關嘅目錄缺口要另外處理。
