# Studio Atlas 外框同分頁呼叫端

呢個單元實作設計修訂 `3c8fe2708ba03470c1b171e2fce12fcbdfaab0fc` 記錄嘅外框／分頁合約，修改原生標題繪畫、專案分頁佈局、巢狀分頁簿呼叫端同分頁管理對話框。範圍包括外觀同視覺空間分配行為，唔止換顏色。

## 實際覆蓋

| 負責檔案 | 改動 |
| --- | --- |
| `BBLTopbar.cpp` | 有外框嘅專案識別標籤、20 DIP 資料夾圖示、32 DIP 歷史同識別表面、按情境顯示嘅關閉回饋，以及先預留固定指令空間嘅標題文字預算 |
| `MainFrame.cpp` | 專案分頁列同周圍外框之間嘅間距、DPI 變更後重新套用間距，以及專案分頁列主題更新 |
| `Widgets/TabStrip.cpp` | 色調式選取表面配對文字、可見標記同半粗體名稱；透過共用減少動態效果路徑提供 250 ms 選取漸變；完整水平標題量度；有界限嘅釘選項目分配；溢出選單勾選目前目的地 |
| `Tabbook.cpp` | 密度間距同圓角巢狀導航表面、按選取字型量度最小尺寸、按情境配對選取前景／背景、保留呼叫端明確指定嘅內距，以及 DPI 更新 |
| `Widgets/TabStripDialogs.cpp` | 原有可捲動清單外加不透明結果卡片、密度間距、空白／摘要文字換行、使用語意色嘅無效模式摘要，以及卡片 DPI 更新 |

標題列保留 46 DIP 高度、工具識別碼、拖曳區、最大化／還原行為同關閉處理函式。專案名稱同專案分頁列原有嘅未儲存狀態標記繼續分開。標題標籤只用固定指令以外嘅剩餘空間，文字預算最多 240 DIP。容納唔到文字時，可選標籤會收起，唔會搶佔指令空間。完整標題保留喺項目說明文字同專案分頁模型。歷史資訊沿用原有真實來源紀錄路徑同內容。

本單元冇因為 `MainFrame.cpp` 包含未使用嘅 `ProgressStatusBar` 就假設有狀態列。原有歷史／來源紀錄標籤會更新繪畫，但唔會新增另一個狀態表面，亦唔會聲稱已覆蓋應用程式其他狀態元件。

## 溢出同身分

水平分頁以選取字型量度完整本地化名稱。群組標籤、釘選標記、未儲存標記同可見關閉控件，各自計入實際獨立縮放後嘅寬度。群組標題亦保留完整量度嘅水平名稱。舊有 240 DIP 分頁寬度上限，唔再喺考慮溢出之前默默縮短標籤。

本地視覺分配器喺可用預算內優先安排釘選目的地，並保留模型顯示順序。太闊而放唔落嘅釘選目的地會進入原有溢出選單，繼續維持釘選、關閉保護同穩定識別碼。選單勾選目前目的地；目前分頁溢出時，選單控件會顯示色調狀態。呢項改動只改視覺分配，唔改釘選、分組、模型順序、隱藏狀態持久化或啟動語意。

分頁列最小尺寸包含搜尋、可選新增同溢出目標。預算低過支援最小值時，可以完全唔顯示分頁；計算唔會使用負數預算。實際字型量度需要更多空間時，水平列高度會增加。已設定嘅垂直導航列寬度繼續有效。名稱超出該寬度時，垂直列沿用原有明確顯示嘅縮短方式同完整工具提示；完整換行嘅垂直標籤仍屬另外工作。

## 對話框組合同無障礙界線

群組選擇、分頁搜尋同批次關閉預覽保留原有 `ListBox` 實例同事件綁定。每個清單移入支援鍵盤導航嘅圓角卡片。要求高度同時受目前螢幕工作區三分之一高度，以及清單原先要求高度限制。清單保留原生捲動同選取。空白同摘要標籤沿用現有換行實作，包括中日韓文字處理。

群組名稱輸入、正則運算式建構器、包含釘選項目、預覽驗證、操作啟用、Enter／方向鍵導航同 Escape 取消，全部沿用原有處理函式。冇新增翻譯文案、持久化鍵、功能引擎、列印操作或資料操作。搜尋結果列文字仍沿用共用清單控件嘅省略號／工具提示呈現。整個對話框喺細螢幕嘅適配、長核取方塊標籤同所有實際焦點轉移，仍需原生驗證。

共用動態控制器負責減少動態效果行為。語意啟動即時生效；動畫只改繪畫。視窗控制、分頁選取、關閉確認或指標目標，都唔會等待動畫。

### 溢出拖曳修正

第一版有界限溢出分配器揭示 `OnTabDragEnd` 對舊矩形嘅假設：佢計算所有模型顯示嘅分頁，包括因寬度而隱藏嘅控件，再透過未篩選清單映射所得位置。釘選寬度 A=100、B=400、C=100、D=100 時，由闊縮窄會令 B 舊中心停喺 304，但可見 C 同 D 中心移到 154 同 258。喺 180，即 C 後面，放低 D，卻錯誤將 D 移到 C 前面。

修正後處理函式只收集已顯示分頁控件。揀下一個可見鄰居時排除正拖曳嘅身分，將鄰居穩定 ID 解析成目前模型位置，再按來源移除調整插入界線。喺最後可見鄰居後面放低時，會以該鄰居為錨點，唔會落到無關隱藏模型尾端後面。`MoveTab` 同 `Model::move` 保持不變，包括釘選區域限制。

獨立回歸使用正式溢出分配器、正式拖曳目標輔助函式，以及逐字擷取嘅 `Model::add`、`index_of`、`pinned_count` 同 `move` 函式內容。最小儲存轉接器以 std::string 取代 wxString 標題儲存；佢唔會執行 wxWidgets 或模擬原生輸入。八個案例通過，對實際最終分頁順序作出 28 項斷言，涵蓋報告中由闊縮窄嘅順序、鄰居之前／之後、原位放低、冇可見鄰居、隱藏尾端同釘選區域保護。喺暫存擷取輔助函式移除最後鄰居界線偏移，會產生兩項失敗斷言同退出碼 1。還原正式輔助函式後，全部 28 項斷言重新通過。十項原始碼檢查亦會拒絕移除已顯示控件篩選。

### 可見焦點同無障礙溢出修正

因寬度而隱藏嘅分頁，之前仍留喺循環鍵盤導航序列。分頁列持有原生焦點，但唯一焦點環由隱藏分頁繪畫器負責；無障礙查詢亦返回隱藏控件嘅舊矩形。修正後焦點投影只包含已分配空間而顯示嘅分頁控件，之後接真正嘅溢出按鈕。重新佈局會將剛被隱藏分頁嘅焦點調整到該按鈕。方向鍵喺序列循環，Home 同 End 選擇兩端；溢出按鈕有焦點時，Enter 或 Space 開啟原有溢出選單。全部分頁都溢出時，仍保留呢個可到達目標。

溢出按鈕會取得原生焦點，所以共用按鈕繪畫真正焦點環。鍵盤啟動只處理一次，唔會喺放開按鍵時再啟動。收起選單後，焦點返回調整後目標，包括取消，以及所選目的地仍然放唔落嘅情況。放大後溢出消失，焦點會落返可見嘅目前目的地，或第一個可見分頁。只有分頁列或溢出原本持有焦點，重新佈局先會還原原生焦點，保留無關控件焦點。啟動、穩定 ID、釘選、群組、重排限制同選單目的地內容全部不變。

無障礙保留模型顯示分頁嘅身分，但將未獲分配空間嘅分頁報告為不可見及畫面外，唔會附帶可取得焦點／已有焦點狀態或舊螢幕矩形。可見溢出子項使用按鈕角色，狀態同預設操作交由真正按鈕嘅無障礙物件處理。該物件持有原生焦點時，焦點查詢會返回佢。呢啲係原始碼層面嘅實作事實；螢幕閱讀器輸出、原生事件傳遞同焦點像素仍需執行期間驗證。

獨立回歸編譯直接擷取嘅正式分配同焦點投影輔助函式。七個案例通過，共 29 項斷言，涵蓋由闊縮窄嘅焦點調整、End 後 Enter、方向鍵循環、選單選取／取消後返回目標、放大令溢出消失、全部溢出分配，以及空／過期目標。刻意喺暫存擷取輔助函式保留隱藏焦點索引，會產生六項失敗斷言同退出碼 1；還原正式輔助函式後，全部 29 項斷言通過。原始碼檢查亦會拒絕以純繪畫回饋取代原生溢出焦點，並檢查隱藏分頁嘅無障礙投影。測試唔會執行 wxWidgets、派發原生輸入或證明實際焦點畫面。

## 還原同待完成工作

可以獨立還原呢個單元，恢復之前外框繪畫同視覺分配。咁做亦會恢復舊有強制顯示釘選溢出行為同水平標題上限，所以係外觀／佈局混合還原，唔係純繪畫還原。唔需要一併還原工作流程頁面整合、欄位幾何或中性色角色配色。

待完成工作包括完整換行嘅垂直分頁標籤、極端顯示／字型設定下嘅原生對話框適配、實際標題工具列鍵盤焦點證據、無關狀態元件，以及清單內所有其他應用程式表面。採用共用元件唔等於證明完整覆蓋。呢個原始碼單元唔代表全應用程式重設計已完成。
