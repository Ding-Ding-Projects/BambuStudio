# Studio Atlas 噴嘴架與熱端詳情

Monitor 噴嘴架、映射選擇卡同「Hotends Info」資料列採用緊湊圓角卡、中性色表面，以及先顯示識別資料嘅層次。已選卡使用 Device 次要容器底色同主要邊框；停用卡改用柔和底色，但保留原有選取標記。錯誤文字同韌體更新提示保留原有語意色。耗材色塊仍然顯示實際材料顏色。

## 可達介面與保留行為

- `StatusPanel.cpp` 擁有 Monitor 噴嘴架。映射內嘅 `wgtDeviceNozzleRackSelect` 亦使用 `wgtDeviceNozzleRackNozzleItem`。
- 選擇面板保留噴嘴架次序 `16, 18, 20, 17, 19, 21`、左右擠出機身份、動態噴嘴限制、相容性判斷，以及原有滑鼠放開事件內容。
- 噴嘴架嘅「Hotends Info」操作會開啟 `wgtDeviceNozzleRackUpgradeDlg`。資料列保留空置、未知、正常、異常、讀取、重新整理、韌體版本、序號同使用時間路徑。讀取、移動、歸位、升級導向同功能支援檢查全部不變。

## 量度與生命週期

選擇卡保留 88 × 100 DIP 最小尺寸，但移除最大尺寸上限。建立、標籤變更同 DPI 變更後，都會將實際 sizer 內容納入闊度同高度計算。量度前先更新字型，再清除舊最小尺寸，讓較長譯文可以向上層要求足夠空間。

熱端材料同韌體欄保留 220 同 183 DIP 偏好最小闊度，移除 40 DIP 高度上限。資料同 DPI 更新會重新整理字型及排列。錯誤同重新整理圖示容器將邏輯尺寸 20 直接傳入共用按鈕 API，避免高縮放時轉換兩次。原有圖示尺寸、事件處理同焦點行為不變。

## 驗證與剩餘限制

`node --test ui-md3/tests/nozzle-rack-atlas.test.mjs` 通過四項原始碼及非視窗檢查。舊版本 `50715f4355e8b845042bd4809bac2da2ce5c40f4` 得到三項失敗、一項保留行為通過。量度檢查以提供嘅內容尺寸，執行正式程式運算式，覆蓋 100%、125%、150% 同 200%；並無量度原生文字。十九個硬件、映射同韌體方法與基準比較，只容許新增資料列量度呼叫。

完整原生建置發現兩個編譯整合錯誤：卡片方法聲明放咗喺噴嘴架而唔係噴嘴項目類別，以及狀態圖示呼叫咗 Button 冇提供嘅縮放方法。聲明現已屬於 `wgtDeviceNozzleRackNozzleItem`，圖示改用 `Button::Rescale()`。獨立檢查以真正已配置 wx 標頭，編譯完整正式卡片標頭及兩個定義，亦編譯實際狀態按鈕聲明及呼叫。刻意破壞嘅反向案例必須出現指定 MSVC C2039 診斷；修正案例通過。呢啲檢查並無編譯完整翻譯單元，亦唔代表執行時排列已驗證。

尚未聲稱完整原生建置成功，亦無硬件操作、實際畫面擷取，或真正語言、主題及密度矩陣。外層噴嘴架闊度、映射彈窗定位、「Hotends Info」可視範圍、長序號及資料列溢出，仍需檢查已建置介面。原有鍵盤選擇限制、內層噴嘴對話框同乾燥控制不屬今次修改。本篇並無宣稱打印機介面已全面重設，亦無宣稱畫面已達一致。
