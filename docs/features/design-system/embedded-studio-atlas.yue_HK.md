# 內嵌 Studio Atlas 樣式

呢次純外觀改動將 Studio Atlas 瓷白／石板中性色套用到產品自己擁有嘅內嵌頁面，依據來源設計 `669af08fe25582d75a4775389eb53760fea39481` 同原生配色版本 `b748affe0f687f6cfbe6068a82d32988047f790a`，包括修正後嘅淺色邊線 `#6d7e94`。獨立網站同第三方資產不在範圍。

## 範圍同保留行為

DeviceWeb 耗材頁、首頁、設定指引、裝置連線、項目／模型、登入、耗材管理同自訂耗材樣式採用一致中性表面及說明文字。原有語意令牌、強調、選取、警告、錯誤、材料／線軸顏色保留，主題選擇器同主程式注入嘅深色樣式表不變，冇新增由作業系統覆蓋應用程式主題嘅機制。

冇 HTML、JavaScript、React、橋接、回呼、資料儲存、裝置協定或翻譯改動。寬高、內距、溢位、顯示狀態、變換、字型尺寸同輸入幾何不變；保留舊版版面合約唔代表舊版每個版面都正確。

控件新增可見焦點外框，唔移動版面盒。新過渡只影響背景及邊框顏色，長度 100 毫秒，要求減少動態效果時移除。原有活動指示同獨立動畫不在呢個繪畫單元，需要另外驗證。

## 驗證同限制

喺倉庫根目錄執行 `node --test tests/embedded_atlas_styles.test.mjs`。來源檢查將 23 個樣式表同固定基準比較，保留原選擇器、非顏色宣告及強調／狀態變數，拒絕刻意幾何修改，並計算預設文字同欄位邊線對比。本地必須有基準提交。

互動清單要求九個入口樣式表各有一個完整區塊，其餘十四個冇區塊。空白正規化後，完整後綴必須符合焦點外框同兩個減少動態媒體規則；未知宣告、選擇器、at-rule、尾隨文字同重複標記全部拒絕。負向案例逐一移除必需區塊、插入重複標記、加入 padding 或空白分隔嘅 height 宣告，亦會喺第二個標記之後加幾何宣告。

`a2be7df26cd5981da2c1e50d4c64c5e3a86609b9` 嘅舊互動檢查錯誤接受缺失區塊。將裝置樣式表區塊移除，再執行舊檢查，會出現預期紅色回歸 `Missing expected exception (AssertionError)`。加強後九項全通過，包括拒絕上述變異；呢次修正只改測試同本文，產品 CSS 不變。

呢啲檢查冇測試內嵌引擎嘅 CSS 層疊、自訂顏色、強制顏色、鍵盤、翻譯、響應式版面、動畫時間或實際繪製。預設配色計算唔代表所有合成狀態或自訂色對都合格。

冇啟動應用程式、瀏覽器、安裝程式或打印機，冇擷圖或版面量度。任務禁止啟動，所以 Material Designer 即時流程不可用；已提交設計只係來源參考。整合負責人負責產品編譯及日後獲授權嘅執行矩陣。

## 還原

保留獨立純外觀提交，還原該提交可以恢復內嵌配色，同時保留其他行為、建置修正同原生工作流程改動。冇設定遷移或用戶資料重設。
