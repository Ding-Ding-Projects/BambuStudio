## 個人詞彙界線

標準輸入係具版本 JSON 物件，包含 `schemaVersion: 1` 同 `entries` 映射。只有明確只供顯示嘅轉接器可以套用映射。一般翻譯輔助函式亦服務紀錄、錯誤同匯出，唔可以成為私有替換嘅隱含路徑。

驗證必須測試有效匯入、拒絕格式錯誤／過大輸入、替換、持久化、清除、原文、重疊鍵同穩定內部識別碼。公開測試資料使用中性合成詞。私有輸入、私有映射文字同私有本機路徑，永遠唔進入公開原始碼、紀錄、匯出、畫面擷取或託管驗證負載。合成測試資料覆蓋，唔可以描述成已驗證私有檔案。

選單場景包括短同長清單、無結果、巢狀結果、長標籤同捷徑、正則驗證、建構器套用／取消、鍵盤選取、Escape 清除、焦點返回，同控件之間獨立狀態。動態場景包括中斷／重啟動畫、回呼期間釋放、減少動態效果，同背景工作期間介面回應。

切片場景包括明確取消、新要求之後收到舊完成、模型／設定／列印板改變、切片失敗、關閉同重試。兩個組合操作都必須拒絕過期結果。冇獲授權硬件時，實體印表機傳送同列印仍然另外未驗證；任何測試都唔可以默默開始真實列印。
