原生 AMS 控制同嵌入式 `open_humidity` 路徑都會開啟 `AMSDryCtrWin`。設定、材料存放準備、啟動進度、烘乾中、暫時不可用原因同錯誤提示，繼續由原有裝置狀態控制。

狀態數值同烘乾設定而家各有獨立語意卡片，圓角及邊距跟隨密度。說明標籤用輔助字體，數值用較清楚的標題層級。溫度同時間輸入保留單位及驗證，以完整組別換行。準備說明同返回／開始按鈕亦可換行。主頁、準備頁及進度頁各自提供捲動，改變大小、DPI 或內容後會延後更新可見捲動範圍。對話框可調整大小，原有最小大小保留。

主要操作用 Filled、返回用 Outlined、停止用 Danger，沿用共用按鈕的焦點、滑鼠、停用同減少動態效果行為。按鈕先解除舊最小大小，再量度新文字或 DPI。冇新增動畫、硬件狀態推測、產品文字或裝置指令。
