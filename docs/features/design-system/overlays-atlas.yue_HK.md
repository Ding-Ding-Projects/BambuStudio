## 巢狀清單同待辦

- 外觀：字體搜尋／清單、步進、字重／對齊、預覽、選色、形狀／間距、預設匯入／匯出／儲存、全域重設、列選單及錨定仍待真實互動／邊界證據。固定寬度內部列可獨立捲動，但最小顯示仍待審查。
- 命令面板：每個豐富設定、選單操作及停用狀態要獨立註冊／啟用／無障礙證據。保留 120 結果上限，開到主頁唔等於註冊全部子控件。
- Regex：Build／Reference、群組、編輯器、旗標、樣本／匹配、worker 診斷、程式協助及每個搜尋呼叫者都待互動；最小顯示分頁文字未驗證。
- 通知：即時／畫布通知及位置屬 `NotificationManager.cpp`。模型、批次預覽及破壞控制未重設計。
- 歷史：復原橫額、分類／狀態／儲存／日期／裝置篩選、時間線／詳情、比較、標籤、批次匯出、還原預覽、打印機／草稿變體各自要證據。原生選擇及文字欄待轉換／幾何工作。
- 文件：樹節點、連結、錨點、表格、程式碼、圖片、備援及文章內控件要獨立證據；只改產品閱讀器，冇改網站。
- 更新記錄：日曆、篩選、長版本、雙語、連結、空白、驗證及匯出揀選器待真實驗證。
- 匯出：格式表、保真／損失、編碼、壓縮條件控制、提示、輸出路徑、密碼確認、驗證及平台選檔待證據，序列化／壓縮執行不變。
- `MD3Menu`、`SuperConfirmGate.cpp`、`MsgDialog.cpp`、`TabStripDialogs.cpp`、即時通知及標準工具屬其他範圍。靜態參考唔係缺失控制嘅實作。

## 獨立審查修正

`83cf6a2677356c20664c073e8f04f818fc292e67` 有兩個缺陷：歷史兩個 `Label::SetLabel` 呼叫錯傳只屬建構子嘅旗標，修正移除多餘參數，保留建構換行及 `Wrap(content_width)`。命令選取亦重上色所有直接普通面板，包括六個真實強調色色塊；而家用列到圖示裝飾板映射，只改該板，搜尋重建喺刪列前清映射。

`ui-md3/tests/overlays-atlas-regressions.test.mjs` 檢查真實 Label 宣告／參數、建構換行、選取白名單及身份生命週期。原版一項通過、三項失敗；修正後四項通過、零失敗。可用 `OVERLAY_SOURCE_REF` 指定本地歷史版本，仍係來源回歸，唔係原生互動。

### 建構子回歸邊界修正

最初建構樣式檢查會跨到下一個標籤借用旗標，記憶體移除副標題樣式後，舊表達式仍錯誤通過。修正會從遮罩來源抽取平衡呼叫參數，只看各自第四參數，字串同註解唔可以提供分隔或樣式名。副標題及安全標籤各有獨立移除案例，未改嗰個仍通過；另有含分號／括號／逗號及註解假旗標 fixture。修訂後七項通過、零失敗，呢次只改測試，產品來源不變。
