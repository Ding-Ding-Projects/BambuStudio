# Studio Atlas 濕度詳情

呢個來源單元只涵蓋 `AmsMappingPopup.cpp` 嘅 `AmsHumidityTipPopup`／`AmsHumidityLevelList`，同 `DeviceTab/uiAmsHumidityPopup.cpp` 嘅 `uiAmsPercentHumidityDryPopup` 及宣告。映射、噴嘴選取、乾燥命令、打印機能力同選擇頁面嘅呼叫者不變。

## 可到達路徑同狀態

原生 `Widgets/AMSControl.cpp` 嘅 `EVT_AMS_SHOW_HUMIDITY_TIPS`，以及內嵌 `DeviceWeb/ViewModels/DevicePage/AmsControlWeb/ViewModelActions.cpp::open_humidity`，都保留原路由：普通 AMS 用等級彈出頁；支援遠端乾燥嘅 N3F／N3S 用另一個乾燥對話框；其餘受支援類型用百分比／溫度／時間頁。兩個呼叫者檔案不變。

有效等級條件、等級賦值、圖片選取、百分比、溫度取整、時／分格式、Drying／Idle 條件及 AMS 身份不變。冇新增讀數、單位、訊息鍵、計時器、回呼、命令或持久化。原初始佔位行為保留，唔會扮成已確認遙測。

## 組合同版面擁有權

普通彈出頁有按文字量度嘅標題，原關閉控制留喺真實 `MD3ScrolledWindow` 之外。捲動內容包含目前圖片、五級圖例同原說明，按所屬顯示工作區預留總共 32 DIP，最闊 740 DIP。文字按實際內容寬、密度內距同垂直捲動條換行；建立、重新開啟及 DPI 縮放共用方法。原關閉命中幾何及關閉行為不變。

圖例取代固定 680 × 104 DIP 圖片背景列，改用中性容器、分開量度嘅 Dry／Wet 端點行，同原五張等級圖。欄數按可用寬、真實圖片寬及密度間距計算，五至一次序同明暗選擇保留。高度跟行數及端點文字高；縮細比例或寬度會替換舊尺寸限制，唔保留舊實體像素下限。

百分比頁保留內容外嘅原標題列，將三等寬欄改成三行標籤／值，濕度、溫度、剩餘時間次序及值不變。說明可換行，值用標題層次；狀態圖示／文字用量度水平排版。視口最闊 440 DIP 並限制喺顯示工作區，內容可垂直捲動。更新內容及 DPI 會刷新字型、行距、內距、圖片邊界、高度及捲動範圍，唔發裝置操作。

搵唔到所屬顯示器時，以 800 × 600 DIP 作明確版面備援假設，唔係真實顯示證據。細過控件／圖片固有寬度嘅極細顯示，以及極大自訂字體，仍係執行驗證邊界。

## 最終位置修正

獨立審查發現呼叫者可能先按只有標題嘅尺寸 Fit 同定位，之後 `Popup` 先擴大內容。`AmsHumidityTipPopup::Popup` 而家保留要求原點，完成最後量度，再將完整矩形限制喺同一所選顯示工作區內，最後先顯示。兩個呼叫者不變。若無法識別顯示器，仍沿用原備援尺寸假設，唔宣稱位置已驗證。

新回歸檢查真實內嵌呼叫者嘅 `Fit → Position → Popup` 次序，再用標題擴大成完整內容嘅模型執行產品 popup 方法，涵蓋右／下溢出、負要求原點同位於負桌面座標嘅顯示器。舊實作失敗，修正後五項濕度檢查全通過。只係來源／生命週期模型證據，唔係原生彈出位置證據。
