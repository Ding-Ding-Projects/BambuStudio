# 校準視窗佈局

## 說明頁面

校準外框將可用捲動用戶區寬度分配畀可見頁面，唔再置中一個最小 1100-DIP 頁面。原有頁面邊距改為跟隨所選密度。說明標籤按呢個寬度量度原文，保留實測高度，並更新外層捲動範圍。前後圖片群組以完整圖片換行。

縮放、顯示同 DPI 改變會合併成延後重排。進行中重排唔會遞迴排程自己。捲軸寬度改變會排程之後再量度。原有標籤自動換行亦會回應內容改變。印表機指令、步驟順序、校準值、翻譯字串同儲存身分全部不變。

## 驗證同限制

`node --test tests/calibration_layout.test.mjs` 檢查實際轉接器。對照提交 `5568ae6ec28bb86cf481989da79d5582ca76dbfd`，三個案例全部失敗；目前原始碼全部通過。喺 MSVC 開發環境執行 `node tests/calibration_layout_fixture.test.mjs`，只會喺儲存庫外建置非視窗測試，測試正式 `CalibrationLayout.hpp`：五個案例通過，涵蓋四種縮放實測寬度、窄／隱藏邊界、高度改變、延後合併同狀態釋放。原有保留檢查只明確正規化新佈局操作；操作、值同文字繼續同原始基準比較。

呢篇講嘅四個編譯再執行 fixture（`calibration_layout_fixture`、`calibration_minimum`、`calibration_reflow` 同 `calibration_result_viewport`）由 `tests/native_fixture_compiler.mjs` 揀編譯器：Windows 用 MSVC `cl.exe`，要喺開發環境執行；其他主機用 `$CXX`（預設 `c++`），C++17 加 `-Wall -Wextra`。所以 Linux 合約檢查都會跑同一批 fixture 同佢哋嘅負面模式，唔會因為冇 `cl.exe` 就停低。

以上係原始碼同輔助函式證據，唔係原生畫面證據。呢項改動冇建置或啟動應用程式。最小用戶區可讀性、鍵盤捲動／焦點、英文／廣東話／雙語文字、兩種主題同 100%、125%、150%、200% 顯示縮放，仍需原生畫面矩陣。預設列同結果表格屬之後有界限改動。

## 校準說明頁版面

校準外框而家按捲動區可用闊度分配頁面，唔再硬性要求 1100 DIP。頁面邊距跟隨所選密度。說明文字按原文重新量度換行及高度，再更新外層捲動範圍；前後對照圖片以完整圖片為單位換行。

改變大小、顯示頁面及 DPI 變動會合併成延後重排。重排期間唔會遞迴排入自己；捲動條令可用闊度改變時，再量度一次。原有自動換行亦會處理文字更新。打印指令、步驟次序、校準數值、翻譯文字及儲存結果識別全部保留。

舊版本三項來源檢查全部失敗，現時三項全部通過；直接使用正式版面輔助程式的非視窗 C++ 測試有五項通過。呢啲只係來源及輔助程式證據，唔代表原生畫面已驗證。今次冇完整編譯或啟動程式；最低客戶區大小、鍵盤操作、三種語言模式、兩種主題及四種顯示比例仍然要由原生畫面驗證。預設材料列及結果表格另有獨立修改單元。

`tests/calibration_presets_layout.test.mjs`：之前原始碼一項通過、兩項失敗；目前三項全部通過。身分測試比較完整槽建構函式內容，只正規化兩個確切佈局替換，並拒絕被改擠出機索引。正式寬度／狀態輔助函式繼續由五案例 C++ 測試覆蓋。原生畫面仍未驗證。

舊來源有一項通過、兩項失敗，現時三項全部通過。索引檢查比較整段材料列建立程序，只正規化兩個指定版面改動，並確認改錯噴嘴索引會被發現。原生畫面仍未驗證。

## 高度量度修正

兩個延後轉接器先記住並解除之前明確標籤最小高度，再換行、失效最佳尺寸快取、量度同安裝新高度。咁樣視窗較闊或內容較短需要較少行時，之前最小值唔會限制 `GetBestSize()`。之前高度只用嚟決定父層佈局係咪需要更新。

`tests/calibration_reflow.test.mjs` 將兩個實際正式方法內容，同會按字元內容換行、套用 wx 式最佳尺寸最小值限制嘅非視窗標籤模型一齊編譯。對照 `2ea14a5ea158e3311ad7680409243d51cd35b37a`，四個案例全部失敗。修正後四個全部通過：說明同建議標籤由窄至闊再至窄，以及內容縮短。呢點證明該限制下嘅轉接器次序，唔係原生文字量度、繪畫、焦點或捲動證據。

## 文字高度量度修正

兩個延後重排程序先記低並解除舊的最小高度，再換行、清除最佳大小快取、重新量度及設定新高度。咁樣視窗變闊或者文字縮短時，舊高度就唔會箍住新量度。舊高度只用嚟判斷需唔需要更新父容器版面。

非視窗測試直接編譯兩個正式程序，文字模型會按內容換行，亦會模擬最佳大小受最小高度限制的行為。修正前四項全部失敗，修正後四項全部通過，涵蓋兩種標籤由窄變闊再變窄，以及文字縮短。呢個結果只證明量度次序，唔代表原生字體量度、畫面、焦點或捲動已驗證。

## 內在寬度修正

共用頁面最小值改為未指定（`-1`），唔再明確設零。移除繼承嘅 1100-DIP 下限，同時保留固定寬度後代計算出嚟嘅最小值。只有實際換行標籤使用明確零最小寬度。因此，比用戶區更闊而不可分割嘅後代，會計入外層虛擬範圍，仍可水平到達。

`tests/calibration_minimum.test.mjs` 編譯實際頁面同建議初始化陳述，以及共用巨集，配合模擬 wx 有效最小值同外層捲動傳遞嘅非視窗模型。測試喺 100%、125%、150%、200% 縮放，以真實側邊內距，將固定 600-DIP 狀態控件放入 540-DIP 頁面視窗。之前原始碼四個溢出案例全部失敗，只有有界限標籤案例通過（1/5）；修正後通過 5/5。呢個係尺寸合約檢查，唔係原生捲軸或焦點證據。結果表格捲動擁有權仍待獨立審閱。

## 原有內容闊度修正

共用頁面最小闊度改為未指定（`-1`），唔再明確設為零。咁樣可以移除 1100 DIP 限制，同時保留固定闊度子控制項計算出嚟的最小闊度。只有真正換行的標籤先用零最小闊度；比可用區域更闊的完整控制項會計入外層捲動範圍。

測試直接編譯正式頁面及提示卡的初始化語句與共用常數，模擬有效最小闊度傳到外層捲動區的過程。四種顯示比例下，600 DIP 狀態控制項放入 540 DIP 頁面再加邊距，舊版四項溢出檢查全部失敗，只有有界標籤一項通過；修正版五項全部通過。呢個只係尺寸契約檢查，唔係原生捲動條或焦點證據。結果表格捲動容器仍待獨立審核。

## 結果表格實作

自動壓力提前、多擠出機壓力提前同自動流量結果，現時使用本地 `CalibrationResultViewport`，繼承現有 `MD3ScrolledWindow`。每個表格保留原有排列器、標頭順序、直接子控件、值、擠出機／托盤身分、驗證同操作。整張表格水平捲動，唔將欄位分開換行。三個擁有排列器項目擴展至可用寬度。

只有視窗本身有受限最小寬度。周圍頁面保留未指定最小值，令其他固定後代繼續計入。延後尺寸、顯示、DPI 同結果內容更新，直接量度 `GetSizer()->CalcMin()`；有水平溢出時預留原有捲軸厚度，更新本地虛擬尺寸，再經外層捲動主體更新祖先。較短結果集可以降低高度，因為之前視窗最小值永遠唔作量度來源。更新要求會合併；用戶區寬度改變會再做一次延後處理。冇新增動畫、產品文案或校準行為。

## 結果表格

自動壓力提前、多噴嘴壓力提前及自動流量校準結果，改用沿用現有捲動控制項的本地水平捲動容器。原有表格排列、標題次序、直接子控制項、數值、噴嘴及材料槽識別、驗證同操作全部保留。整張表格水平捲動，唔會將互相關聯的欄位拆散換行。三個容器都擴展至可用闊度。

只有本地捲動容器限制最小闊度，外層頁面繼續保留未指定最小闊度。大小、顯示、DPI 及結果內容變動會合併成延後更新，直接量度表格排列器，需要時預留水平捲動條高度，再更新本地虛擬大小及外層捲動範圍。舊容器高度唔參與新量度，所以結果減少時可以縮短。冇新增動畫、產品文字或校準行為。

來源檢查修正前三項有兩項失敗，修正後三項通過；原有保留檢查五項通過。直接編譯正式容器類別的非視窗測試六項通過，刻意取消本地闊度限制後，溢出擁有權一項失敗，再用原來源重跑六項通過。今次冇完整編譯或啟動程式；原生捲動條、滾輪、焦點、鍵盤及全部畫面組合仍待實機驗證。

## 垂直滾輪路由修正細節

結果視窗現時會喺只處理水平嘅捲動輔助器吞掉事件之前，先處理垂直滾輪。佢搵最近外層 `wxScrolledWindow`，複製原事件，保留旋轉、增量、軸同修飾鍵，經螢幕座標轉換位置，將事件物件改成收件者，再透過該擁有者處理器派發。只有派發報告已處理，先消耗原事件。水平事件、缺少外層擁有者同未處理派發，繼續正常處理。冇使用 `SetRevealOwner`，因為會停用本地水平捲動。

非視窗測試執行實際已綁定正式處理器。六個案例涵蓋複製負載同座標、水平留喺本地、最近擁有者選取、缺少擁有者替代處理、未處理派發，同保留本地水平捲動步長。喺 `4e901cddc5d71949703cbd62adc575f8509b4580`，六個有三個失敗。刻意移除新綁定會產生同樣三個失敗；還原原始碼通過 6/6。幾何保持 6/6，相關原始碼保留保持 8/8。呢點唔取代原生滾輪、焦點或繪畫驗證。

## 垂直滾輪路由修正

結果容器會先處理垂直滾輪，避免只支援水平捲動的內層處理器吞咗事件。程式找出最近的外層捲動容器，複製原事件，保留轉動量、增量、軸向及修飾鍵，經螢幕座標換算位置，再交俾外層事件處理器。只有外層確認已處理，先消耗原事件。水平事件、冇外層容器及未處理情況繼續交回正常流程，亦唔會停用本地水平捲動。

測試執行正式綁定的處理程序，六項涵蓋事件內容與座標、水平留喺本地、最近容器、冇容器、未處理及水平捲動速度保留。舊版六項有三項失敗，刻意移除新綁定亦有相同三項失敗；還原後六項全部通過。幾何六項及來源保留八項繼續通過，原生滾輪、焦點同畫面仍待驗證。
