# 具版本嘅託管證據收件者復原

從程序建立開始嘅啟動診斷，會由確切驗證器簽出版本選用 `hosted-gui-public-v3.pem`。其他呼叫端預設保留收件者版本 2。產生端只接受版本 2 同 3；所選 PEM 缺失時會失敗，唔會退回另一把金鑰。收件者版本同證據結構描述獨立：結構版本 2、經驗證 manifest、執行、產品原始碼、驗證器原始碼、執行檔雜湊同密文檢查保持不變。封套以 SPKI SHA-256 識別實際收件者。

管理讀取器識別已封存版本 1、版本 2 同版本 3 公開金鑰。佢按確切 SPKI 身分選擇，拒絕未知或重複身分，並沿用目前使用者嘅 DPAPI 保管路徑。版本 1 保留歷史儲存槽；版本 2 同 3 使用各自以雜湊命名嘅槽。冇取代或重新標示舊公開金鑰或受保護槽。

獲明確授權嘅本機管理員可以新增收件者：

```powershell
pwsh -NoProfile -File scripts/md3/Initialize-HostedGuiEvidenceKey.ps1 -Initialize -Version 3
```

GitHub Actions 上會拒絕初始化。操作建立新 RSA 收件者，只將 DPAPI 保護嘅私密位元組寫入目前使用者嘅本機保管目錄，並以獨佔方式建立新公開 PEM。已存在目的地同重新解析祖先路徑會被拒絕。私密同受保護緩衝區唔會出現喺輸出、命令參數、儲存庫檔案或工作流程上載。只有公開 PEM 同公開身分屬可審閱原始碼材料。

執行 `37100674583` 喺確認工作程序同桌面已清理後，傳送咗部分加密診斷證據。相應本機收件者不可用，所以內容仍未開啟。新收件者無法復原之前嘅密文。版本 3 公開金鑰發佈並獲獨立審閱後，需要重新執行綁定確切原始碼嘅託管診斷。即使成功解密新證據，喺讀取經驗證內容之前，仍唔能夠證明產品成功啟動或某個初始化器失敗。

呢項改動冇喺本機執行產品、除錯器、介面或測試。金鑰初始化只係管理保管操作。保留之前加密套件原樣，並如實報告無法審閱嘅狀態。

版本 3 初始化已成功完成。管理讀回新受保護槽時，身分同產生嘅公開身分一致。呢點證明新收件者嘅本機保管，唔代表解密過任何舊套件。獨立原始碼審閱同新託管診斷仍然需要完成。
