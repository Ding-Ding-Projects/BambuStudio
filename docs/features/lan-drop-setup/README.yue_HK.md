# 可攜式區域網絡託管設定工具

可攜式配套工具已完成編譯，並對現有服務進行了有限範圍的執行驗證。發佈及完整設定驗收仍然待辦。

這個獨立配套工具會檢查本機 Docker 引擎，以及確切的區域網絡模型投遞 Compose 服務。它透過沙盒介面提供設定、覆核、啟動、取消及健康狀態結果。現有服務會原地啟動，不會以套件內的預設值重新建立，因此可以保留連接埠、儲存卷及佇列。遠端 Docker 端點不獲接受。

全新設定目前支援建立新的專用具名儲存卷。如果儲存卷已存在，但找不到相符容器，就會阻止全新設定，等候覆核。資料夾選擇仍未提供。投遞箱不需要站台金鑰，所以設定不會要求任何憑證，配對結果只包含服務地址。

取消操作會在有界限的後端階段之間協作處理。它不會按 PID 終止程序、停止背景服務或移除容器及儲存卷。介面會保持連接，直到工作程序結束並完成服務狀態核對；檢查失敗會令操作維持未解決狀態，並阻止再次啟動。重送已接受的請求會傳回原有操作。每個工作階段會保留 128 份收據，之後拒絕新的啟動請求，而不是刪除舊收據來撤走重播保護。

## 編譯途徑

- `build.bat /s -Companion LanDropSetup`：編譯未封裝的配套工具。
- `build-installer.bat /s -Companion LanDropSetup`：產生單一可攜式執行檔。
- 加上 `-Plan` 可檢視所選途徑，不會取得依賴項目或開始編譯。

一般原生編譯仍然是預設選項。配套工具使用確切的 Electron 45.2.3 及 electron-builder 26.18.0 版本，並附有含完整性資料的 npm 鎖定檔。它重用現有已固定版本、通過總和檢查碼驗證的 Node 啟動工具。原始碼 `0e9a7c849d91141b77ddde007f975cb35be2b7cf` 曾透過根目錄入口完成未封裝編譯；期間截斷的 Node 下載被拒絕，重新取得後成功完成。該次編譯不能驗證其後的原始碼變更。這個檢查點沒有加入發佈工作流程或建立版本發佈。較新的可攜式結果記錄如下。

產生工具現在要求原始碼及索引處於已提交、沒有未提交變更的狀態，並內嵌資訊清單，記錄完整原始碼提交、索引樹、版本、確切的執行環境及建置工具版本，以及相關輸入的雜湊。另一份套件證明會記錄執行檔雜湊及內嵌資訊清單雜湊，不含私人機器路徑。內嵌及外部證明各有用途；執行檔不能包含自己最終的雜湊。

輪詢完成後，就緒結果會重新檢查目前容器、確切的專案及服務標籤，以及資料掛載是否保持不變。容器被替換會令狀態核對維持未完成；已結束的容器會回報為已停止。現有服務要獲准使用，套件內 Compose 檔案指定的已發佈摘要必須出現在解析所得映像的儲存庫摘要中，而設定的儲存庫身分亦須相符。較舊或無關的映像不會被更動，並會回報需要升級；單靠版本標籤並不足夠。

## 驗證及剩餘工作

原始碼 `ed55a003f333ffc01b5879b853f8eedc7d9b6f05` 的可攜式套件曾完成編譯，並在隱藏桌面上操作。該次覆核發現顯示競態：工作程序結束後、健康狀態核對完成前，輪詢已經停止；而較遲按下「取消」，亦會把已完成的操作回報為已取消。目前原始碼將狀態核對活動與工作程序存續時間分開，在核對有結果之前繼續輪詢，並處理實際取消回應。核對失敗會停止自動輪詢，保留手動「重新檢查」，同時不容許重複啟動。

頁首現在會顯示後端已驗證的已發佈映像身分，只有映像通過精確准入檢查後才會取得。這項資料十分鐘後失效，檢查失敗時亦會清除。預期服務版本與實際驗證仍然分開；配套工具版本從來不構成已安裝服務版本的證據。

五項針對呈現程序的測試，會以最小 DOM 及真正控制器，配合延後回應的後端，執行正式呈現程序。它們涵蓋自動完成、終結狀態的取消競態、有界限的核對失敗，以及身分到期及失效。兩項因果變異會恢復舊有輪詢及取消行為，必須令同一組使用端斷言失敗。

原始碼 `9eeafe7dabb4f2b3c5ae7baac66d349f31108862` 其後透過根目錄可攜式入口完成編譯，結束碼為 0。未簽署執行檔的 SHA-256 為 `bc1bd891e8e4ebf91e020eeb211997018fefb0d233d1b3f1e4810f5e2b06cbfa`。實際內嵌資訊清單與產生工具及全部四項套件內託管輸入相符。在具名隱藏桌面上，現有服務流程毋須按「重新檢查」，便自動到達健康結果，並顯示已驗證映像身分。在 960 x 720 及 640 x 520 的外框視窗尺寸、96 DPI 下，已檢視影像顯示結果及保留的頁尾；最小尺寸下亦能透過鍵盤捲動到發送頁面控制項。全部五個已持有身分的程序均正常結束，空白桌面亦已關閉。所選容器的身分、映像、連接埠、掛載及重新啟動狀態均保持不變。

該次執行使用持續連線的 Lowlevel MCP 相容途徑，配合綁定身分的原生輸入及正常關閉。CDP 擁有權驗證阻止了連接，因此沒有聲稱取得 DOM/CSS 版面探測收據。完成後的介面如實隱藏「取消」，但當時無法以確定性的原生注入重現較遲取消的競態；該分支仍然只有正式使用端測試替身的證明。全新設定、依賴項目取得、該次執行期間另一裝置的健康檢查，以及完整語言、主題及縮放矩陣仍未驗證。這些結果不能取代先前另行記錄的區域網絡驗證。

十一項針對操作及控制器的測試，使用注入的後端替身及暫時佔用連接埠的接聽程式，全部通過。它們涵蓋作用中及未解決操作的互斥、取消後狀態核對、保留設定、未知操作、有界限的歷史、舊請求重播、收據容量，以及預先檢查失敗後、經確認不存在目標的復原。中性的 Docker Compose 設定測試資料會針對繼承的專案名稱、dotenv 檔案及孤立容器移除，執行正式環境規則。正式程序讀取器的測試會拒絕過大的標準輸出，同時持續讀走過大的標準錯誤輸出。PowerShell 及 JavaScript 原始碼解析通過。這些結果不能證明實際 Docker 啟動、已安裝依賴項目的復原、可攜式封裝或實際呈現行為。

另一項正式使用端測試會使用 Docker 格式的 JSON，檢查停止及執行狀態切換、被替換的身分、儲存變更，以及已發佈映像摘要准入的正反情境。原始碼 `dfc272840f97a947268b6dbd48128588bf58a3c4` 的可攜式產生工具曾產生執行檔，但封裝後證明步驟失敗，原因是 PowerShell 將只有一個檔案的陣列展開。陣列處理已修正；該次失敗執行不獲接納為套件證明。

仍未完成的項目包括：自動取得可信依賴項目、原生授權及同意處理、全新空白資料夾儲存、可續接草稿、複製網址及記錄檢視、完整本地化診斷、原生關閉對話框本地化、全部語言、主題及縮放影像，以及經量測的最小尺寸覆蓋。必要功能清單亦未完整，包括附獨立正規表示式建立器的搜尋、個人用語匯入、操作音效、外觀設定、鍵盤及命令面板覆蓋，以及完整內嵌文件。這裡沒有聲稱已完成所有通用功能。

設計狀態清單及建議協定位於 `design/lan-drop-setup/`。套件內的 Compose 檔案固定使用服務版本 1.0.1；配套工具發佈與服務發佈是兩項獨立結果。實作期間沒有更動任何運作中的服務。
